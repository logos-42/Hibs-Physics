# 最小物理实验：回旋共振频移验证 H1 核心

## 0. 目标

用**一个桌面级实验**验证 H1 的核心签名——「电磁时变场驱动空间流起伏变化，
产生有限增益 η>0」的**可观测后果**：质量取消 ⟹ 回旋频率频移。

这是 roadmap 判决量 D1（G1 生死门/标定门）的**最小化实现**：单粒子、单
频率计、开/关对照。不是新物理，是把「验证 H1」落实成最便宜的一次测量。

## 1. 被验证的链（核心签名从哪来）

```
H1（假设）：电磁时变场驱动空间流起伏变化，产生有限增益 η > 0
  ⟹ m_eff = s·(1 − μ)                     （AMC1 质量取消，s=锚定强度）
  ⟹ ω_ci = qB / m_eff                      （FC9：回旋频率 ∝ 1/m_eff）
  ⟹ R_ci = ω_ci(驱动开) / ω_ci(驱动关) − 1 = 1/(1−μ) − 1   （D1 判决量）
零假设（H1 假）：R_ci = 0，即驱动场对回旋频率零影响
```

全部环都是仓库已证/已登记条目（AMC1 = theory-mass-cancellation，
FC9 = theory-frc-compact，D1 = fusion-program-roadmap）。实验只测
**后果签名**，不测 η 的来源（来源留给理论层，G1 只标定不解释）。

## 2. 为什么这是最小实验（最小性论证）

| 对比项 | 本实验 | 替代方案（不做） |
|---|---|---|
| 对象 | **单离子**（H⁺ 或 Be⁺，Penning trap/离子阱） | 铜-氢等离子体双流形（PA 轮）——复杂：需等离子体源、双流形、三温度 |
| 签名 | 回旋频率频移（一个频率，直接测） | 双流环 η（需 Q_A 泛函全场测量）——重 |
| 装置 | 桌面：小磁体 + 射频驱动 + 频率计 | 双流环/FRC 装置——吨级 |
| 与 roadmap | **与 G1/D1 完全一致**（D1 就是为此设计；G0+G1 = 15 人·月 = 全周期 1.29%） | 偏离既有门表 |
| 许可 | 无氚无中子，**无需核许可**（前 18 个月） | 聚变装置需核许可 |

单粒子优于等离子体的理由：去掉集体效应（双流形叠加、三温度弛豫、
等离子体不稳定性）对签名的污染，测最纯的「质量取消 ⟹ 频移」。

## 3. 装置设计（最小部件清单 + 物理参数）

| 部件 | 参数（桌面级） | 依据 |
|---|---|---|
| 离子 | H⁺（q/m 最大，频移最明显）或 Be⁺（Penning trap 精密测量标准） | SA 轮诊断阶梯：单粒子回旋共振/Penning trap 精度可达 **1e-6** |
| 约束磁场 | 0.5–5.3 T（永磁/小型超导）⟹ H⁺ ω_ci ≈ 7.6–80.8 MHz | SA 轮锚点：B=5.3T ⟹ 80.80 MHz；9T ⟹ 137.21 MHz（都在射频诊断内） |
| 时变驱动 | 射频/RMF，频率 ≈ 回旋频段（驱动空间流时变，PA4） | PA4：时变磁场 ⟹ 时变空间场 |
| 频率测量 | 锁定/频率计，目标 **δ ≤ 1e-4**（3σ 判别力） | roadmap D1：δ=1e-4 ⟹ 可探测 μ_min ≈ 1e-4 |
| 对照 | 驱动开/关，同离子测 R_ci；盲测防系统效应 | 零假设判据 |

**判决统计**（roadmap D1 口径）：
- δ = 1e-4、3σ ⟹ μ_min = δ/(1+δ) ≈ **1e-4** 可探测
- 聚变级需 μ ≈ 0.999（FC11 天花板 0.999781），差 **4 个数量级**——本实验是
  μ 数量级阶梯（1e-4 → 1e-3 → … → 0.999，每年一个数量级）的**第一格**

## 4. 成功标准与后续

- **R_ci > 3σ** ⟹ H1 有签名：进入标定期（G1 标定门）——标定
  μ(B)/μ(f)/μ(配比) 三曲线，放大装置
- **R_ci ≈ 0（δ 精度内）** ⟹ H1 证伪：按 roadmap 预写处置**停装置线**，
  花 1.29% 预算买到判决（两个分支都不白干）
- 本实验之后才有资格谈「低成本聚变路径」——原理判真，几何成本
  才兑现（AMC3：抹平成本 ∝ 梯度²）

## 5. 死法（写死）

1. **频率精度不足**（δ > 1e-4）：判别力不够 ⟹ 先买最便宜设备跑通、
   升级冷/窄线诊断（单粒子/Penning trap 1e-6 首选），不换热谱线
   （SA 轮结论：1 keV 热谱线只到 ε ≥ 1.5e-3）
2. **系统效应伪装频移**（温度漂移/场漂移/电源纹波）：
   开/关对照 + 盲测 + 同装置同离子双测量（D2 的 Λ 口径同族）
3. **单粒子签名 ≠ 等离子体签名**（集体效应改变签名形态）：
   本实验只判 H1 的单粒子后果；双流形/等离子体层留给下一阶段，
   不作为本实验的成败判据

## 6. 诚实边界（写死）

- 这是 D1 的最小化实现，**不是新物理**；全部数字 = 仓库既有条目代入
- 只测后果签名（质量取消 ⟹ 频移），**不测 η 的来源**——来源由 H1
  收编（leo 提供物理来源），G1 只标定 η 数值

- η_inj 数值、驱动功率标度 k（D3）仍待本实验之后标定
