# 自旋-统计的代数内核（VSS1–VSS8）

> 上一轮（VBS / VBC）把缺口 A 登记为：「为什么自然界只取 σ = ±1 这个二元子群，
> 而不是一般任意子相」。本轮把它**推出来**——在仓库自己的语言里闭合。

## 1. 三个前提（都不是新公设）

| # | 前提 | 仓库出处 | 为什么不是新公设 |
|---|---|---|---|
| 1 | **角色性**：g(0)=1 ∧ g(a+b)=g(a)·g(b) | VBS4（统计相位可加）是它的另一面 | 这是「相位」概念本身的要求：相位可加 ⟹ 取指数后相乘 |
| 2 | **4π 复原**：g(4π) = 1 | SFS5（Cℓ(3) 最小表示 2 维 ⟹ SU(2) 双重覆盖）；数值层 e^{2iπσ₁} = I | SU(2) 的表示论事实：2π 旋转 = −I、4π 旋转 = +I，**在每一个表示里都成立** |
| 3 | **三方向（3D）**：旋转群的基本群是 ℤ₂ | P3（三方向假设） | π₁(SO(3)) = ℤ₂（3D 旋转群）；2D 才是 π₁(SO(2)) = ℤ——任意子的来源 |

前提 3 的位置很关键：**它决定了"两类"而不是"无限类"**。3D 的闭路只有两种同伦类，
所以相位只能落在两个值上；2D 有无限多种，才有任意子。仓库的 P3 恰好就是"3D"。

## 2. ★★ 核心定理（VSS3）

```text
IsRotationPhase g := (g 0 = 1) ∧ (∀ a b, g (a+b) = g a * g b)

theorem closure_phase_two_values (hg : IsRotationPhase g) (h4 : g (4π) = 1) :
    g (2π) = 1 ∨ g (2π) = -1
```

证明只有三行：
```
g(4π) = g(2π + 2π) = g(2π)·g(2π)        （角色性）
g(4π) = 1                                （4π 复原）
⟹ σ² = 1  ⟹  σ = ±1                     （ℂ 中 σ²=1 只有两个解）
```

**⟹ σ ∈ {±1} 不再是定义选择，而是"角色性 + 双覆盖"的推论。**
两个前提都不是新公设 ⟹ **未引入任何新公设、新标度。**

## 3. ★ 推论：任意子被排除（VSS4 / 数值 S2）

```text
theorem sq_one_two_values (σ : ℂ) (h : σ * σ = 1) : σ = 1 ∨ σ = -1
```

在 ℂ 里 `σ²=1` 恒等于 `(σ−1)(σ+1)=0`，只有两个解。所以任何**非 ±1 的统计相
（任意子）都不满足 4π 复原**：

| 绕数 α | σ = g(2π) | \|σ²−1\| | 满足 4π 复原 |
|---|---|---|---|
| 1（整数绕数） | +1 | 4.9e−16 | ✓ 玻色型 |
| 0.5（半整数绕数） | −1 | 2.4e−16 | ✓ 费米型 |
| 1/3（三分统计） | e^{2πi/3} | **1.732 = √3** | ✗ 违反 ⟹ **排除** |
| 1.7（一般实数） | e^{3.4πi} | 1.902 | ✗ 违反 ⟹ **排除** |

数值 S1：扫描 α ∈ [0, 2π)（200001 点），`|σ²−1| < 1e−6` 的零点**只有两个**（α = 0 与 α = π）。

⟹ **在 3D（三方向）+ SU(2) 双覆盖下，统计只有两种，没有第三种。**

## 4. ★ 两个分支的物理身份（VSS5 / VSS6）

```text
σ = +1 ⟹ g(θ+2π) = g(θ)     单值 ⟹ 可降到 SO(3) ⟹ 玻色型
σ = −1 ⟹ g(θ+2π) = −g(θ) ∧ g(θ+4π) = g(θ)   真双值 ⟹ 费米型
```
（σ = −1 这一条正是 VBS2「2π 变号、4π 复原」在角色语言下的形式。）

## 5. ★ 配对不是约定：2π 旋转在自旋 j 的表示上是纯量 (−1)^{2j}（数值 S4）

SU(2) 的中心是 {I, −I}。任何自旋 j 的不可约表示都把 2π 旋转（= −I）映成纯量 `(−1)^{2j}`：

| 自旋 j | 表示维数 | R(2π) 的标量 | 是纯量？ | 统计 |
|---|---|---|---|---|
| 0 | 1 | +1 | ✓ | 玻色型 |
| 1/2 | 2 | **−1** | ✓ | 费米型 |
| 1 | 3 | +1 | ✓ | 玻色型 |
| 3/2 | 4 | **−1** | ✓ | 费米型 |
| 2 | 5 | +1 | ✓ | 玻色型 |

⟹ **「整数自旋 ⟹ 玻色、半整数自旋 ⟹ 费米」在仓库里是表示论事实，不是事后约定。**
（数值用 2×2 / 3×3 / 4×4 / 5×5 的具体 J_z 矩阵算 R(2π) = exp(−i·2π·J_z)，五个自旋全中，
且都验证了 R(2π) 是纯量——即落在中心。）

## 6. 与 VBS 的接口（VSS7 / VSS8）

- **VSS8**：若态按角色变换（f(θ) = g(θ)·f(0)），则 f 的闭包相因子恰为 g(2π)
  ⟹ **σ 就是 2π 旋转的相位**——把"角色"和"闭包相因子"接上。
- **VSS7**：也可以完全不提角色，只用 VBS 的闭包定义 + 4π 复原：
  `f(θ+4π) = σ²·f(θ)`（VBS1）与 `f(θ+4π) = f(θ)` 联立、取非零态 ⟹ σ²=1 ⟹ σ=±1。
  两条路同结论，一条走角色、一条走仓库自己的闭包语言。

## 7. 诚实边界（4 层）

- **① 数学恒等**：核心是 `σ²=1 ⟹ σ=±1`（ℂ 中一次因式分解）——真但平凡；
  `g(4π)=g(2π)²` 是角色性的代入。
- **② 结构对应**：角色性 = 相位可加；4π 复原 = SU(2) 双覆盖（SFS5）；配对 = (−1)^{2j}
  是 SU(2) 中心的表示论事实。全是标准数学。
- **③ 数值匹配**：S1–S5 全机器精度（1e−16 ~ 1e−9），验的是恒等本身。
- **④ 概念重构**：**缺口 A 在仓库语言内闭合**——σ ∈ {±1} 从"定义选择"变成"三条已有结构的推论"，
  且**任意子被排除**。**无新可检验预言。**

**更正（本轮的自我纠正）**：上一轮我说这条链需要「GQC2 + SFS5 + VBS」三块碎料。
**核实后不成立**：GQC2（格点化 ⟹ 光锥 ⟹ 不可通信）的角色是**许可性**的
（它保证闭包相位是态自身的角色、而非环境的函数），**不是本定理的证明前提**；
真正的第三块是**三方向（P3，3D）**——因为必须 3D 才能把闭路类压到 ℤ₂（2D 就有任意子）。
本轮采用了更正后的说法。

**仍未闭合（登记，不编）**：
1. **标准 Pauli 自旋-统计定理的另一半**——「相因子 ⟹ 场算符反对易」——需要**场算符**语言
   （QFT 公理：微观因果 + 正定性）。仓库里没有场算符，**这一半不在仓库的语言里，也未闭合**。
   仓库做的是：把"统计"**定义**成闭包相因子，于是"自旋 ⟹ 相位"这一半就够了；
   但"相位 ⟹ 算符反对易"这一半没有对应物。
2. **拓扑前提 π₁(SO(3)) = ℤ₂ 未形式化**（需要代数拓扑）。仓库里与之等价且**已有**的形式是
   「4π 复原」，本轮用它作前提（这是等价的替换，不是回避）。
3. 所有**标度类**缺口（966× / e / M₀ / ρ·α·k·κ·ν）未动。

## 8. 本轮对"解释力"这把尺子的影响

对照上一轮的记账（两把尺子）：
- **公设经济**：σ ∈ {±1} 从输入变成输出 ⟹ 独立输入又少一个。这是本轮唯一一处"输入 → 输出"。
- **解释力**：这**正是**标准 spin-statistics 定理的代数内核那一步
  （"自旋的表示 ⟹ 2π 旋转的标量 ∈ {±1}"）。所以"为什么是玻色/费米两种"在仓库语言里**有答案了**。
  但标准定理的另一半（算符统计）仍缺 ⟹ **仓库版的 spin-statistics 是"半条定理"**，不是全条。
- **经验新颖性**：仍为零（与标准理论数值全同）。
