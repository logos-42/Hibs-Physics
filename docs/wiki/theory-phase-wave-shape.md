# 相位场形状谱与 KdV 估值配置（KV1–KV6）

> leo（2026-10-01，/loop）：「把波的形状、波本身、相位场、空间场放在一起考虑。
> 相位场在波动过程中的形状如何？本体 = 空间本身在运动，这个运动因为相位场的波形
> 产生了变化。需要从振动本体上开始推导。」

## 1. 本轮做什么（诚实，写最前面）

**不是**「KdV 就是空间的动力学方程」——那是**断言**，需要新公设（本轮**没有加**）。
本轮做两件事：

1. **接口代数（Lean，PF1–PF5）**：把「相位场 θ、波形状 sech²、空间场 C」之间那些
   **纯代数**关系钉下来——相位可加、行波叠加封闭、形状恒等式、偶/奇性。
2. **数值配置测试（KV1–KV6）**：把「形状当标尺」这条路径**真正跑起来**，并给两个
   **判死测试**：形状族能不能配出质量阶梯 3,6,7？（KV5：不能）形状谱只依赖几个参数？
   （KV6：一个 c）

**仓库根基**：MS3（C 的波动方程 ∂²C = c²∂²C，`theory-maxwell-space.md`）；
相位场 θ(x,t) 以相速度 c（`current-status.md:454`）。

## 2. Lean：`Explorations/PhaseField.lean`（PF1–PF5，零 sorry 零 warning，挂聚合根）

| 定理 | 内容 |
|---|---|
| **PF1** | 相位可加：`e^{i(θ₁+θ₂)} = e^{iθ₁}·e^{iθ₂}` ⟹ 相位场叠加 = 复乘法（振动合成律） |
| **PF2** | 行波叠加封闭：`f = g(x)+h(−x)` 族的和仍是同族（波动方程线性性的谓词版） |
| **PF3** | 形状恒等式：`(1/cosh x)² = 1 − tanh²x`（sech² 形式的代数根基） |
| **PF4** | 形状偶性：`1/cosh(−x) = 1/cosh x`（振动形状无方向偏好） |
| **PF5** | 形状奇分量：`tanh(−x) = −tanh x` |

**接口结论**：相位场的振动形状 = **偶函数 × 复相位**，叠加按**乘法**合成。
偶形状 ⟹ 峰对称（孤子形状族）；复相位可加 ⟹ 两个振动合成 = 相位相乘
（与 VBS 闭包因子同一代数结构）。这是「波形状当标尺」需要的最小代数接口。

**Lean 三个坑（本轮实测）**：`Real.sech` 在 mathlib **不存在**（没有这个函数）；
`Real.tanh` 定义成复数版（`.re` 嵌入）——奇偶性要用 `Real.tanh_eq_sinh_div_cosh` 展开再证；
PF2 的函数式目标 `simp` 不闭合，要 `change` 展开再 `rw + ring`。

## 3. 数值：`scripts/verify_phase_wave_shape.py`（KV1–KV6）

产物：`artifacts/phasewave/{report.json, summary.txt, fig_shape_ruler.png, fig_phase_field.png}`

### KV1 ★ 形状锁尺度（成立）

```text
孤子 u = (c/2)·sech²((√c/2)(x−ct))
振幅 ∝ c，宽度 ∝ 1/√c  ⟹  振幅 × 宽度² = 8·acosh(√2)² = 6.214555（纯数，与 c 无关）
```

**「波形状当标尺」在这里是真的**：一个波的形状把它的尺度钉死了（可算）。
但全部钉在唯一一个自由参数 c 上 ⟹ **只搬运一个标度，不产生第二个**。

### KV2 形状谱（定量）

宽度² 比值 = {1: 3.0, 2: 1.5, 3: 1.0, 6: 0.5, 7: 0.4286}（∝ 1/n）。
**形状族 sech² 的宽度²谱比是逆整数序列 1/n，而质量阶梯是 3, 6, 7 ⟹ 阶梯不是形状谱的几何产物。**

### KV3 ★ sech² 是 KdV 精确解（验证）

解析导数代入 `u_t + 6uu_x + u_xxx`：c = 0.25/1/4/16 残差全部 **≤ 1.14e−13**（机器精度）。
⟹ 孤子是 KdV 的精确解（代数上三个 tanh 幂次逐项消掉）。

### KV4 守恒量零变化（可积）

C₁、C₂、C₃ 在（解析）演化下相对变化 **全 0.0** ⟹ KdV 无耗散、无跑动
⟹ **不产生新标度**（形状谱是「搬运」不是「生成」）。

### KV5 ★★ 判死测试 1：形状族配不出质量阶梯 3,6,7

sech² 是**单参数**族（c 连续）：配 3 个目标永远可行（3 个自由度）。
**没有排除力 ⟹ 不能预言 3,6,7。** 这是「波形当标尺」路线的核心否定。

### KV6 ★★ 判死测试 2：形状谱只依赖一个参数 c

守恒量 `C₂ ∝ c^{3/2}`（偏差 1.3e−3）⟹ 整个形状谱只依赖 c。
**几何自由度 = 1 ⟹ 一个理论只能「校准」一个标度，不能预言第二个。**
这与 SC6（尺度不变 ⟹ 比值输出给不出标度）是同一件事的两面。

## 8. PW：把「相位场形状」与「空间场传播」接成两层接口（2026-10-06）

KV 轮已经证明「KdV 形状可以锁定一个尺度」，但还没有把它和仓库已有的空间场 `C` 波动方程接起来。
本节配置的不是新公设，而是测试复相位场接口：

```text
ψ(x,t) = A(x,t) · exp(iθ(x,t))
```

对 `1+1D` 空间波动算子 `□ = ∂t² − ∂x²`，分解为：

```text
□ψ = exp(iθ) [
  □A
  + 2i(At·θt − Ax·θx)
  + iA□θ
  − A(θt² − θx²)
]
```

这里的四项分别对应：

- 包络形状自身的波动；
- 包络梯度与相位梯度的耦合；
- 相位场自身的波动；
- 相位梯度产生的有效局部项。

### PW1–PW4 实测

| 测试 | 结果 | 认识论状态 |
|---|---:|---|
| PW1：`A(x−t) exp(iθ(x−t))` 同流复相位场 | 残差 `0` | 数学恒等式 |
| PW2：同流包络与相位 | 残差 `0` | 结构接口 |
| PW3：包络速度 `v=0.65`、相位仍按 `c=1` 传播 | 残差峰值 `0.144336` | 非零相对运动候选；**不是质量定理** |
| PW4：KdV 包络残差 | `1.67e−16` | KdV 包络层成立 |
| PW4：线性空间波动残差 | `0` | MS3 空间场传播层成立 |

### 当前统一描述

因此目前最干净的分层不是「KdV 取代空间场方程」，而是：

```text
相位场 θ + 包络 A
        ↓
复相位场 ψ = A exp(iθ)
        ↓
空间场 C 的线性传播（MS3）
        ↓
包络形状的非线性修正（KdV 型，尚非框架公设）
        ↓
包络与空间流脱离时出现非零相对残差
```

**关键结论**：KdV 包络层与 MS3 空间传播层可以同时成立，但它们不是同一个方程。
「脱流残差」可以作为锚定/质量候选接口继续研究，但目前只证明它是一个非零波动残差，
没有证明它等于质量、能量或第二标度。

### 本节没有做的事

- 没有把 KdV 写成空间场 `C` 的新公设；
- 没有把 PW3 残差命名为质量；
- 没有给出 `m_e/M₀`、`v/M₀` 或胶球 `N={3,6,7}`；
- 没有解决绝对标度缺口；
- 没有使用耗散或非酉项。

产物：`scripts/verify_phase_wave_coupling.py`、`artifacts/phasewavecoupling/report.json`、
`summary.txt`；门禁断言 PW1–PW5 已挂入 `verify_all.py`。

### PW5：与 SM3 偏离量对位

速度扫描 `v={0,0.25,0.5,0.65,0.8,0.95}` 显示，当前包络模型的脱流残差与 `1−v²/c²` 严格成正比，
比例离散度小于 `1e−10`。这说明 PW3 与仓库 SM3 的“偏离空间流”在**接口形状上同构**；
但它仍不是质量定理，因为比例系数是包络曲率，且没有导出质量单位或第二标度。

## 9. PWA：PW3 与 MC1 的最后一跳（2026-10-06）

仓库 MC1 的锚定质量平方是：

```text
anchorMassSq(s) = s²
```

PW3 给出的量是：

```text
R_PW(v) = K · (1−v²/c²)
```

对 `v={0,0.25,0.5,0.65,0.8,0.95}` 做了三种对位：

| 锚定强度候选 | 最大误差 | 判定 |
|---|---:|---|
| `s=1−v` | `0.75007` | 不能直接等同 |
| `s=1−v²/c²` | `0.75007` | 不能直接等同 |
| `s=sqrt(R_PW)` | `0` | 可以逐点匹配，但这是反向定义 |

因此 PW3 目前只能给出：

```text
PW3 残差 与 SM3 偏离量同构
```

还不能给出：

```text
PW3 残差 = MC1 锚定质量平方
```

缺的不是代数，而是两个物理输入：

1. 包络曲率 `K` 如何映射到 MC1 的锚定强度 `s`；
2. 这个映射的单位/归一化从哪里来。

`PWA3` 的 `s=sqrt(PW3)` 只是定义匹配，不是推导。**如果后续不能从相位场闭合、拓扑绕数或已有公设导出 `K` 与 `s` 的映射，
就必须把它登记为新的手输接口，不能称为质量统一。**

产物：`scripts/verify_phase_anchor_interface.py`、`artifacts/phaseanchor/report.json`、`summary.txt`；
PWA1–PWA3 已挂入 `verify_all.py`。


## 10. PWW：相位绕数不能单独固定锚定归一化（2026-10-06）

进一步测试闭合相位 `θ=2π n x/L` 是否能固定 PW3 的归一化系数 `K`。
绕数扫描 `n={1,2,3,5}` 全部整数化；但同一绕数下改变包络形状参数 `c={1,4,9,16}`，归一化曲率离散度分别为：

```text
n=1: 2.999975
n=2: 0.749994
n=3: 0.333331
n=5: 0.119999
```

**结论**：相位闭合和绕数能提供离散拓扑标签，但不能单独给出 PW3→MC1 所需的归一化。
同一个绕数仍允许不同包络曲率，因此 `K` 需要额外动力学或归一化输入。
这把最后的缺口定位得更精确：不是缺绕数，而是缺“包络形状 → 锚定强度”的动力学映射。

## 11. PWS：包络曲率到锚定强度的最小候选（2026-10-06）

对 `A_c(x)=(c/2)sech²(√c x/2)`，定义无量纲形状曲率：

```text
K_shape = max|A''| / max|A| ≈ c/2
```

数值扫描 `c={0.25,1,4,9,16}` 的最大相对误差小于 `2e−3`。结合 PW3：

```text
s_candidate² ∝ K_shape · (1−v²/c²) ≈ (c/2)(1−v²/c²)
```

这个候选把锚定候选拆成两个因素：

- 形状因素：`c/2`；
- 脱流因素：`1−v²/c²`。

**但这仍不是 MC1 质量定理**：绝对归一化、质量单位以及 `s_candidate` 到 `anchorMassSq(s)` 的物理映射都没有从现有公设推出。
当前最小缺口已经从“缺一个任意残差系数”收窄为：**是否存在由相位闭合/拓扑/空间场动力学导出的归一化方程**。

PWS1/PWS2 已挂入 `verify_all.py`；产物：`scripts/verify_phase_anchor_shape_map.py`、`artifacts/phaseanchorshape/`。


## 12. PDO：振动本体的动力学来源审计（2026-10-06）

新鲜复核仓库已有空间场方程：

- MS3：`□C=0`，线性空间波传播；
- MS5：`□C=J`，电荷/电流作为显式驱动；
- 现有方程没有 `C` 或 `ψ` 对自身的非线性反馈项。

PDO 测试确认：

- 纯相位同流波 `θ=k(x−t)` 的波动残差 = `0`；
- 纯相位没有包络曲率；
- `□ψ+β|ψ|²ψ=0` 这类包络局域化方程虽然是候选，但 `β` 是新动力学输入；
- `□ψ+μ²ψ+β|ψ|²ψ=0` 还额外引入 `μ` 标度。

**结论**：从现有振动本体可以推出传播和相位闭合，但不能自己产生局域包络。
若要让空间运动因相位波形变化而自发形成局域结构，必须从现有公设推导一个非线性反馈，
或明确加入带死法的新动力学公设。当前两者都没有完成。

这不是停止，而是把下一步钉成唯一问题：**从 `C` 的已有结构（MS3/MS5、`|C|=c`、相位闭合）
能否推导出非线性反馈项；若不能，新增项就是公设而非推论。**


## 13. PNF：固定模长空间场本身不能产生包络非线性（2026-10-06）

沿现有 SLS1/ MS3 结构取二维相位嵌入：

```text
C = c (cos θ, sin θ)
```

因此 `|C|=c` 固定。对无源线性波动算子 `□C`，分解得到：

```text
□C = c n_perp □θ − c n [(θt)² − (θx)²]
```

其中 `n=(cosθ,sinθ)`，`n_perp=(-sinθ,cosθ)`。数值审计：

- 光锥相位 `θ=k(x−t)`：径向 `□C` 分量 `0`，且 `□θ=0`；
- 脱离光锥相位 `θ=k(x−0.65t)`：径向残差 `−1.668975`；
- 但固定模长本身没有包络自由度。

**结论**：固定模长 + 无源线性空间波动只允许光锥相位，不会自动产生局域包络。
这不是坏消息，而是把“从振动本体推导非线性”的入口钉到了唯一位置：
必须从 `|C|=c` 约束的几何兼容条件、源项 MS5，或相位闭合条件中推导自相互作用；
若推不出来，新增非线性就是公设而非推论。

PNF1/PNF2 已挂入 `verify_all.py`；产物：`scripts/verify_phase_norm_feedback.py`、`artifacts/phasenormfeedback/`。
