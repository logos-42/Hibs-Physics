## 3. 尺度协变性（SC1–SC6）：为什么框架「原理上」给不出标度

框架 QCD 层的输出形状是阶梯：`m² = N·M₀²`，`m = √N·M₀`。三条全证：

| 定理 | 内容 |
|---|---|
| ★ SC1a `SC1a_mSq_rescale` | `m²(N, λM₀) = λ²·m²(N, M₀)` |
| ★ SC1b `SC1b_mMass_rescale` | `m(N, λM₀) = λ·m(N, M₀)` |
| ★★ SC2 `SC2_mSq_ratio_scale_free` | `m²(N₁,M₀)/m²(N₂,M₀) = N₁/N₂`（**与 M₀ 无关**） |
| ★★ SC3 `SC3_mMass_ratio_scale_free` | `m(N₁,M₀)/m(N₂,M₀) = √N₁/√N₂` |
| ★★ SC4 `SC4_ratio_invariant` | **阶梯比值是重标定不变量**（对 M₀ ↦ λM₀ 零敏感） |
| ★★ SC5 `SC5_invariant_cannot_read_scale` | 重标定不变的输出**读不出**标度（λ ≠ 1 时无法区分 M₀ 与 λM₀） |
| ★★★ SC6 `SC6_ladder_cannot_output_scale` | **主结论**：阶梯比值**原理上不可能输出 M₀ 的数值** |

**SC6 的意义**：这不是「还没算出来」，是「**这一形状不算**」。
框架现有的输出全是比值形 ⟹ 它对标度的敏感度**恒等于零**。
这解释了为什么标度类缺口的补法不是「把现有推导再做细」——**做细多少都还是比值**。

数值（S2）：M₀ 扫 7 个量级，一切比值残差 **4.44e−16**（机器精度）。
