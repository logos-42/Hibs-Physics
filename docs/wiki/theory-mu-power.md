# μ 的功率账本与胶球 N 的同源检验

本页做两件事：① 把"同源"精确成可检验的陈述并**检验它**；② 把"多少瓦换多少 μ"算成数。

## 1. 同源载体：同一整数向量的两个泛函

仓库已有两条用**同一族整数**说话的账。写成泛函：

    N(n) = Q(n) = Σnᵢ² + Σ_{i<j} nᵢnⱼ [+ |μ̄₃|]      （幅值泛函 —— 含集体项；RT3 的 Q）
    μ(n) = 1 − |Σnᵢ| / Σ|nᵢ|                        （符号泛函 —— 抵消度）

**★ 结论一：同源成立，互相决定不成立。** 两个见证（Lean MW4/MW5 与数值层互锁）：

| 见证 | 向量 | N | μ |
|---|---|---|---|
| A（同 N 不同 μ） | (1,1,0) | 3 | 0 |
| A（续） | (2,−1,0) | **3** | **2/3** |
| B（同 μ 不同 N） | (1,1,0) | 3 | 0 |
| B（续） | (1,1,1) | **6** | **0** |

枚举层：|nᵢ| ≤ 4 内**同 N 不同 μ 有 20 组**、**同 μ 不同 N 有 12 组** ⟹ 两个泛函确实独立。
所以"胶球与 μ 同源"这句话**可以成立**，但**不蕴含**"知道 N 就知道 μ"——还要额外的选择规则。

## 2. FC11 天花板与奇偶律

口径先钉死：FC11 的 m_e/m_i = 2.19432e-4 是**残余比**，对应 **μ 的天花板**（不是地板）

    μ 天花板 = 1 − 残余比 = 0.999780568036375   （仓库已公开的数）
    名义 gross = 1/残余比 = 4557.22

**★ 结论二（本次发现）：奇偶律 —— 毛与净同奇偶。** 对整数向量

    Σ|nᵢ| ≡ Σnᵢ ≡ |Σnᵢ| (mod 2)   ⟹  gross ≡ net (mod 2)

枚举（|nᵢ| ≤ 6）**违例 0**。它的直接后果：**残余量子不能随便配 gross** ——

| 残余 net | gross | 同奇偶 | μ | 乘性实现 C(m,2)·q = gross |
|---|---|---|---|---|
| 1 | 4557 | ✓ | 0.999780557384 | (m,q) = (2,4557)、(3,1519)、(7,217) |
| 2 | 9114 | ✓ | 0.999780557384 | (2,9114)、(3,3038)、(4,1519)、(7,434) |
| 3 | 13672 | ✗ 被否 | — | — |

注意：**实现不唯一**（残余 1 就有 3 种），所以这条只能当"账目自洽的候选集"，**不能当预测**。

## 3. 同源高档位推论（若两个账共用同一个计数单位）

残余比 2.19e-4 ⟹ 每股 |n| ≈ 4557 ⟹ N = 2n² = 4.15e7 ⟹ 质量 = √N·M₀

    √(4.153e7) × 977 MeV ≈ 6.30 TeV

而胶球阶梯（同一 M₀）是 1.7–2.6 GeV ⟹ **差 3 个量级**。这是本次探索最硬的张力：
"同源"在**载体**层自洽，在**能量尺度**层不自洽。两条收敛路径（**交回 leo 校准**）：

- 路径甲：承认存在**两个不同的计数单位**（μ 的"连接单位"比 N 的"条数"细 ~10³ 倍）；
- 路径乙：μ 载体就是**同一阶梯的高档位**（一个 ~6 TeV 的构型），那么它是一个可查的预言。

## 4. 功率账本

若一个连接单位的能量是 ε（物理实现待给），则

    W = ε·|net| = ε·gross·(1−μ)      ⟹      dW/dμ = −ε·gross（常数）

**★ 结论三：每单位 μ 的价格只随 gross 走，与 μ 当前位置无关**（Lean MW2/MW3）。
自洽检查全过：W 随 μ 严格递减；**μ → 1 ⟹ W → 0**（完全抵消 ⟹ 零代价），这与仓库已有的
"双螺旋反向 ⟹ μ = 1 ⟹ 光子无质量"一致。

分辨率-代价权衡（ε 取磁管量级 6.17e8 J；分辨 μ 需 gross ≥ 3/μ_target）：

| μ 目标 | gross ≥ | W |
|---|---|---|
| 1e−2 | 300 | 1.83e11 J（≈ 5.1e4 kWh） |
| 1e−3 | 3000 | 1.85e12 J（≈ 5.1e5 kWh） |
| 1e−4 | 30000 | 1.85e13 J（≈ 5.1e6 kWh） |

⟹ 要细分辨就必须大 gross，就必须更贵 —— **分辨率与代价不可兼得**，这条可直接接诊断规格。

## 5. ε 的量级下界（由"μ ≈ 1 不普遍"反推）

观测事实：质量普遍存在 ⟹ μ 接近 1 是罕见态 ⟹ 把 μ 推到 1 的势垒必须远大于热涨落，
否则系统早就弛豫到无质量态。取 margin = 10：

**★ 结论四：ε ≳ 10·kT**。三个候选的过线情况：

| 候选 | ε | 过线 |
|---|---|---|
| 磁管能量（B = 12.2 T、a = 0.5 m、R = 2.111 m） | 6.17e8 J | ✓ |
| 热涨落（T_e = 100 eV） | 1.60e−17 J | ✗ |
| 回旋光子（f = 200 MHz） | 1.33e−25 J | ✗ |

⟹ 若 μ 的量子化是真实的，**抵消必须由宏观自由度（磁场/电流）承担，不能靠热涨落或单光子**。

3. ε 的三个候选都是**量级估计**（用装置参数或等离子体温度代入），不是推导。
4. 乘性实现不唯一 ⟹ 第 2 节只是"自洽候选集"，不是"指认"。
