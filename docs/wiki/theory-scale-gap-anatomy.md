# 标度缺口的位置：它为什么会出现

> leo（2026-10-01）：「真正缺的第二个标度，这个真正的缺口是怎么出现的？」
> 本页不是新推导，是**定位**：把「缺口在哪」写成可复用的诊断。上一轮（SC 轮）已把
> 「单个常数的数值 = 单位」拆出去，所以这里要面对的是**剩下那一小撮无量纲比从哪来**。

## 1. 名字要改：缺的不是「一个数」

上一轮的结论是：框架**零标度内容**（{c, ħ, M₀} 恰好够定义 M/L/T ⟹ 全是单位）。
所以「缺第二个标度」这句话本身是**症状的名字**，不是病因。病因是：

```text
框架的动力学里**只有一个长度**；而观测世界的质量来自**两个结构上不同的来源**。
```

## 2. 缺口的确切位置（仓库已有）

| 事实 | 出处 |

| 电子：候选式 `m ≡ M₀/2` ⟹ **966 倍**（用 M₀≈0.987 那一版；当前 M₀=0.977 给 956.0） | `verify_electron_neutral_spin.py` / `verify_dirac_electron.py` |

⟹ **缺口不在「少一个数」，在：框架算出来的质量都是 M₀ 的 O(1) 倍，而电子的质量是 M₀ 的 1/1900。**

## 3. 它是怎么出现的（四步）

```text
① 框架是尺度不变的（SC6 已证：现有输出形状原理上给不出标度）。
   ⟹ 它的一切长度都只能是同一个长度的倍数。**对每个固定的结构扇区，解空间是一条「射线」。**

② 钉住那条射线 = 拟合格点一次 = 得到 M₀（等价地 r₀ = ℏc/M₀）。

③ 但电子的质量**不是那条射线上 1×（或 √N×）的点**，而是 ~1/1900 × ——
   它属于**另一条射线**。

④ 框架里没有把两条射线连起来的方程。
   ⟹ **缺口就在这里产生**：不是「数量不够」，是「同一个尺度不变解空间里出现了第二条独立射线，
      而框架没有连接它们的方程」。
```

（「射线」是比喻：指"同一结构扇区下，全体长度只有一个整体尺度自由度"这一点。）

## 4. 为什么必然如此（不是偶然遗漏）

```text
尺度不变的动力学 ⟹ 只能给出「长度之比」（无量纲），给不出长度
⟹ 理论必然长成：一批**无量纲比值** + 若干**待定长度**
⟹ 待定长度的**个数 = 动力学里独立长度的个数**
```

观测世界显示质量至少来自**两种结构上不同的来源**：

| 来源 | 类型 | 标准理论里怎么来的 |
|---|---|---|
| 强作用标度 Λ_QCD（~1 GeV，即我们的 M₀） | **生成型** | 渐近自由 + 维度transmutation：无量纲耦合 α_s + 一个能标 ⟹ 自动生出一个标度 |
| 电弱标度 v（~246 GeV） | **基本型** | Higgs 势里的**基本质量参数**（输入，不由别的生成） |

**一个"生成型"标度与一个"基本型"标度之间的比值，没有任何原理约束它。**
⟹ **「缺第二个」= 观测世界有两个独立质量来源的直接投影。**

## 5. 和标准理论的关系：同一个缺口，两种语言

| | 标准模型 | 本框架 |
|---|---|---|
| 生成型标度 | Λ_QCD（由 α_s 生成） | M₀（拟合格点钉住） |
| 基本型标度 | v = 246 GeV（Higgs 参数，输入） | **无**（W/Z/Higgs 明确记录为无机制） |
| 比值 | **v/Λ_QCD ≈ 250，无人能算** = **层级问题** | **M₀/m_e ≈ 1900（记作 966 的那一版）**，无人能算 |

⟹ **这不是本框架的 bug，是这个问题的本体。** 标准模型的层级问题问「为什么 v 比 Λ 大 250 倍」；
我们问「为什么电子的 r₀ 比胶球的 r₀ 小 ~1900 倍」。**同一个问题。**

另一种同样诚实的读法：缺口 = **框架没有电弱扇区**（W/Z/Higgs 无机制已登记）。这与上面是同一句话，
只是更粗。

## 6. 这个诊断给出什么下一步

**要找的东西不是「第二个标度」（那是症状），是**：一条**能把两条射线连起来的方程**

```text
= 一条**非尺度不变**的动力学（跑动 / 不可逆 / 非线性）
```

仓库自己已经把这个缺口命名过：**ε（闭包缺陷 / 非酉分量）** —— 也就是「耗散」那一格。
所以「耗散」直觉**正是对着这个缺口的**；但（承上轮）它提供的是**非尺度不变性（打开门）**，
不是那个数值本身。

**可判死的判据（写死）**：

> 一条「连接射线」的机制若成立，必须让**至少一个现在手输的无量纲比变成输出**
> （966 / v-M₀ / α 里至少一个），**且不引入新的手输无量纲比**。
> 若它只是把手输从 A 移到 B，则缺口没关（只是搬家）。

### 9.1 对的那一半：「形状当标尺」成立，而且 KdV 精确实现了它

KdV 孤子 `u = (c/2)·sech²( (√c/2)(x−ct) )` 是**精确解**（解析导数代入，残差 ≤ 8.5e−14 机器精度；

```text
振幅 ∝ c ,  宽度 ∝ 1/√c   ⟹   振幅 × 宽度² = 8·acosh(√2)² = 6.214555  （纯数，与 c 无关）
```

⟹ **一个波的形状把它的尺度钉死了。** —— leo 的直觉在这里是对的，而且这是可算的。
**但全部钉在唯一一个自由参数 c 上 ⟹ KdV 只搬运一个标度，不产生第二个。**

### 9.3 真正想要的东西在孤子理论里，但**不在 KdV 里** —— 在「竞争项的平衡」（Derrick）

给麻花环算清（用仓库已有的 `Lk = Tw + Wr`）：

```text
E(L) = F₀·L + (k_t/2)·(2π·Tw)²/L    ⟹  dE/dL = 0  ⟹  L* = 2π·Tw·√(k_t/(2F₀))   ⟹   L* ∝ Tw
```

数值：Tw = 1, 2, 3, 6, 7, 1912 ⟹ `L*/(2π·Tw) = 0.70711`（= √(k_t/(2F₀))）恒为常数
⟹ **一个拓扑计数定出一个长度**。这是「形状当标尺」的精确可算形式。
