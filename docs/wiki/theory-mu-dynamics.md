# μ 动力学（TD 系列）

接行动手册（hushfusion `docs/PATH-ACTION-PLAYBOOK.md`，2026-09-24）第 1–3 步：
把 μ 从**静态参数**升级成**状态变量**，把 GravityControl 的 `flatten` 接进 μ 的演化，
并计算控制顺序的交换子。

## 一、TD1–TD10（PlasmaDynamics）：状态方程

TM1–TM4 一直在问"若 μ 如此，则质量那样"——缺的是 μ 自己的演化方程。最小形式取
**饱和增长**：

```
μ(t+Δt) = μ(t) + η·(1 − μ(t))          η = 单步控制增益
闭式解：μ_n = 1 − (1 − η)^n (1 − μ)     （TD7）
```

三条理由让它成为最小候选（**模型选择**，不是物理定律）：单调不超调（TM1）；
μ=1 是不动点但有限增益下不可达（TD3/TD8）；增量 ∝ 剩余容量，无需人为截断。

| 定理 | 内容 |
|---|---|
| TD1a | μ,η ∈ [0,1] ⟹ 更新后仍在 [0,1]（不超调） |
| TD2 | μ<1 且 η>0 ⟹ 严格推进 |
| TD3 | 0<η<1 ⟹ μ=1 一步不可达 |
| **TD3b** | **η>1 ⟹ 一步越过 1（稳定区边界 = 1）** |
| TD4/TD5 | μ=1 是不动点；η=1 一步到 1 |
| TD7 | 闭式解 μ_n = 1 − (1−η)^n(1−μ) |
| **TD8** | **0<η<1 ⟹ 任意有限步 μ_n < 1（有限步不可达）** |
| TD9 | 轨道单调递增 |
| **TD10** | **μ_n < 1 ⟹ 质量永不归零（TM2b 的动力学版）** |

**两个临界值**（数值扫描 N10）：η = 1 是**无超调**上界（TD3b/TD5）；η = 2 是**收敛**
上界（由 |1−η| < 1 给出）。三段：0 ≤ η ≤ 1 无超调收敛；1 < η < 2 超调但收敛；
η ≥ 2 不收敛/发散。收敛域分析在数值层，Lean 侧形式化的是超调边界（η vs 1）。

## 二、TD11–TD18（MuFieldCoupling）：桥与交换子

新模块 `ProjectionPhysics/MuFieldCoupling.lean`。桥的定义——增益不从天上掉下来，
由**抹平进展**给出：

```
η = flattenProgress A v v₀ = 1 − Q_A(v) / Q_A(v₀)        （TD11）
```

| 定理 | 内容 |
|---|---|
| TD11a/b | 未抹平 ⟹ η=0；已平坦 ⟹ η=1 |
| **TD12** | **抹平一次 ⟹ η = 1（复用 GCA2c，flatten 接入 μ 更新）** |
| TD13 | 起伏越小 ⟹ 进展越大（Q 与 η 反向） |
| TD14a | 先抹平 ⟹ μ 一步到 1（与初值无关） |
| TD15 | 顺序差 = (η_after − η_before)(1 − μ) |
| TD16 | 显式顺序差 = (1−μ)(1−η_before) |
| **TD17** | **不可交换见证：先抹平后更新 μ'=1 vs 先更新后抹平 μ'=0（Fin 2）** |
| **TD18** | **满增益 ⟺ 零代价 ⟺ 区域已平坦** |

**顺序效应的来源**（TD15）：差只来自**增益的差**。增益不读场（常数 η）⟹ 差为零 ⟹ 可交换。
所以非交换性**不是**抹平本身带来的，而是"μ 更新读场"这一**反馈耦合**带来的。

**与 GCA6 是两件事**（别混）：GCA6 说的是两个**抹平**算子部分重叠 ⟹ 不可交换（两个都改场）；
本模块说的是抹平与 **μ 更新**的顺序依赖 ⟺ 反馈耦合。两者都是"不可交换"，来源不同。

## 三、诚实边界

- 状态方程 μ ↦ μ + η(1−μ) 是**模型选择**，不是从物理推出的；
- 把 η **定义**成抹平进展同样是模型选择。它把第二输入缺口从"η 是哪来的"重述为
  **"抹平功率是哪来的"**（TD18）——**缺口位置移动了，缺口本身还在**；
- 全部定理 = 代数恒等 + 序关系 + 有限维见证（真但平凡）；收敛域（η vs 2）在数值层；
- 环流 MHD / 等离子体动理学未建模；无新物理预言。
