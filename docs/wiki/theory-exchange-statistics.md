# 交换回路 ≅ 2π 旋转回路（ES1–ES8）

> **要解决的问题**：VBS 那一轮把统计性**定义**成了闭包相因子
> （`Clos: f(θ+2π) = σ·f(θ)`），并在缺口登记里如实写着「闭包相因子是**定义选择**」。
> 本页把它升级成一条**条件定理**：**交换相因子 = 闭包相因子**。

## 1. 拓扑输入（**标准事实，本页未形式化**——这是唯一的非代数内容）

三维里 N 个全同粒子构型空间的 π₁：

| 空间 | π₁ | 相位（π₁ 的 ℂ* 值角色） |
|---|---|---|
| `C_N(ℝ³)` | `S_N`（对称群） | 角色必过**阿贝尔化** `S_N^ab ≅ Z₂` ⟹ **只能 ±1** |
| `C_N(ℝ²)` | `B_N`（辫群） | `B_N^ab ≅ Z` ⟹ **可 U(1) ⟹ 任意子** |

出处：Fox–Neuwirth 1962（*Math. Scand.* **10**, 119）；Fadell–Neuwirth 1962。
而「交换回路」与「2π 旋转回路」在三维构型空间里落在**同一个**非平凡类：
**交换两个粒子 ⟺ 把其中一个转 2π**（Dirac 皮带诡计 / 弦问题）
—— Fadell 1962（*Duke Math. J.* **29**, 231）；Finkelstein–Rubinstein 1968（*J. Math. Phys.* **9**, 1762：
kink 模型里「半整数自旋可存在 ⟺ 费米统计可存在」）。

## 3. ★★ 「任意子为什么需要二维」的答案（本页核心）

**两个维度用的是同一个方程**：`χ(2) = χ(1)²`（两次交换 = 一次 2π 旋转）。

| | 群 | 2 是什么 | 结果 |
|---|---|---|---|
| 三维 | `S_N^ab ≅ Z₂` | `2 ≡ 0`（阶 2） | `χ(1)² = χ(0) = 1` ⟹ **被迫 ±1** |
| 二维 | `B_N^ab ≅ Z` | `2 ≠ 0` | `χ(2) = χ(1)²` **不构成约束** ⟹ `χ(1)` 自由（U(1)） |

⟹ **同一个方程，只因 2 在群里是否为零，一边给出两个值、一边给出整个圆。**
这就是「任意子只在二维」的干净原因，也把 VSS 那轮「三维排除任意子」的理由
从「旋转群的 π₁ = Z₂」升级成「**构型空间 π₁ 的阿贝尔化 = Z₂**」——
后者同时覆盖**交换**，不只是旋转。

数值：E1 零点只有一个非平凡值（模 2π 去重 2 个点）；E2 `χ(2) − χ(1)²` 最大偏差 **1.6e−16**；
E3 三维可达 2 个 vs 二维整个 U(1)。

## 4. E4 ★★ 提升检验：「2π 旋转非平凡」的严格核

把旋转回路提升到 `SU(2) ≅ S³`（单位四元数），`U(θ) = cos(θ/2)I − i sin(θ/2)σ_k`：

- **2π**：提升从 `+1` 走到 **`−1`** ⟹ 端点距 `+1` = **2.000**（非闭合 ⟹ **不可缩**）
- **4π**：提升回到 **`+1`** ⟹ 端点距 `+1` = **2.4e−16**（闭合）

并且给出 4π 回路的**显式收缩族**：

```text
H(u, φ) = cos φ · (cos u, sin u, 0, 0) + sin φ · (0, 0, 1, 0)     φ ∈ [0, π/2]
φ = 0   → 整个大圆（= 4π 提升，走一遍）
φ = π/2 → 常值 (0,0,1,0)
每个中间 φ 都是**闭曲线**（H(0,φ) = H(2π,φ)）
```

数值：`|q| − 1` 最大偏差 **1.1e−16**；每条曲线闭合性偏差 **2.4e−16**；`φ=π/2` 距常值 **1.2e−16**。
⟹ **4π 可缩（显式同伦），2π 不可缩（端点在同伦下不变，相对基点）。**
这正是「交换 = 2π 旋转」非平凡的严格核。

**本页自纠一处错误**：第一版我写的收缩族是「θ ↦ U(s·θ) 同时缩放 s」——
**那不是回路的同伦**（中间态端点跑到 `−I`，不是闭曲线）。改成上面的纬线族才成立。

## 5. E5 ★★ 皮带诡计：不变量 = 扭转数的奇偶（同一个 Z₂）

模型：皮带的扭转总量 `T ∈ Z`。两个操作——
① 局部分配（**保守**：Σ 不变，数值验证通过）；
② **绕过端点一次**（皮带诡计的标准动作，作为**模型输入**）使 `T → T − 2`。

- `T = 1`（2π 旋转）：可达集合只有**奇数** ⟹ **到不了 0**（不可解）
- `T = 2`（4π 旋转）：可达集合只有**偶数** ⟹ **可归零**（可解）

⟹ 不变量就是**奇偶** = Z₂ —— 与第 2 节三维相位、与 E1 的零点**是同一个群**。

## 6. ★★ 升级：VBS 那条定义现在是条件定理

```text
VBS（原：定义）  Clos:  f(θ + 2π) = σ · f(θ)     「统计性 := 闭包相因子」
ES8（现：定理）  交换回路与 2π 旋转回路同类  ⟹  交换相因子 = 闭包相因子
```

**统一的对象是「构型空间 π₁ 的阿贝尔化」这个 Z₂**：
二维旋转群的 π₁ 是 Z₂、三维构型空间的阿贝尔化也是 Z₂，而交换与 2π 旋转落在**同一个**生成元上
⟹ 两个相位必须相等 ⟹ 「统计性 = 闭包相因子」不再是定义。

## 7. 诚实边界（4 层）

- **① 数学恒等**：ES1–ES7 是 `Z → ℂ*` 角色的一次代数；**ES8 的证明只有一行**
  （`rw [h ℓ₁, h ℓ₂, hc]`）。**全部重量在拓扑输入上。**
- **② 结构对应**：拓扑输入全部是**标准事实**（Fox–Neuwirth / Fadell / Finkelstein–Rubinstein），
  本页只做引用 + 把结论对到仓库的闭包语言上。
- **③ 数值匹配**：E1–E6 全机器精度（验恒等本身）；E4 的四元数提升是标准表示的数值复核。
- **④ 概念重构**：**VBS 的定义 ⟹ 条件定理**（本页唯一的新东西），以及
  「任意子为什么需要二维」从「旋转群 π₁」升级到「构型空间阿贝尔化」。

**缺口登记（不编）**：
1. **拓扑输入本身未形式化**（需要代数拓扑：配置空间、辫群、Fox–Neuwirth 定理）。
   Lean 里用一行假设 `cls : Loop → Fin 2` 把它抽掉——**本模块的作用是让这个输入显式、不可偷渡**，
   不是证明了一条新代数定理。
2. **仍不是完整的自旋-统计定理**：算子那一半（相位 ⟹ 场算符反对易）仍缺，仓库没有场算符语言。
3. 二维「任意子」在本页只到「角色族有自由参数 α」；**α ∉ πZ 的具体见证在数值层**（E2/E3），
   未进 Lean。
4. E5 的「绕过端点使 T → T − 2」是**模型输入**（皮带诡计的标准动作），本页没有从几何推出它。
