# 彭罗斯扭量 × 流动空间（探索）

> leo（2026-08-15）假设：扭量模型可以描述点光子；用扭量描述带质量的
> 电子/正电子——电子和正电子在法向量方向不同，由此产生不同电性；
> 胶子是否也符合扭量（带入不同参数描述单个胶子）。

## 1. 数学内核（`Twistor.lean` TW1–TW5 全证，零 sorry）

```text
TW1 ★ 扭量动量恒等：p = π⊗π̄（rank-1 厄米）的 det = 0 恒成立
    ——扭量构造的动量必然在光锥上（无质量）。这是"扭量天生描述
    无质量粒子"的数学内核，也是"单扭量描述不了电子"的障碍
    （彭罗斯经典结果：有质量粒子需双扭量）
TW2 扭量射影等价：π → sπ 动量只缩放 |s|²（CP³ 射影等价）；
    螺旋度 = CP¹（黎曼球面）
TW3 ★ 电子障碍（诚实判定）：TW1 ⟹ 单扭量动量无质量 ⟹ 电子
    （m ≠ 0）不能由单个扭量描述——需要双扭量扩展
TW4 ★ 电性 = 法向量方向：电荷共轭线性部分 C = iσ₂ 与法向量
    σ₃ = iσ₁σ₂ 反交换 ⟹ C 翻转 σ₃ 本征值（±1 ↔ 电性 ±）
TW5 胶子扭量：无质量（TW1 恒等）+ 色八重态 2³ = 8（Cℓ(6)）
```

## 3. 兼容性判定（诚实 4 层）

| 粒子 | 扭量兼容性 | 判定 |
|---|---|---|
| **光子** | 单扭量 ✓（TW1：动量 det = 0 恒——无质量粒子的自然描述） | 彭罗斯模型成立 |
| **电子/正电子** | 单扭量 ✗（TW1 阻止：det = 0 ⟹ 无质量）——需双扭量 | 经典障碍（诚实） |
| **电性假设** | 独立成立（TW4：电荷共轭翻转法向量 σ₃ 本征值 ±1）——电性是法向量朝向的符号 | ✓ 代数对应（非电性数值来源） |
| **胶子** | 单扭量 ✓（TW5：无质量恒等 + 色八重态 2³ = 8）——胶子参数（无质量/自旋 1/色）全部适合 | ✓ 完全兼容 |

**结论**：扭量与流动框架的兼容点 = **无质量粒子类**（光子/胶子——
两者天然适合单扭量，且与仓库公设一致：光子随空间流动 ⟹ 无质量 ⟹
扭量动量恒等）；**带质量类（电子）是扭量理论的经典障碍**（单扭量
det = 0 恒 ⟹ 必须双扭量/扭曲扭量扩展，未形式化——诚实标注）。用户的
"电子/正电子 = 法向量方向不同 ⟹ 电性不同"有独立的代数内核（TW4：
电荷共轭 C = iσ₂ 翻转 σ₃ 本征值——电性 = 法向量朝向），这是 Cℓ(3)
里可证的结构对应；但电性的数值（e）仍是输入（第二输入缺口）。
