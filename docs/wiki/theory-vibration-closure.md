# 振动闭合（VBC1–VBC5）：从起点开始推

> leo（2026-10-01）起点（原话）：
> 「空间在振动，和一切本身都是振动，这件事情是一致的。你可以把空间的振动和
> 空间以光速运动本身，理解为一种振动的状态。」
>
> 指令：「从这件事上开始推。」

## 0. 起点为什么是「同一句话」而不是两句话

把起点写成相位场就清楚了：

```text
θ(x, t) = 相位场          ——「空间在振动」
θ 以相速度 c 推进（ω = ck）——「空间以光速运动」
```

**「在振动」= 相位在推进；「以光速运动」= 推进的速率是 c。** 两者是同一个对象的
同一件事（相位场 + 它的传播速率），不是两个需要桥接的东西。仓库里这一条本来就有：
MS3「安培 ⟺ C 的波动方程」、MF1「因子分解 ω = ±ck」、N35「无源区 ω/k = c（实测）」。
所以这个起点**不新设公设**——它只是把 SLS1 换一种语言说出来。

## 1. 第一步：相位走过的路径只有两种拓扑

相位沿一条路径推进。路径的拓扑只有两种，这不是附加假设，是路径本身的性质：

| 模式 | 相位的走向 | 后果 |
|---|---|---|
| **开放路径** | 单调推进，永不回到自身 | 不存在任何相因子 σ（`IsOpen`） |
| **闭合回路** | 必须回到自身 | 存在闭包相因子 σ（`ClosureFactor`，VBS 的定义） |

形式化（Lean `Explorations/VibrationClosure.lean`）：

```text
noncomputable def phaseAdvance (Δ : ℝ) : ℂ := Complex.exp (Δ * I)
def IsOpen (f : ℝ → ℂ) : Prop := ¬ ∃ σ : ℂ, ClosureFactor f σ      -- 复用 VBS 的 ClosureFactor
```

## 2. ★★ VBC1：闭合 ⟹ 整数（「绕数必须整数化」不是公设）

```text
theorem winding_index_integer (Δ : ℝ) (h : phaseAdvance Δ = 1) :
    ∃ n : ℤ, Δ = n * (2 * Real.pi)
```

**读法**：若相位走满一周后复值回到 1（相位闭合），则推进量必然是 2π 的整数倍。
这是**相位单值性的直接后果**（拓扑学标准事实：S¹ → S¹ 的映射度是整数），
不是一条可以选择的公设。

⟹ **缺口 C 的「整数那一半」在此闭合。** 上一轮（VBS 轮）把「绕数为什么整数化」列为
开放缺口；本轮把它推出来了。

数值（`verify_vibration_closure.py` C3）：
- 1000 条闭合路径（n ∈ [−5,5]）：max\|∮dθ/(2π) − n\| = **0.0**（机器精度）
- 1000 条开放路径（均匀连续）：落在整数上的比例 = **0.0**
⟹ 「整数」不是普遍的，是**闭合的特权**。

## 3. ★ VBC3：三分 —— 开放 / 玻色型 / 费米型

```text
theorem phase_itself_is_open : IsOpen (fun θ : ℝ => (θ : ℂ))     -- 见证：θ ↦ θ 是开放的
theorem open_not_bosonic  : IsOpen f → ¬ IsBosonicF f
theorem open_not_fermionic : IsOpen f → ¬ IsFermionicF f
theorem open_excludes_closed : IsOpen f → ¬ ClosureFactor f σ
```

三类**互斥**，且各有见证（开放模 = 相位本身；+1 与 −1 的见证见 VBS7 的半角/全角螺旋）。
⟹ 「光子 / 玻色子 / 费米子」在框架内是**同一个相位场拓扑模式的三个取值**：
开放（无闭包）／闭包 +1／闭包 −1（σ 取一般值则是任意子，见 VBS 与 C2 数值）。

数值 C1：开放模 f(θ) = θ 的比值 f(θ+2π)/f(θ) 均值 3.45、**标准差 5.14**——
若存在常数 σ 该标准差应为 0。

## 4. ★★ VBC4 / VBC5：闭合 ⟹ 时间

```text
theorem clos_translate (h : ClosureFactor f σ) :
    ∀ n : ℕ, ∀ θ, f (θ + n·(2π)) = σⁿ · f θ            -- 每走一个 2π 就乘一个 σ
theorem clos_periodic_of_root (h : ClosureFactor f σ) (hσ : σⁿ = 1) :
    ∀ θ, f (θ + n·(2π)) = f θ                            -- σⁿ=1 ⟹ 有周期
```

**读法**：
- `n` = **闭合次数**；`clos_translate` 说每一步乘以 σ，即**每一次闭合 = 一个时间单位**。
- `σⁿ = 1` 时出现周期 ⟹ **有内部时钟 ⟹ 有时间**。
- 开放模没有闭合 ⟹ 没有周期 ⟹ **没有时间**（这就是光子 dτ = 0）。
- VBS2（费米型 4π 复原）是本定理 **n = 2、σ = −1** 的特例——被吸收成一条推论。

⟹ 这条与仓库既有的 `Archive/HiddenEventClocks.lean`（「每个非零质量事件追加一个离散
涌现时间单位」）**是同一件事**：那里的「质量事件」就是这里的「一次闭合」。
本定理给它一个相位场的来源。

数值 C4：n = 0..10 的 `f(θ+n·2π) = σⁿ f(θ)` max 误差 **4.9e−15**。

## 5. 这一步带来的公设压缩（本轮最实在的收益）

两条原本独立的公设，成为**同一相位场两种拓扑模式**的区分：

| 仓库原有公设 | 振动语言下的身份 |
|---|---|
| SLS2 光子 = 完全随空间运动（dτ = 0） | **开放模**：相位不闭合 ⟹ 无周期 ⟹ 无固有时 |
| MC1 质量 = 内部运动（自旋）对空间运动的锚定 | **闭合模**：相位闭合 ⟹ 有周期 ⟹ 有固有时 |
| SM3c 质量 ⟹ 偏离空间流动（dx ≠ c·dt） | 同上（闭合模的平动分量） |
| QFT1/QFT2 激发 = 偏离空间流动 | 同上 |

这不是新预言，是**结构压缩**：四条陈述塌缩成「同一个相位场的开放/闭合二选一」。

## 6. ❌ 撤回：上一轮的「等速 ⟹ 2πr = λ」猜想不成立

上一轮（VBS 轮 §8）我提出过一条猜想：**「若三方向分量等速，则 2πr = λ ⟹ ħ = h/2π」**。
本轮必须撤回它，因为它的中间步骤是错的：

- 该猜想用的是**欧氏分解** `w² + v² = c²`（切向 + 轴向 = 总速度 c）。
- 但欧氏分解与相对论速度合成**不相容**：取等速情形 w = v = c/√2，则
  **顶部 rim 点的经典合成速度 = w + v = √2·c ≈ 1.414c > c**。
- 数值（C5）：`顶部 rim 点经典合成速度 = 1.4142`，`是否超过 c = True`。

**修正版（可用的相对论陈述）**：把输入换成一个干净的量——

```text
输入：螺旋半径 r = ƛ（约化康普顿波长）= ħ/(m c)
⟹ 静止时：ω₀ = c/r ⟹ ħω₀ = m c²            （数值 1.000000000，精确）
⟹ 运动时：内部频率 ω = ω₀/γ ⟹ 时间膨胀自动出现（β=0.6 ⟹ 1/γ = 0.8 = √(1−β²)）
```

⟹ 于是 ħ 的「几何比例层」从「r = λ/2π 这个几何选择」**收缩成一句话：`r = ƛ`**
（螺旋半径 = 约化康普顿波长）。**2026-10-01 更正**：这不是「与 966× 同一张脸」——
ħ 的数值是**单位类**（可溶解：SI 1.0546e−34 / 自然单位 1 / 普朗克单位 1 是同一个 ħ），
966× = M₀/(2m_e) 才是**比值类**（真缺口）。见 [theory-scale-accounting.md](./theory-scale-accounting.md)。
这是负面结果换来的正向收益：猜想的形状被替换成一个更干净、且与相对论相容的陈述。

## 7. 诚实边界（4 层）

- **① 数学恒等**：VBC1 是拓扑学标准事实（S¹ → S¹ 映射度为整数，`Complex.exp_eq_one_iff`）；
  VBC2/VBC3 是定义的直接推论；VBC4 是 `σⁿ` 的归纳；VBC5 是 VBC4 的代入。全部真但平凡。
- **② 结构对应**：`IsOpen` 的定义把「光子无固有时」翻译成「相位不闭合」——
  这是**语言重写**（SLS2/SM1 的振动版），不是新推导。
- **③ 数值匹配**：C1–C4 全机器精度（0.0 ~ 5e−15），验的是恒等本身；
  C5 是真实常数代入（ħ、m_e、c）。
- **④ 概念重构（本轮贡献）**：**公设压缩**（SLS2 + MC1 + SM3c + QFT1/2 四条的振动重述）
  + **「闭合 ⟹ 整数」把缺口 C 的整数那一半关掉** + **时间 = 闭合次数**（与
  `Archive/HiddenEventClocks` 合流）。**无新可检验预言**。
- **缺口登记（不编）**：
  1. **单值性只给「n 是整数」，不给「量子单位是 ħ」。** 从闭合推不出 `相位 = 作用量/ħ`
     （即 ∮p dq = n ħ 里的那个 ħ）——那一跳仍是输入。
  2. **σ 为何只取 ±1**（缺口 A）——本轮没动；VBS 的三分只给出「开放 / +1 / −1 三选一」，
     没给出「为什么自然界只实现这两个闭包值」。
  3. **所有标度类缺口**（966× / e / M₀ / ρ·α·k·κ·ν）——振动语言无量纲化后只剩比例，
     对这些**毫无用处**（除非走 HQ11 的分形自生成率 g）。
  4. `r = ƛ` 里那个 ƛ 的**数值**仍来自 m（即仍与质量标度同源）。
