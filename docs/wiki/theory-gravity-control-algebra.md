# 控制引力场的代数系统：基元 = 起伏能量（二次型）

## 问题

leo（2026-09-17）："如果有布尔代数，能不能根据现在推导出的物理学，设计一种控制
引力场的代数系统？需要 AI 做的不是怎么做出来，而是**怎么解释、怎么使用**——基本
逻辑根据数学的什么量化属性来定义。"

## 答案（一句话）

能，但真正的对象**不是**布尔代数。控制逻辑的基元是**起伏能量**——一个非负二次型
`Q_A(v) = Σ_{i∈A}(v_i − v̄_A)²`——不是真值。布尔代数只是它的一个特例（控制区域
层状时的可交换子格）。

## 为什么基元是起伏能量（四条判据同时命中）

引力在此框架里不是实体，是空间场的泛函：Φ = ½v²（SG11 已证），引力加速度 = −∇Φ。
所以"控制引力"≡"控制流动的梯度结构"。一个逻辑基元必须满足四件事，仓库里只有
**起伏能量**同时满足：

1. **可观测量**：Q_A 是一个标量，有限次测量可定（不是抽象真值）。
2. **幂等可判定**：抹平两次 = 抹平一次（GCA1，P²=P）⟹ 可作开关，不是能量泵。
3. **二值退化**：Q_A = 0 ⟺ A 内流动常值 ⟺ A 内 ∇Φ = 0 ⟺ **引力关闭**（GCA2）。
4. **代价共轭**：抹平成本 ∝ 被拿走的起伏²（AMC3 的 κg²/2）——基元量本身就是代价
   （GCA7）。布尔真值没有权重，这里有。

## 从"量化属性"到"计算"的推导链

```
二次型 Q_A（GCA2）
  → 极化恒等式 ⟨u,v⟩_A = ½(Q_A(u+v) − Q_A(u) − Q_A(v))（GCA3）
  → 内积 ⟹ 正交（两个控制互不干扰 = 内积为 0）（GCA4）
  → 正交投影族 = 逻辑（P_A, I−P_A 构成互补投影对，GCA5，复用 PA2）
  → 格运算：∧ = 复合、∨ = P+Q−P∘Q（可交换时）、¬ = 正交补（**不是**集合补）
  → 布尔代数 = 全部投影可交换的子格（GCA6）
```

补元的关键澄清：投影格的补是**正交补** I−P（同一区域内"被保留的部分"），不是
"在区域外做相反控制"。所以"取消一个抹平操作"≠"制造反向引力"——与仓库哲学一致：
反引力是抹平偏差（归零），不是制造反向引力。

## 布尔性的边界（GCA6，本轮被数值检查修正过一次）

**可交换 ⟺ 控制区域族是层状的（laminar：两两不交，或一个包含另一个）。**

- **GCA6a 不交 ⟹ 可交换**：P_A、P_B 各自只动自己区域，互不干涉。
- **GCA6b 嵌套 ⟹ 可交换（吸收律）**：B ⊆ A ⟹ P_A∘P_B = P_B∘P_A = P_A——小区
  控制被大区控制**吸收**。`flatten_absorb_of_subset` 给出算子形式。
- **GCA6c 部分重叠 ⟹ 不可交换**：A={0,1}、B={1,2} 时先抹 A 再抹 B 得 [0.5, 0.5, 0]，
  先抹 B 再抹 A 得 [0.5, 0.25, 0.25]——施加次序改变最终引力分布（可测顺序效应）。

**修正记录**：最初写下"真包含 ⟹ 不可交换"，数值扫描（N6）立刻推翻——嵌套的两个
抹平算子是可交换的（吸收律）。正确刻画是层状（不交或嵌套）。这条修正同时改掉了
Lean 里的一处伪定理。

工程含义：**控制区域层状 ⟹ 控制程序可像布尔式一样化简、综合、验证；区域部分重叠
⟹ 控制词变成有序词，执行次序进入语义，必须按序执行并逐步验证。** 这不是事后检查，
是装置几何的设计原则。

## 与仓库已有"锁定定理"的重新解释

FC5（S* 与 τ_E 必须同比例放大）、FC10（Θ=B²/m_eff 唯一不变量）、TM2（μ≠1 必有正
质量）这些分散的"不能独立调"结论，是同一个代数事实的多个指纹：**相应的控制通道
不可交换**。锁定 = 交换子不为零。把它们从"一条条经验禁忌"提升成"控制代数里的一
条结构定理"是这个视角的收获。
