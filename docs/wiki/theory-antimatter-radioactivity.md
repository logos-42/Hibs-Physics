# 反物质与放射性（AM1–AM5）

> leo（2026-11-02）：「有没有方法根据这个算式算出反物质？或者放射性的根源」

## 1. 反物质：能算，而且很干净

框架公设：**电荷 = 流的散度**（正电=发散、负电=汇聚）、**质量 ∝ 流速平方**。
于是定义「流动反向」`C ↦ −C`：

| 编号 | 定理 | 内容 |
|---|---|---|
| **AM1** ★★★ | `charge_neg` | 散度线性 ⟹ **反向 ⟹ 电荷变号** |
| **AM2** ★★★ | `mass_neg` | `(−c)² = c²` ⟹ **反向不改质量** |
| **AM3** | `reversal_involution` | 反向两次回原状（反粒子的反粒子 = 粒子） |

**⟹ 反粒子 = 流动反向的同一团物质。同质量、反电荷。**

这不是凑的：电荷是散度（奇），质量是流速平方（偶），一奇一偶自动给出这个结构。

## 2. 但立刻撞墙：C 对称 ⟹ 净电荷为零（AM4）

**`net_charge_zero_of_C_symmetric`**：若一个系综在反向变换下封闭（每个构型都有其反向），
则**总电荷严格为零**（证明：反向是双射且电荷变号 ⟹ `Σq = −Σq`）。

⟹ **只要动力学不破缺 C，物质与反物质必然等量。**

宇宙里没有反物质。所以：**框架必须有一个 C 破缺机制，而它一个都没有。**

这条不是遗憾，是判决：它把「框架缺什么」从形容词变成了一条可核对的陈述
——缺的不是"更多计算"，是**一个破缺 C 的机制**。

## 3. 放射性：有方向，没有速率

| 问题 | 框架能说 | 框架不能说 |
|---|---|---|
| 为什么衰变 | 重核可通过"重排条数"降低总质量 ⟹ 不稳定（**方向**） | **速率**、半衰期、分支比 |
| α 衰变 | 无 | Gamow 因子需波函数穿透，框架只有运动学恒等式 |
| β 衰变 | **结构上不允许**（见下） | — |

**β 衰变为什么结构上不允许**：它本质是**同时破缺 C 与 P** 的过程（最大破坏，只耦合左手）。
而 AM4 证明本框架的构型空间是 **C 对称**的 ⟹ 无法表达这类过程。

## 4. 两件事不能同时要

要 β 衰变 ⟹ 必须加手征 ⟹ 手征必然破缺 C ⟹ **AM4 的前提被毁** ⟹
「反粒子 = 流动反向」这条干净结论也没了。

> **要么保留"反粒子=流动反向"（那就没有 β 衰变、没有放射性、没有我们存在），
> 要么加手征补弱力（那反物质就不再是干净的流动反向）。**

这是本批工作里最硬的一次二选一。


## 5.5 α / γ / 自发裂变：C 守恒的三条道（`Explorations/DecayChannels.lean`，DC1–DC5）

AM4 只禁 **β**（弱、破缺 C）。**α / γ / 自发裂变都是 C 守恒的**，在干净设置里能存在。
本模块只做框架真能推出来的部分：

| 编号 | 定理 | 内容 |
|---|---|---|
| **DC1** ★★★ | `alpha_threshold` | **α 发射阈值**：Q > 0 ⟺ √Nᵢ > √N_f + √N_α |
| **DC1b** ★★★ | `alpha_threshold_stronger` | **√N 律让衰变更难**：等价于 `Nᵢ > N_f + N_α + 2√(N_f·N_α)` —— 多出的量必须超过**两倍几何平均**；而加性律（m = N·M₀）只要 `Nᵢ > N_f + N_α`（`additive_threshold`）。⟹ **两条质量律的可分辨差别** |
| **DC2** ★★★ | `geiger_nuttall_slope` | **Geiger–Nuttall 斜率与前置因子无关**：λ₁/λ₂ = exp(−C/√E₁ + C/√E₂)，**ω 完全消掉** ⟹ 前置因子算错 1500 倍**只影响截距** |
| **DC3** ★★★ | `barrier_C_invariant` | **反物质核寿命相同**：势垒 ∝ q₁q₂，反向下两电荷同时变号 ⟹ 乘积不变 ⟹ 隧穿概率不变 |
| DC4 | `fission_uses_same_threshold` | 自发裂变与 α **结构相同**，只是碎片条数换成两个 |

### 推不出的（写死）

1. **绝对速率**：需要 ω 的数值来源。框架只给 `M₀/ħ ≈ 1.5×10²⁴ s⁻¹`，核能级间距给 `≈1.5×10²¹ s⁻¹` ⟹ **差 1.5×10³ 倍**（缺 ~1 MeV 的核尺度）。DC2 证明这个误差**只进截距，不进斜率**。
2. **γ 速率**：爱因斯坦 A 系数 ∝ ω³|d|²，`ω³` 来自**场量子化的相空间**；框架没有场的量子化 ⟹ γ 只能给**选择定则**，给不出速率。
3. **势垒归一化**：Gamow 指数里的 `∫√(V−E)dr` 需要把"力"积成"势"并按 WKB 积分 —— 那是**外部输入**。

### 一句话判决

**α 和自发裂变：阈值可推、速率不可推；γ：只有选择定则；β：结构禁止。**

## 5. 结论

- **反物质**：有对称性（同质量、反电荷），**没有不对称性**（AM4 是定理级否决）。
- **放射性**：有**方向**，没有**速率**；β 衰变是**结构不允许**，不是"还没做"。
- 与实测的对照：反粒子质量 = 粒子质量（正电子 1e-9 内 ✓）——这条框架说对了，
  但它说的是**任何** C 对称理论都会说的话，不构成支持。
