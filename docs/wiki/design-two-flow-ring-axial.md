# 轴向分离双流环：把中性面从导体上搬进空间

## 0. 这一页是什么：一个**目标**，不是又一轮笔记

`design-two-flow-ring.md` §10.6.1 的结论是：**共面布置下，场变号点恰好落在内环半径上**
（点丝模型在环上有近场奇异性；单个环的共面轴向场跨过自己的导线就变号）⟹ 中性面**贴在导体上**，
不是真场反位形。leo（2026-10-02）：「一开始按照新的结论往下继续走，**开始把这个当作是一个目标**。」

⟹ 本页把这个目标写成**可算、可验收**的东西：**让中性面悬在空间里**。

## 1. 判据（解析）

单环半径 a、轴向偏置 z₀，对原点的轴上场 `B_z = μ₀Ia²/(2(a²+z₀²)^{3/2})`。
两环分置 z = ∓d/2（外环 Cu 在 −d/2 为正电流、内环 H 在 +d/2 为 −λI），要求**原点为零场**：

```text
f(a,d) := a² / (a² + (d/2)²)^{3/2}
**f(R_Cu, d) = λ · f(R_H, d)**          ⟹  λ(d) = f(R_Cu,d) / f(R_H,d)
```

两个极限（都是**可对位的既有结论**）：

| 极限 | λ | 意义 |
|---|---|---|
| d → 0 | **R_H/R_Cu = 0.58333…** | **共面判据正是本判据的特例**（数值 A1 逐位一致） |
| d → ∞ | **(R_Cu/R_H)² = 2.93878** | **分离距离有上限**：λ ≥ 2.94 时原点永远不是零点 |

⟹ **d 与 λ 一对一锁定**：装置选定 λ 后，分离距离**没有自由度**（反之亦然）。
设计参数从"两个（d, λ）"降成"**一个**"。

## 2. 设计点（示例：λ = 1.5）

```text
d*        = 1.090526 m       （反解 f(R_Cu,d) = 1.5·f(R_H,d)，代回 B_z(0) = 0 精确）
离最近导体 = sqrt(R_H² + (d*/2)²) = 0.6479 m     （共面时 0.35 m ⟹ 拉开 +0.26 m）
容差      = |Δλ/λ| < 5%  才能让原点场残差 < 1% 特征场（斜率恒 0.405 ⟹ 线性）
```

零点离最近导体 0.65 m —— **悬在空间里了**。轴上剖面（`fig_axial_null.png` 右图）：
场在 z<0 为正、跨过原点整片变负（粉区），**变号就发生在空间中的原点上**，不在任何导体上。

## 3. 死法（写死，可判）

| 死法 | 判据 | 现状 |
|---|---|---|
| λ 出窗口 | λ ∉ [0.58333, 2.93878) | 数值 A2 已验（单调、趋向极限） |
| **λ 漂移** | d 固定时，`|B_z(0)|/B_scale` 随 ‖Δλ/λ‖ **线性**增长；要残差 < 1% 需 ‖Δλ/λ‖ < 5% | 数值 A7 已验（斜率 0.405 恒定） |
| 细丝模型失效 | 环有厚度时 `f(a,d)` 要换成有限截面解 | **未做**（见 §5） |

## 4. 与共面版的关系（为什么这不是"推翻"，是"包含"）

```text
共面版：d = 0        λ = 0.58333    中性面在导体上     ← 上一轮的结论
轴向版：d = 1.0905   λ = 1.5        中性面悬空         ← 本页目标
        ─────── 同一判据的两个取值，d→0 逐位复现共面判据（A1）
```

⟹ **上一轮的"不行"是这条曲线在 d=0 端的取值，不是判据被否。** 两个结论不冲突：
一个说"共面不行"，一个说"要分开多少、电流比配多少才行"。

## 5. 诚实边界

- **细丝模型**：判据用点丝环（标准电磁学）。真实环有径向与轴向厚度，会把近场抹平 ⟹
  d 很小时（零点离导体 < 环厚度量级）判据要换成有限截面解。本页给的是**细丝口径**下的精确判据。
- **"离最近导体 0.6479 m" 是从环中心线量的**（未减环半厚）。
- 场仍是标准电磁学（**结构对应层**）；本框架要求的两条（PA3 线性叠加、DR2b 反向抵消）在共面版已验，
  本页沿用同一场模型。
- **不含任何 μ 的主动产生**（仍是档 3 第二输入缺口）；**无新物理预言**。
- **装置级几何（缺口 #1）仍未覆盖**：d\\* = 1.09 m 只说了两环沿轴的相对位置，
  绝对 z 包络、端部结构、真空腔、RMF 线圈如何与两个流环并存 —— 都还没做。
- 容差 5% 是**单口径**结果（λ 标定误差），不含其它误差源（几何公差、流的不均匀）。

## 7. 三步已完成（2026-10-02，`scripts/verify_two_flow_ring_axial_env.py`，**11/11 通过**）

| 步 | 结论 | 数字 |
|---|---|---|
| ③ **有限截面修正** | 点丝口径**够用**，并给出它失效的尺度 | d* 1.090526 → **1.092326 m**（**+0.17%**）；同一 d 下 λ 差 0.13% |
| ① **零场面** | 必须分**两类**；反向区在轴端**被导体封闭** | **干净分支 470 点**（过原点）/ **导体邻近伪影 70 点**；到导体**表面**净空 **0.0623 m**（到中心线 0.0945 m）；z ∈ [−1.202, **+1.600**] m |
| ② **装置包络** | 四条硬界**同时**满足，且与共面版可比 | L = 1.460 m、B = 5.88 T < FC12 6.686 T；R+截面 0.630 ≤ PF7 1.817 m 且 ≤ L/κ 0.730 m；t = 0.10 m < t_max 0.202 m |

- **③ 的意义**：截面把近场抹平 ⟹ 所需分离距离略增、所需 λ 略降，**修正量 0.17% 量级**
  ⟹ 本尺度下点丝判据可以当工程判据用（失效尺度 = 截面尺寸 ∼ d，未算）。
- **① 的意义**：**干净分支两端接入导体** ⟹ 反向区不是自由空间里闭合的曲面，而是**在轴端由导体封闭**；
  零点面对轴**不对称**（−1.202 vs +1.600，因两环半径不同）——这会直接影响端部设计。
- **② 的意义**：**不是靠放大装置换来的**（L 1.46 / B 5.88 对照共面版 L 1.4 / B 6.0）。

**本轮口径**（均为**工程口径**，非上游物理结果）：截面半宽 0.03 m、环厚 0.10 m、
端部余量 0.30 m、径向余量 0.20 m。改口径请一并改脚本与 `artifacts/twoflowring_axial_env/report.json`。
