# 胶球构造学：胶球能否构造其他粒子

## 1. 问题（leo，2026-08-13）

1. 胶子有没有其他性质？
2. 胶球的构造能否构造其他粒子——玻色子、费米子、夸克？

## 2. 结论（诚实分层）

| # | 断言 | 判定 |
|---|---|---|
| 1 | 纯胶球不能构造费米子（夸克/轻子） | **✗ 硬约束**：自旋统计定理，无例外 |
| 2 | 胶球能混合已知玻色子（f₀/f₂/η 介子） | **✓ 真实唯象学**：格点+实验支持 |
| 3 | 胶子(s=1)+旋量流(s=1/2) 代数上可给费米子 | **✓/✗**：1⊗1/2=1/2⊕3/2 可行，机制/数值缺失 |
| 4 | Cℓ(6) 旋量 8 维 = 色八重态；3⊗3=8⊕1 | **★ 新代数观察**（值得继续） |
| 5 | SU(3)⊃SU(2)：λ₁λ₂λ₃ 生成 SU(2)，3→2⊕1 | **★ 结构桥**：三方向↔弱同位旋↔三色 |
| 6 | W/Z/Higgs 量级（80/125 GeV） | **✗ 无机制**：1.7 GeV vs 80/125 GeV 不可跨越 |

## 3. 核心论证

### 3.1 自旋-统计硬约束（为什么胶球是玻色子）

三胶子（自旋 1）的组合角动量：

```
1⊗1 = {0,1,2}（全部整数）
1⊗1⊗1 = {0,1,2,3}（全部整数）
```

⟹ 纯胶球 J^PC ∈ {0++, 2++, 0-+, 1-+, 2-+, 3++...}，**永远是玻色子**。胶球不可能直接构造费米子——这不是模型选择，是物理定理（任何纯玻色子组合的角动量为整数）。

### 3.2 费米子的唯一代数来源 = 旋量

```
胶子⊗旋量: 1⊗1/2 = {1/2, 3/2}  ← 半整数出现
```

用户框架的 σψ 旋量流（MinimalCore.lean MC1）正是 s=1/2 对象。"胶子+旋量流 → 夸克"在代数上可行（s=1/2 输出），但机制和数值缺失（与 966 倍缺口同源），不能算构造成功。

### 3.3 ★ Cℓ(6) 旋量 = 色八重态（新代数观察）

```
dim Cℓ(n) = 2ⁿ;  复旋量空间 = 2^(n/2) 维（n 偶数）
Cℓ(2): 旋量 2 维;  Cℓ(4): 4 维;  Cℓ(6): 8 维;  Cℓ(8): 16 维
```

**Cℓ(6) 的旋量空间 = 8 维复 = 胶子色八重态的维度（8 个胶子）**。三方向三重化（(σ₁,σ₂,σ₃)×2 = 6 生成元）→ Cℓ(6) → 8 维旋量。代数恒等式 Cℓ(3)⊗Cℓ(3) ≅ Cℓ(6)。配合色组合 **3⊗3 = 8⊕1**：8 = 胶子（伴随表示），1 = 胶球（色单态）——"三方向升维到色空间"的自然通道。

### 3.4 SU(3) ⊃ SU(2) 分解（三方向↔三色结构桥）

- Gell-Mann λ₁,λ₂,λ₃ 满足 [λ₁,λ₂]=2iλ₃ ⟹ 生成 SU(2) 子代数——三方向 (σ₁,σ₂,σ₃) 在色空间有精确对应
- λ₃ 特征值 {1,−1,0} ⟹ 色三重态 3 → 2⊕1（前两色=弱二重态，第三色=单态；与弱同位旋结构一致）
- 伴随表示分支：8 → 3⊕2⊕2⊕1（标准分支规则）
- 色单态 (1,1,1) 不是 SU(3) 本征态（λ₈·(1,1,1) = (1,1,−2)/√3）——是 **C₃ 置换不变量**（GlueballBridge 已证），与格点"色单态=纠缠平均"一致
- 超荷方向 λ₈ 特征向量 (1,1,−2)：电荷量化 (U(1)_Y) 的来源

### 3.5 C₃ 色循环特征值

循环置换矩阵特征值 = (1, ω, ω²)，ω=e^{2πi/3}；**1+ω+ω²=0** = 色单态条件 Σcᵢ=0 的代数根源。(1,1,1) 是置换不变（特征值 1）方向 = 用户框架色单态。

### 3.6 胶球与已知玻色子的混合（真实唯象学）

| 胶球态 | 已知对应 | 混合对象 |
|---|---|---|
| 0++ | f₀(1710)/f₀(1500) | 标量介子（已有 G4 Higgs 门户机制） |
| 2++ | f₂(2340)/f₂(1950) | 张量介子（格点支持 2++ 次轻） |
| 0-+ | η(1405)/η(1475) | 赝标量介子（格点第三轻） |
| 1-+ | π₁(1600)? | 奇异量子数候选（格点预言） |

"胶球构造介子" = **混合**（胶球态与 qq̄ 介子态混合），不是从胶球长出夸克。

## 5. 诚实边界

1. 自旋统计是硬约束：任何"胶球构造费米子"的声称必须引入旋量自由度（半整数自旋），纯胶球做不到
2. Cℓ(6) 8 维旋量是**维度巧合或结构**尚未判定——需要证明"三方向三重化"有物理意义，而不只是数字 8=8
3. 3→2⊕1 是标准分支规则，不是新物理——结构桥成立，但没有新预言
4. 弱玻色子/Higgs 量级差异（1.7 vs 80/125 GeV）无机制，不能声称构造了 W/Z/Higgs
5. "胶球混合介子"是格点+唯象学已知内容；用户框架贡献的是用 C₃/SU(3) 矩阵实现色结构（已有 Lean），非新预言
