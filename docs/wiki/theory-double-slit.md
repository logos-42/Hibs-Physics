# 双缝 = 空间螺旋谐波的干涉（波粒二象性重释，探索）

> 观察哪条缝 = 对空间运动谐波的压缩（去掉板子到光源之间的空间谐波

## 1. 数学内核（`DoubleSlit.lean` DS1–DS4 全证，零 sorry）

```text
DS1 空间螺旋运动的平面结构 = 谐波：
    螺旋（平面圆周 + 法向传播）的 xy 投影是圆（cos²+sin² = 1），
    截面投影 x(z) = R cos(ωt) 是谐波——"平面的波纹"的严格说明
    （三方向流动的平面圆周分量 = 空间螺旋运动的来源）
DS2 ★ 干涉恒等式：cos α + cos β = 2cos((α+β)/2)·cos((α−β)/2)
    ——两列谐波叠加 = 调制的条纹（波纹产生干涉的代数根源）
DS3 双缝强度恒等：4cos²δ = 2(1 + cos 2δ)
    ——条纹 = cos² 调制（明暗相间）的代数内核
DS4 ★ 观察 = 相干丧失：|z₁+z₂|² = |z₁|² + |z₂|² + 2Re(z₁·z̄₂)
    ——交叉项 2cos(Δφ) 是干涉来源；相位随机化 ⟹ 交叉项消失
    ⟹ 无干涉（两道条纹）——"压缩空间谐波" = 退相干
```

## 3. 诚实 4 层判定

| 层 | 判定 | 理由 |
|---|---|---|
| ① 数学恒等 | 真但已知 | 螺旋投影/叠加恒等/退相干 = 标准波动光学的代数（不依赖"空间谐波"的物理地位） |
| ② 结构对应 | 已知物理 | 双缝干涉、路径观测破坏干涉（退相干）都是实验事实的数学描述 |
| ③ 数值匹配 | — | 与标准双缝公式一致（恒等层无新数值） |
| ④ 概念重构 | 不可证伪 | "波粒二象性不存在"：波 = 空间螺旋投影（DS1），粒子 = 谐波压缩（DS4）——同一空间结构的两种观测姿态；谐波获得几何来源（螺旋投影） |

**结论**：数学上**可以证明**三件事——① 空间螺旋运动的平面投影是谐波
（波纹有几何来源，DS1）② 谐波叠加自然产生干涉条纹（DS2/DS3）
③ 观察（相位相干丧失）必然产生两道条纹（DS4）。这三件构成"双缝 =
空间谐波干涉"的自洽数学描述。但这是解释层重构：**数学内核与标准波动
光学/退相干完全同构**，无新物理预言；"波粒二象性不存在"是概念叙事
（两种观测姿态），不是可检验的新定律。
