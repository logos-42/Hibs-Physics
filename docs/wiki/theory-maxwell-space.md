# 电磁 = 空间场的运动学（全新形式推导，探索）

> leo（2026-08-14）：麦克斯韦方程规定了电磁效应，把空间运行纳入——

## 1. 核心结构（本页的数学内容）

**标准麦克斯韦**：E、B 两个独立场 + 两条独立演化定律（法拉第/安培）。

**本框架（全新推导）**：

```text
唯一独立动力学场 = 空间场 C（满足波动方程）
电磁场是 C 的运动学派生：
  E = −∂_t C   （电场 = 空间场的时间变化）
  B = ∂_x C    （磁场 = 空间场的空间梯度；3D 中 B = ∇×C 自动无散）

检验（MaxwellSpace.lean MS1–MS5 全证）：
  MS1  差分交换：∂_t∂_x C = ∂_x∂_t C
  MS2  ★ 法拉第定律自动成立：∂_tB = −∂_xE（恒等，非独立定律）
  MS3  ★ 安培-麦克斯韦 ⟺ C 的波动方程：∂_tE = −c²∂_xB ⟺ ∂_t²C = c²∂_x²C
  MS4  电磁场 = 空间场运动学（定义定理）
  MS5  ★ 源（电荷/电流）⟺ C 方程驱动项：∂_t²C = c²∂_x²C + J（互相影响）

⟹ 麦克斯韦方程组的独立内容 = 空间场 C 的波动方程；E、B 是表观形态。
```

**麦克斯韦尺度之上的内容**：C = 电磁矢量势 A，但仓库 SLS1（|C| = c 普适）
给 C 物理意义 ⟹ **规范自由度被物理条件固定——仓库假设消灭规范冗余**。

## 3. 三场地位与互相影响

| 场 | 地位 | 动力学 |
|---|---|---|
| C（空间场） | 唯一独立场 | 波动方程（MS3）；被源驱动（MS5） |
| E（电场） | C 的时间变化 | 无独立动力学（派生） |
| B（磁场） | C 的空间梯度 | 无独立动力学（派生） |

互相影响：源（电荷）⟹ C 方程非齐次（MS5）——电荷不是场外"子弹"，
是空间场方程本身的驱动项；C 的波动 ⟹ E、B 的表观演化（法拉第/安培
"自动成立"）。
