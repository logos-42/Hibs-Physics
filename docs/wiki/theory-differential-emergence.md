# 理论概念：导数、斜率、散度与旋度（隐数空间）

> 2026-08-04 会话问答编译（compile-first）。问题：草案里有没有斜率/旋度？散度推导出来了吗？导数在隐数空间意味着什么？
> 核心结论：**当前理论里没有任何微积分对象**——公理只有离散代数（⊕、⊗），无连续性、无逆元（故无除法）。
> 术语修正（2026-08-04）：**除法 = 乘以逆元**，归约路径通着；真正的卡点是逆元不存在。不过它们的"代数雏形"位置已经能指认（§3）。

## 1. 诚实现状：草案里没有斜率、旋度、散度、导数

- ✅ 全仓 grep：`slope` / `curl` / `divergence` / `derivative` 零命中
- ✅ 唯一的微积分痕迹是 time 页里被标注为**走私假设**的 ∂_t（狄拉克方程重述），SPEC §5 已诚实声明
- ✅ 散度：**未推导**。DengYu 侧的玻尔兹曼碰撞不变量（1, v, |v|²）守恒是"散度形状"的陈述（连续方程），但本工程只引用未推导

## 2. 为什么导数在隐数空间"不存在"（根因）

三个结构性缺口：

1. **无连续性公理**：S 只有 ⊕/⊗，没有拓扑、没有极限
2. **无除法（精确版：无逆元）**：除法可归约为"乘以逆元"（z₁/z₂ = z₁ ⊗ z₂⁻¹）——归约路径是**通的**；
   真正的卡点在本工程 ℂ 实现（`ℂ : Int × Int`，ℤ[i]-型环）**没有逆元结构**——全仓无 `Inv`/`⁻¹`/`Field`/`DivisionRing` 实例，
   且 ℤ[i] 不是域（1+i 无逆元）⟹ 差商 `(f(s₁)⊖f(s₂)) ⊗ (s₁⊖s₂)⁻¹` 依旧无意义，
   但缺口已精确定位为**逆元不存在**（系数环是 Int，公理没贴一个 inv），而不是"乘法之外除法独立缺失"
3. **差商的落点**：若为 S 补上逆元（升级系数环到 ℚ[i]/ℝ），差商/斜率**在隐数空间内就有意义**，不必落到观测空间；
   当前 Int 环下，逆元缺失也把"斜率是观测空间操作"的说法弱化成"目前只能在观测空间作差商"

推论（✅ 平凡但关键）：线性映射的差商恒等于它自己 ⟹ 当前框架内"导数 = 线性算子本身"（slope(π) = π，slope(L) = L）。在出现非线性映射之前，微积分没有可推导的内容。

## 3. 代数雏形：导数形状的对象已经住在 End(S) 环里

| 微积分算子 | 代数身份 | 雏形状态 |
|---|---|---|
| 导数/线性化 | End(S) 的元素（Flow 的线性化 L） | ✅ End(S) 是环（A1+A2）——"居住地"已存在 |
| 斜率 | π ∘ L（线性化的观测投影） | ✅ 投影算子 π 存在（L2） |
| 散度 | tr(L)（线性化的迹；环上的标量 = 核方向信息流） | ❌ 迹未定义；需矩阵表示 + D5 |
| 旋度 | (L − Lᵀ)/2（反对称部分） | ✅ **Clifford 楔结构已证**（C2 反交换 ⟹ 外代数） |

- 旋度的代数雏形是**已有的**：σᵢσⱼ + σⱼσᵢ = 0 就是楔积结构，Cℓ(Q) ⊃ 外代数
- 散度的物理含义候选：核方向的信息流，∝ 信息损失（= 能量，Bridges.infoLoss）——与 K4 核运动（内部自由度）同族
- 连续版本（∇·、∇×、∂_μ）全部卡在 D4（度量/签名）+ 光滑性假设，与 ∂_μ 走私警告同级

## 4. 下一步建议

不新增微积分公理；先补两个环内对象：

1. 📋 D5（⊗ 结合性）⟹ Flow 链可线性化 ⟹ L 存在 ⟹ 差商对象有住处
2. 在 End(S) 矩阵表示上定义迹（tr 是环上唯一标量函数，呼应 D2 的 κ 唯一性）

两者之间有一个值得注意的联系：**质量 = Aut(ker) 不变量（D2），散度 = tr(L) 沿核方向的退化**——"核决定质量"与"核方向信息流"可能是同一标量的两个投影面。
