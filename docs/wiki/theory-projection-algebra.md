# 理论概念：隐数投影代数（路线主线）

> 2026-08-06 会话编译（compile-first）。leo 方向纠正：**隐数 ≠ 复数的另一种写法**。
> 隐数是潜在状态空间（latent / hidden space），第一性不是 i²=-1，而是**投影幂等 P²=P**（状态生成机制）。
> 四元数/旋转降级为**比较对象**（空间已有时的变换机制）。
> 结论：投影代数 PA1–PA6 全部已证。所有引用定理见 SPEC.md 与各 .lean 模块。

## 1. 隐数 ≠ 复数：两条路线的区别

```
复数路线(已降级为比较对象):            隐数路线(主线):
  单位元                                 潜在对象 h ∈ H(无确定方向)
    ↓                                      ↓
  乘法规则 i²=-1                          映射/投影 P(幂等 P²=P)
    ↓                                      ↓
  旋转(空间已有时的变换)                  状态出现(空间生成机制)
```

- 复数/四元数解决:**空间已经存在时,旋转如何代数化**。
- 隐数解决:**没有确定状态的对象如何产生具体空间中的状态**。
- 四元数的正确问题不是"隐数是不是一种四元数",而是"隐数空间若存在内部乘法,是否产生类似四元数的非交换结构"(Q3 已证:ij≠ji)。

## 2. 投影代数的代数公理(PA2)

互补投影对 `ComplementaryProjection`(幂等 + 正交 + 完备)是状态生成机制的代数公理:

```
幂等 P² = P        —— 观测后不再改变(H4 的推广)
正交 P∘Q = 0       —— 不同方向互不可见(实部看不到虚部)
完备 P + Q = id    —— 信息不丢失,无第三自由度(L8 范数分解的投影形式)
```

ℂ 实例 `realImagProjection` = {Π_re, Π_im}(实部投影 + 虚部投影),全部字段已证。

## 3. 变换复合:半群而非群(PA3 + PA5)

- ✅ **复合封闭(PA3)**:复合表 5 项全确定——re∘re=re、im∘im=im、re∘im=0、im∘re=0、0∘任何=0。**{Π_re, Π_im, 0} 构成半群**,状态生成可迭代。
- ✅ **半群非群(PA5)**:`hproj_re_not_injective`——Π_re 非单射(0 与 cI 同像 0)。非平凡投影不可逆。
- **物理含义**:投影产生状态是**有损**的——确定性来自信息损失(核方向不可观测,K3)。若需要群(可逆变换),必须引入可逆层(旋转/四元数,即比较对象)。**投影半群与旋转群是两层:生成机制层 vs 变换机制层。**

## 4. 与量子测量的连接(PA6)

- ✅ `pvm_skeleton`:幂等 + 正交 + 完备 = **投影值分解**(PVM 的代数骨架)。

- 诚实边界:**无概率公理**——Born 规则不在此框架内;只有"测量投影产生结果"的代数骨架。
