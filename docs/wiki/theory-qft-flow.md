# QFT × 流动空间：激发态与全域纠缠（QFTFlow）

> leo（2026-08-15）假设：用流动空间框架重新定义 QFT 的"激发态"，并纳入全域性量子纠缠。标准 QFT 说"粒子 = 场的激发态（a†|0⟩）"；流动空间重释为"激发 = 偏离空间流动的锚定模式"。同时考虑：全域纠缠 = 空间场自身的相干结构（非粒子间超距作用）。

## 核心结构（Lean `Explorations/QFTFlow.lean` QFT1–QFT9，全证零 sorry，4144 jobs）

### 第一组：激发态 = 偏离空间流动（QFT1–QFT4，已有公设重述）

- **QFT1 ★ 非激发 = 完全随流**：dx = c·dt ⟹ dτ² = 0（引用 SM1）——流动空间的"基态模式" = 光锥上的流动本身（光子）。非激发不是死寂，而是与空间流动完全同步。
- **QFT2 ★ 激发 ⟹ 偏离空间流动**：0 < dτ² ⟹ dx ≠ c·dt（引用 SM3c）——激发 = 从全域流动中分离（锚定），"空间阻力"的精确形式。
- **QFT3 激发态质量 = 锚定范数**：m² = |ψ₁|²+|ψ₀|²，非零旋量 ⟹ m² > 0（引用 MC4'/MC2'）——激发强度不是场的能量，而是旋量流对空间运动的锚定量。
- **QFT4 多激发质量加法**：三方向叠加 m² = m₁²+m₂²+m₃²（引用 MC6'，胶球 √N 序列代数种子）+ **叠加锚定永不减少**（新证，产生算符叠加单调性）。

### 第二组：全域纠缠 = 空间场相干（QFT5–QFT7）

- **QFT5 ★ 全域相干**：**cos(θ+π) = −cos θ 对任意位置相位 θ 成立**（新证，mathlib 三角恒等）——反相双螺旋（EH 系列）在任何位置完全反关联，**与位置/传播距离无关**。数值：传播距离 L = 1..50 圈，反相恒等机器精度 2e-15，E(Δ=π) = −1 精确，形状（min=−1, max≈0, mean≈−½）与 L 无关。**全域纠缠的解析内核：E(Δ) 只依赖相对相位差，不依赖距离——纠缠是空间场处处自带的相干结构，不是"遥远粒子间的关联"**。
- **QFT6 三方向 = 全域纠缠基底**：(σ₁+σ₂+σ₃)² = 3I（引用 SH3）+ **det = −3 ≠ 0**（新证）——三方向不可分离地构成一个整体；叠加是满秩的（信息不损失）。
- **QFT7 ★ GHZ 三体纠缠判据**：|GHZ⟩ = (|000⟩+|111⟩)/√2 的单体约化 ρ_A = ½I 是**混合态**（ρ² ≠ ρ，Tr(ρ²) = ½ < 1，新证）——三体纠缠 ⟹ 只看单个方向无法纯化。**全域纠缠意味着"单独一个方向的信息是不完整的"**（三方向全域纠缠的信息完整性判据）。

### 第三组：统一——质量 ⟺ 激发 ⟺ 秩 2 纠缠（QFT8–QFT9）

- **QFT8 ★ 秩判据**：双扭量 det(p₁+p₂) = |⟨π₁,π₂⟩|²（引用 TW6）；**det = 0 ⟺ 两旋量平行**（新证：无质量 ⟺ 非激发 ⟺ 可分，光子边界）；**非平行 ⟹ m² > 0**（新证：激发）。数值：单扭量 det 机器精度 0（秩 1），双扭量恒等 3e-14（秩 2），夹角扫描 det = sin²α（α=0 平行 ⟹ m²=0；α=π/2 正交 ⟹ m² 最大）。

## 三扭量胶球：激发 ⟺ 秩 3 纠缠（GQ1–GQ6，2026-08-15 第二轮）

> 深挖推广：电子 = 双扭量（秩 2），胶球 = 三扭量（秩 3）。三扭量 P = π₁⊗π̄₁ + π₂⊗π̄₂ + π₃⊗π̄₃（πᵢ ∈ ℂ³，色空间）。

### 核心恒等（GQ1–GQ2）

- **GQ1**：三扭量外积和 = Aᵀ(Aᵀ)ᴴ（A 的行 = 三扭量）
- **GQ2 ★ 三扭量 det 恒等**：**det₃(Σπᵢ⊗π̄ᵢ) = |det₃[π₁ π₂ π₃]|²**（det(AA†) = |det A|²，Cauchy-Binet 的 N=3 特例）——**胶球质量平方 = 三扭量体积形式**。与电子 det₂ = |⟨π₁,π₂⟩|²（TW6）同构：N 个扭量的 N×N 外积和之 det = |N 阶行列式|²。

### 秩判据（GQ3–GQ5）

- **GQ3**：质量² ≠ 0 ⟺ det₃ ≠ 0（ℂ 是域）
- **GQ4a ★ 激发 ⟹ 秩 3**：质量 ≠ 0 ⟹ 三扭量线性无关（`linearIndependent_rows_of_det_ne_zero`）
- **GQ4b ★ 相关 ⟹ 非激发**：三扭量线性相关 ⟹ 质量 = 0（`det_eq_zero_of_not_linearIndependent_rows`）
- **GQ5 ★ 退化 ⟹ 无质量**：两扭量相等（π₃ = π₂）⟹ det₃ = 0——第三方向不独立 = 非激发

### 统一链（GQ6）

**质量² = |det_N[π₁...π_N]|²，N = 扭量数**：

| N | 粒子 | det 公式 | 秩 |
|---|---|---|---|
| 1 | 光子 | det₁ = \|π₁\|² | 1（非激发，可分） |
| 2 | 电子 | det₂ = \|⟨π₁,π₂⟩\|²（2 维辛体积） | 2（激发，QFT8） |
| 3 | 胶球 | det₃ = \|det₃[π₁π₂π₃]\|²（3 维体积形式） | 3（激发，GQ2） |

**"激发 ⟺ 秩 2"是"激发 ⟺ 秩 = 扭量数"的特例**——电子与胶球是同一判据的两个实例。
