# 硬件四轴（装置 / 诊断 / 建造-可造性 / 排期）

**本页解决的问题**：四条硬件轴此前只以「正文论述」的形式散落在
`theory-antigravity-confinement.md`（装置设计）、`theory-frc-compact.md`（FC8/FC12 判据
与现实锚点）、`fusion-program-roadmap.md`（排期与门）里——人能读，机器不能算、不能验收、
下游（Forge 的 μ 世界）不能锚。本页定义四条轴，把每条轴钉到**一个验收脚本 + 一份机器可读
产物**上，并给出**缺口清单**（哪些数还没有、需要 leo 给什么）与**下游映射表**。

四条轴的共同纪律（不可协商）：

1. **不发明设计参数/物理**：只能把已有条目（FC/PF/DR/TD/GCA 定理与页面已写下的数）变成
   可计算、可机读、带出处的形式。缺的写 `[缺口]`，**禁止填默认值或占位数字**。
2. **金额不入库**：wiki / artifacts / 脚本里都不出现货币数字，只用 人·月 / 工期 / 人 / 比例。
   验收脚本对产物做货币字样扫描（扫到即报红）。
3. **图纸保持干净**：示意图里不出现「缺口 / 未给出」字样（缺口只留在本页与 report.json 的
   缺口清单里）；脚本对图注做逐条扫描。
4. **数值断言必须能真红**：每条断言都做过变异测试（改一个数 → 红，改回 → 绿）。

### 2.2 FC12 人工场选频判据（RMF）

| 量 | 值 | 单位 | 出处 |
|---|---|---|---|
| 离子回旋频率（B=9T，D-T 平均离子） | 55.282 | MHz | `ω_ci = eB/(2π m_i)`；`FrcCompact.lean` `ionCyclotron`；`artifacts/frccompact` G6 μ=0 行 |
| FC12 选频带（k∈[2,5]） | 110.564 – 276.410 | MHz | FC12 `rmf_selection_band_nonempty` / `rmf_selection_above_ci`：ω = k·ω_ci |
| 装置光速响应上界 c/L（L=0.5m） | 599.58 | MHz | FC12 `rmf_selection_below_light_limit` + `scripts/plot_artificial_field.py`（L=0.5m） |
| 选频带不越 c/L 的场强上限（k=5、L=0.5m） | B < 19.52 | T | 由 FC12 上界条件反解：k_max·ω_ci < c/L |
| 稳态窗口比 m_i/m_e | 4557.22 | 无量纲 | `artifacts/frccompact/report.json` G6 `window_ratio_mi_me` |

**结论（可验收）**：在 B=9T、L=0.5m 下，FC12 选频带 [110.6, 276.4] MHz 完全落在装置光速
响应上限 599.6 MHz 之下——即「RMF 驱动频率必须落在 k·ω_ci 带内」与「不能超过 c/L」两条
要求不冲突，且留有 2.2 倍余量（599.58 / 276.41）。若场强升到 19.52 T 以上（k=5），两条
要求开始打架——这给了一个可锚定的装置设计上限。

## 3. 轴② 诊断——δ → μ_min 阶梯（G0/G1 生死门的定量依据）

- **判决量**：D1 回旋共振相对频移 `R_ci = 1/(1−μ) − 1`（FC9 + AMC1；零假设：标准 MHD 的 R_ci = 0）。
- **可探测下限**（由「实测 R_ci > n·σ，σ = δ·R_ci 的测量相对不确定度」反解）：
  `μ_min(n) = nδ/(1+nδ)`。roadmap §1 用的是 1σ 口径；G1 门的通过条件写的是 **3σ**。

| δ（诊断相对精度） | μ_min（1σ，roadmap §1 口径） | μ_min（3σ，G1 通过条件口径） | 到 FC11 天花板的量级差 |
|---|---|---|---|
| 1e-3 | 9.9900e-04 | 2.9910e-03 | 3.00 个数量级 |
| 1e-4 | 9.9990e-05 | 2.9991e-04 | **4.00 个数量级** |
| 1e-5 | 9.9999e-06 | 2.9999e-05 | 5.00 个数量级 |

- **聚变级天花板（硬）**：FC11 给出 μ < 1 − m_e/m_i = **0.999781**（D-T；`FrcCompact.lean` 证
  `mu_crit_rmf = 0.999780568036375`）。聚变级工作点 μ ≈ 0.999。
- **生死门的定量依据**：桌面判据台（δ≈1e-4）能把可探测下限压到 μ≈1e-4，而聚变级是 1e-1…0.999
  ——两者差 **4 个数量级**；D3（μ ∝ P^k）要爬这 4 个数量级，k=1 需 1e4 倍功率、k=0.5 需 1e8 倍
  （`artifacts/fusionroadmap` R3）。这就是「先在 M6 用 1.29% 的人力判决 μ 有没有主动产生通道，
  再决定加不加钱」的全部算术。
- **两条独立通道互检**：D1 线性通道 `1/(1−μ)` 与 FC4 输运通道 `1/√(1−μ)` 函数形式不同（页面已
  记录该差异）；小 μ 处比值 → 2，μ=0.999 处比值 ≈ 32.6（本轴产物给出逐点表）。
- **生死门花销**：G0 = 6 + G1 = 9 = **15 人·月 = 全周期 1161 人·月的 1.29%**；前 18 个月
  （G0–G3）93 人·月 = 8.01%。

**轴② 缺口**：① 桌面判据台的绝对规格（真空腔尺寸、磁体场强、RF 功率、离子源型式）——wiki 只有
「中型测试台功率量级」的定性表述；② δ 的实际可达值与误差预算（Q1 交付物之一，尚未产出）；
③「3σ」的统计口径细节（统计量定义、批次合并方式、系统误差分解）；④ 零假设（标准 MHD 预测
R_ci=0）的解析/数值基准实现（Q1 交付物）；⑤ 回旋共振测量的探针/光谱诊断配置与频率分辨率
（Q3 才升级）。

## 4. 轴③ 建造-可造性——工序 / 关键路径 / 首件 / 自有 vs 外协

- **工序链（页面原文，`fusion-program-roadmap.md` §2.5）**：
  `规格书/询价 → 桌面台建造 → 中型台 → 复现装置 #2`；加第 ⑥ 步（参数表与重复性统计）构成
  十八个月六道工序，人·月合计 30.5（与 fusionroadmap 产物的逐季度分解逐项一致）。
- **关键路径（派生量，口径显式）**：装置线六道工序中除「诊断升级（并行支撑）」外的五道——
  每道都对应判决门的实物产出/前置（G0 规格书 / G1 首件桌面判据台 / G2 中型测试台 /
  G3 的实物前置 = 复现装置 #2 + 参数表）。口径写在 `report.json` 的 `B3_关键路径（派生）` 里，
  并标注为派生、不冒充页面原话；长度 M1–M18 = 18 个月。
- **首件 = 桌面判据台**（M6 建成，腔体/离子源/RF/探针）：首件判据 = G1 通过条件（`R_ci 实测 > 3σ
  且零假设预测 < 分辨率`）；预写失败处置 = `R_ci=0 ⟹ 停装置线`。首件之前的纪律：Q1 **只设计不采购**
  （只问不买），**G1 判决通过才加人**（加人闸门）。
- **自有 vs 外协**（页面能支撑到的粒度）：
  - 自有（自建/自担）：桌面判据台（首件）、中型测试台、诊断升级（探针阵列+光谱）、复现装置 #2
    的场地与运行、判据规范/预注册协议/理论数值线（1 FTE × 18 月 = 18 人·月）；
  - 外部：G3（M18）起 1–2 个外部实验室做**独立复现**、G7 系统集成 + 外部合作（不自己造全部
    部件）、Q5 对外线（外部实验室合作协议 + 数据共享条款）、Q1 询价单（外购件先询价）。
  - **工件级归属 = `[缺口]`**：页面没有设备清单，因此**无法**给出「哪件自制、哪件外购」。

**轴③ 缺口**：① 设备清单逐项（条目、单件工期、交期）；② 自有 vs 外协的**逐件**归属；
③ 长周期采购件（真空腔/磁体线圈）的制造前置周期；④ 砍掉十级分段压缩线圈后，剩余外购件清单
的变化量（页面只说「砍掉」，未列替代清单）。

## 9. 诚实边界

- **可锚定量 ≠ 已达成量**：轴① 的几何/场强是**设计锚点与机械上限**（来自 FRC/CFR2 现实锚点与

  本页不声称任何一条已被实验验证。
- **轴① 的支点是别人的锚点**：反引力约束环自身的尺寸一个都没有——本页的「装置可锚定量」实际上是
  「这套设计所在物理区间（12cm–2.1m、7–35T、110–600MHz）的可锚定量」。这是刻意的：不发明参数。
- **第二输入缺口仍在**：μ 的主动产生机制（以及 η 的物理来源）是仓库标注的第二输入缺口，
  四条硬件轴都不解决它，只是把它变成**可判决**（G1 用 R_ci 判决）与**可排期**（1.29% 人力先试）。
- **继承页面已声明的资源边界**：氚/中子设施与「μ 主动产生若需微波/激光/额外磁体」两项资源不在
  旧成本模型内（`fusion-program-roadmap.md` §8），必须 G4（M24）后重估；本页的四条轴不改变这一点。
- **口径差异已登记而非已修复**：§5.2 的取整差与措辞差异是**上游既有内容**，本 agent 只读不改，
  已在产物里登记并交回 leo。
- **无新物理预言**：本页是「把论述变成可计算、可验收、可被下游读的产物」的工程化工作，
  不引入新物理，也不修改任何已有定理或数值断言。
