# 魔角石墨烯场源账本：场天花板 → 密度 → μ 窗口

> 计划页 = [moire-field-ceiling-plan.md](./moire-field-ceiling-plan.md)（七层账本 + 判决量 + 门表）。
> 本页是**执行结果**：把仓库已证条目（PF3 / FC1 / 二轮修正链 / FC11b）里的场源
> 换成"有材料天花板 B ≤ B_c2"的魔角石墨烯系场源，看那一串数字变成什么，死在哪一层。

## §0 直接回答

| # | 结论 | 数字 |
|---|---|---|
| ① | **"1° 夹角"不是问题，N=2 才是问题** | MATBG(N=2) 面内 B_c≈1.6 T（未显著违背 Pauli 限）；MATTG/MAT4G/MAT5G(N≥3) 面内 >10 T（违背 2–3×） |
| ② | **面外配置（场 ⟂ 膜，叠层几何）在 0.2m 装置上无解**，且是**代数无解**不是工程困难 | n 被截到 1.19e18（设计需 1e20，差 84×）⟹ 功率 ×3.2e-8；所需 (1−μ) ≤ 4.6e-8 < FC11 地板 2.19e-4（低 4.8e3 倍）⟹ 窗口空 |
| ③ | **面内配置（螺线管里场本就大致 ∥ 膜面）过场门，但功率掉 3 个量级** | B_min(1e20)=1.099 T < 1.6 T（裕度 1.46×）；P ∝ B⁴ ⟹ ×9.99e-4，同功率体积 ×1001 |
| ④ | **紧凑化把场门槛抬到材料天花板之上** | B_death ∝ 1/a：a=0.2m→0.997 T、0.1m→1.99 T、0.05m→3.99 T ⟹ 10cm 级连 N=2 面内 1.6 T 都过不了 |
| ⑤ | **即使过了物理层，工程层两门仍是否决项** | 载流门 1.3e4×（片超流密度）~4.0e5×（片电流）；制冷门 3.75e6×（ITER 冷量 75kW@4.5K vs 稀释制冷机 20mW@0.5K）+ Carnot 9.1× |
| ⑥ | **顺带发现：仓库自身设计贴着 FC11 地板** | 现有 n=1e20 设计需 μ≥0.99968，其 (1−μ)=3.24e-4 只比地板 2.194e-4 高 **1.48×** |

一句话：**魔角石墨烯 × 聚变这条路线，物理层死于"场天花板"，工程层死于"二维超导体的载流容量"
与"亚开尔文制冷容量"，而不是死于超导机制本身。**

## §1 链条与七层账本

    MATBG(θ≈1.1°, N=2) 超导 ─①线圈载流─▶ ②直流约束场 B ─③─▶ 密度 n (β≤1)
        ─④─▶ 功率 P ∝ n² ─⑤─▶ 劳森 τ_req ─⑥─▶ 所需 μ(t) ─▶ 约束闭合

| 层 | 公式（出处） | 本轮数值（a=0.2 m, β=1, T=15 keV, n_design=1e20） |
|---|---|---|
| L1 材料 | B_c2⊥≈0.12 T（N=2）/ B_c∥≈1.6 T（N=2）/ >10 T（N≥3）；Tc 1.1–2.1 K | T_op ≤ Tc/2 ⟹ 0.5–1 K 级（稀释制冷机） |
| L2 导体 | 片电流 K = J_c·d；超流面密度 n_s | MATBG 2.5e-3 A/cm vs REBCO 1000 A/cm；n_s 2.88e12 vs 3.77e16 cm⁻² |
| L3 场-密度 | PF3 B_min=√(2μ₀nkT/β)；FC1 n_max=βB²/(4μ₀kT) | B_min=**1.099 T**；n_max(0.12T)=1.19e18 / (1.6T)=2.12e20 / (9T)=6.71e21 / (35T)=1.02e23 |
| L4 功率 | P ∝ n²⟨σv⟩ ∝ B⁴；V ∝ B⁻⁴ | 面外 ×3.16e-8（体积 ×3.16e7）；面内 ×9.99e-4（×1001）；N≥3 10T ×1.52；压缩 35T ×229 |
| L5 输运 | τ_E=τ₀/√(1−μ)，τ₀=a²/D₀=0.036 s；劳森 n·τ=2e20 | τ_req：168 s（0.12T）/ 2 s（1e20 设计） |
| L6 μ 窗口 | FC11b：可行 ⟺ X_req ≡ (τ₀n/A)² > m_e/m_i=2.194e-4 | 面外 X=**4.59e-8 < 地板 ⟹ 无解**；面内/设计密度 X=3.24e-4 ⟹ 裕度 1.48× |
| L7 制冷 | Carnot W/Q=T_h/T_c−1；容量 mW vs kW | 3.75e6× 容量缺口 + 9.1× Carnot |

两个分支要分清（这是本轮的记账纪律）：
- **满 β 分支**（同一装置几何能装多少功率密度）：n=n_max(B)，P ∝ B⁴ ⟹ 第 3、4 列。
- **设计密度分支**（跑仓库原有的 n=1e20 设计点需要多强的场）：需 B ≥ 1.099 T，此时
  n 不再受场限制，μ 要求固定为 X=3.24e-4（裕度 1.48×）——**场再大也不改善这一列**。

## §3 生死门：B_death(a) = 场天花板低于它 ⟹ 无解

把 L5/L6 合起来：X_req(B) ∝ n² ∝ B⁴（Lean MFC3），所以**场越弱，要求的 μ 越靠近 1**。
令 X_req(B)=m_e/m_i 解出阈值：

    B_death(a) = 0.997 · (0.2/a)  T        （β=1, T=15 keV, D₀=1.11 m²/s）

| 装置尺寸 a | B_death | 被关掉的场源 |
|---|---|---|
| 0.05 m | 3.99 T | MATBG 面外 **+ 面内**（N=2 全灭） |
| 0.10 m | 1.99 T | MATBG 面外 **+ 面内**（N=2 全灭） |
| 0.15 m | 1.33 T | 仅 MATBG 面外 |
| 0.20 m | 0.997 T | 仅 MATBG 面外 |
| 0.30 m | 0.664 T | 仅 MATBG 面外 |
| 1.0 m | 0.199 T | 无（材料天花板都过关） |

**读数**：紧凑化（leo 关注的 10cm 级）把场门槛抬到 2 T 量级，正好越过 N=2 的面内天花板
1.6 T——所以"魔角石墨烯 + 小装置"两个愿望是**方向相反**的；能同时满足的只有 N≥3 多层
（>10 T）那一档。

## §4 工程层两门（量级账，未形式化）

**载流门**：聚变磁体要的是安匝，二维超导体的载流通道只有 ~0.7 nm 厚：

| 量 | MATBG | REBCO（工程基准） | 缺口 |
|---|---|---|---|
| 片超流密度 n_s（最优掺杂 / 满填充 vs 100 nm 层） | 1.96e11–2.88e12 cm⁻² | 3.77e16 cm⁻² | **1.3e4×** |
| 实测片电流（体临界电流 250 nA，宽度取 1 μm 假设） | 2.5e-3 A/cm | 1000 A/cm（4.2K, 19T） | **4.0e5×** |

**制冷门**：MATBG 的 T_op ≤ Tc/2 ≈ 0.5–1 K，即必须工作在稀释制冷机温区：

| 量 | 装置侧 | 亚开尔文侧 | 缺口 |
|---|---|---|---|
| 冷量 | 75 kW @4.5 K（ITER 低温工厂当量） | 20 mW @0.5 K（商用稀释机型，量级） | **3.75e6×** |
| Carnot 代价 W/Q | 64.1 @4.5 K | 585 @0.5 K | 9.1× |

（另注：MATBG 的超导是**栅控**的——必须逐层加栅极才能把费米面调到平带；
"把石墨烯变成线圈"要付的工程代价没有计入本账，方向上是把缺口再拉大。）

## §6 诚实边界（四层判定）

- **数学恒等 + 序关系（真但平凡）**：MFC1–MFC7 全是单调性/幂律/一次否定存在性证明；
  数值层全部是 PF3/FC1/FC11b/二轮修正链的**直接代入**——无新物理预言。
- **数值匹配（需外部输入）**：材料 B_c2（0.12 / 1.6 / 10 T）、Tc、n_s、片电流、制冷容量
  全是外部实验值，取自文献报道的**上界/乐观包络**（二维材料器件间分散大，尤其 B_c2 与 Ic）。
- **解释/工程层（不是装置设计）**：载流门与制冷门是量级账（片电流 vs 安匝、mW vs kW），
  未做线圈设计、热负荷预算、栅控工程；"片电流"用 1 μm 宽假设。
- **缺口未变**：μ 的主动产生机制 = 第二输入缺口；本轮只算"需要多少 μ、窗口是否打开"。
- **本轮新增缺口**：μ 对 ⟨σv⟩ 的影响仍未建模（沿用 FC 轮）；"栅控维持 vs 线圈化"的
  工程矛盾只标注未量化。
