## 3. 结论（这一页能说什么）

1. **对角模型被仓库自己的数据否掉**：N=7 不可表为三个独立绕数的平方和（Legendre：7 = 4⁰(8·0+7)）。
   只要保留 0-+ 那个 N=7，就**必须**有非对角的（集体的、互相耦合的）项。
   ⟹ "环扭转"不是可选项，是**必需项** —— 这是本页最硬的一条。
2. **集体项的最小形状**：N = Σnᵢ² + \|μ̄₃\|，且 μ̄₃（三环整体连接）只在至少一个环被扭过两圈以上时出现
   （变体 II）⟹ 前三个 N 恰好是 3、6、7，与仓库胶球账本一致；而"任意都能取 μ̄₃"的变体 I 会多出一个
   1.86 GeV 的奇宇称态，被格点谱排除 ⟹ **数据选变体 II**。
3. **环扭转同时给出 μ 与 N**：μ = 1 − \|Lk_net\|/\|Lk_gross\|（抵消度）与 N（条数）出自**同一个扭转几何**
   ⟹ 两者不独立 ⟹ 这就是"过度决定"检验点：同一个扭转角要同时对上胶球阶梯**和** FRC/FC11 的窗口。
   极限情形已复核：反向双螺旋 ⟹ μ = 1（光子）,同向 ⟹ μ = 0。
4. **半整数扭转自带自旋结构**（RT5）：转半圈回到 −1、转整圈回到 +1 ⟹ 自旋−统计不需要额外假设。

## 4. 诚实边界（与结果一起引用）

- 质量 = |⟨π₁,π₂⟩| 是 **Penrose 标准结果**（本仓 TW6 已标注"复述"）；本页没有改它。
- **Lk = Tw + Wr 是经典定理**（Călugăreanu–White–Fuller），本页只做**数值复核**（平面残差 ~1.3e-2、非平面用 ΔLk≈0.98–0.99 的判据），不是新证明。
- **"扭转 → N"是模型选择**：本页只**否掉对角模型**、给出最小集体实现，**没有导出选择规则**（变体 II 的 "max|nᵢ| ≥ 2" 是从格点数据**选**出来的，不是推出来的）。
- 与格点只比**比值**；M₀ = 0.93 GeV 仍是**标定**（第二输入缺口未变）。
- 三叶结 Wr 的数值 ≈3.2567 与精确 3 差 ~8.6%，来自离散化（加密不改）——**不要**把这个数当精确值用；要精确值得用解析公式。
- 本页不声称任何 QCD 推导：Borromean/扭环是**图像 + 不变量**，不是从 Yang–Mills 推出来的。
- 顺手记录一处**仓库内部不一致**：`artifacts/glueball/report.json` 的 conclusion 写"√3/√5/√7"，而表格与 `theory-glueball-spherical.md` 写 √3/√6/√7。√5·0.93 = 2.08 落在 2++ 区间(2.15–2.40)**之外**，√6·0.93 = 2.28 在里面 ⟹ **conclusion 那处是笔误**（**已就地更正**：`scripts/verify_glueball_coupling.py` 的 conclusion 字符串改为 √3/√6/√7，`theory-glueball-coupling.md` 的 V4 行同时更正并写明原值，便于回溯）。
