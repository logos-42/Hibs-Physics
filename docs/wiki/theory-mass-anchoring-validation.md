# 质量锚定假设的数值验证（诚实报告 v2）

> 假设：质量 = 内部运动状态（自旋）× 空间运动的阻抗（锚定效果）。
> v2 更新：① 自旋实现改为**旋量流**（Clifford σψ，自旋本身就是运动状态）；
> ② 新增**胶球谱比 m² = N·M₀²** 检验。
> 脚本：[`scripts/verify_mass_anchoring.py`](../../scripts/verify_mass_anchoring.py)

## 1. 电子验证（恒等式陷阱不变）

| 构造 | 数值结果 | 判定 |
|---|---|---|
| m_cand = S/(λ_c·c)，S=ℏ/2 | 4.5547e-31 kg = m_e/2 | **恒等式**：λ_c 由 m_e 定义 |
| m_cand = S/(r_e·c) | 6.2416e-29 kg，差 68.52 倍 | **恒等式**：r_e 内含 m_e |
| m_cand = ℏ/(c·a₀) | 6.6474e-33 kg = α·m_e | **恒等式**：a₀ 定义含 m_e |
| 光子零锚定 → m=0 | 实验上限 <1e-18 eV | **通过**（序关系） |
| a_e 异常磁矩 | 0.001159652181 | **失败**：需 QED 圈图 |
| m_p/m_e | 1836.153 | **失败**：需内部结构 |

**核心发现不变**：电子质量的 {ℏ,c,长度} 构造全是恒等式重排，无独立预言力。
这不是假设被证伪，而是"质量已塞进常数里"——模型需要一个独立的
空间阻抗输入才能变成数值理论。

## 2. 胶球谱比 m² = N·M₀²（v2 新增，最有价值的结果）

### 格点数据（2022–2024 中心值）

```
m(0++) = 1.71 GeV,  m(2++) = 2.40 GeV,  m(0-+) = 2.56 GeV
m(2++)/m(0++) = 1.4035   vs   √2 = 1.4142   差 0.76%
m²(2++)/m²(0++) = 1.9698  ≈  2
```

### 模型：m_G = √N·M₀（N = 内部模式数整数）

| 通道 | N | √N·M₀ (M₀=1.209 GeV) | 格点 | 偏差 |
|---|---|---|---|---|
| 0++ | 2 | 1.710 GeV | 1.71 GeV | 0.0% |
| 2++ | 4 | 2.418 GeV | 2.40 GeV | 0.8% |
| 0-+ | 5 | 2.704 GeV | 2.56 GeV | 5.6% |

**判定**：m² ∝ N（整数模式数）与格点胶球谱相容。M₀ 仍是拟合参数
（≈1.21 GeV ≈ 4Λ_QCD），但**谱形 √N 是结构预言**，不是事后拟合。
这是该假设唯一有数值内容的支持点，需要更精确格点数据确认。

## 3. 0++ 胶球矛盾已修正（v1 论证错误）

v1 曾说"0++ 胶球 J=0 ⟹ 与质量=自旋阻抗矛盾"。**这是错的**：
0++ 胶球内部是两个自旋-1 胶子耦合 |1,1⟩|1,−1⟩，**总角动量为零但
内部运动状态非零**——恰好支持"质量 = 内部运动锚定"，不矛盾。
（是我把总角动量 J 当成了内部运动状态，leo 的胶球理解是对的。）

## 4. 旋量流实现（MinimalCore.lean MC1 v2）

```text
spinFlow σψ   : 自旋算子 σ 作用在旋量 ψ 上 = 内部运动状态
锚定质量      := 旋量流四分量范数之和 (componentNorm)
定理          : ψ ≠ 0 ⟹ 0 < m(σ₁ψ)     [非零自旋 ⟹ 非零锚定]
光子边界      : ψ = 0 ⟹ m = 0          [零旋量 ⟹ 零锚定]
```

Lean #eval 落地：σ₁·(1,0) → 1、σ₁·(0,1) → 1、σ₁·(1,1) → 2；
隐数版 h²：3 → 9、−4 → 16。全部编译 + 验证通过。

## 5. 诚实结论（v2）

1. **电子**：恒等式陷阱不变，无独立预言力（需独立空间阻抗输入）。
2. **胶球谱**：m² = N·M₀² 与格点 0++/2++ 相容（N=2,4，M₀≈1.21 GeV）；
   0-+（N=5）偏差 ~6%（不确定度内）。**这是假设唯一有数值内容的支持点**。
3. **自旋=旋量流实现**：代数正确（非零⟹非零，零⟹零），但仍是序关系。
4. **失败点不变**：a_e 需 QED，m_p/m_e 需内部结构。
5. **最终判断**："自旋 × 空间阻抗"是**自洽的序关系框架**；胶球谱比
   √N 是最接近数值预言的方向，需要更精确格点数据确认。
