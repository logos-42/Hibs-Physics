# 杨–米尔斯四维化（Y4D1–Y4D9）

> leo（2026-11-01）：「我说的是杨米尔斯猜想，有进行四维化吗？结掉我之前没有证明完整的部分」。

## 1. 四维化的真实状态（先摆清楚）

| 模块 | 维度 | 场强定义 | 规范变换 |
|---|---|---|---|
| `YangMillsLattice.lean` | **一维**（`ℤ → Mat3C`） | `F(t) = [A(t), A(t+1)]`（近邻） | **没有** |
| `YangMillsContinuum.lean` | **四维指标**（`Fin 4 → ℝ`、`Fin 4 → ℤ`、四维环面 Haar） | `F_μν(x) = [A_μ(x), A_ν(x)]`（**同点**） | **没有** |
| 本模块 `YangMillsFourD.lean` | **四维格点** `Site := Fin 4 → ℤ` | `F4 = [U_μ(x), U_ν(x+μ̂)]`（近邻，真四维指标） | **有**（Y4D3） |

**结论**：此前「四维化」只做到**指标是四维**，没做到**结构是四维**——没有链路变量、没有 plaquette、没有规范变换、没有 Wilson 环。而规范不变性正是「规范理论」的定义。本模块补的就是这一层。

## 2. 补的四维结构

| 编号 | 内容 |

| **Y4D4 ★★★** `trace_plaquette_gauge_invariant` | **Wilson 可观测量**：`tr P_μν(x)` 规范不变（迹可循环 + `g⁻¹g = 1`）。这是格点 QCD 真正会测的量 |
| **Y4D5** `F4_can_be_nonzero` | 四维格点上存在非零近邻场强（见证：方向 0 取 `cycle3`、方向 1 取 `diag123`，在真正的四维点上） |

## 3. 结掉的三处（全是负面结果，这是重点）

### Y4D7 ★★★ 质量间隙与维数无关

`mass_gap_independent_of_dimension`：4D 格点上间隙陈述与 1D **逐字相同**，且**前提里没有任何格点/维度假设**（`m² = N·M₀²` 的整数性决定一切）。
⟹ **四维化对间隙的贡献是 0**。这不是遗憾，是结论：四维化不会产生间隙。

### Y4D8 ★★★ 非交换性不是间隙的来源（把「未证蕴含」升级为「已证不可能」）

`noncommutativity_is_not_the_source_of_the_gap` 同时成立三件：
1. 存在**非阿贝尔**四维构型（`F4 ≠ 0`，Y4D5）；
2. 存在**处处交换**的四维构型（`F4 ≡ 0`，`abelian_config_field_strength_zero`）；
3. 间隙陈述**对任何构型都成立**（Y4D7，前提里没有 `U`）。

⟹ 「自相互作用（非交换）⟹ 质量间隙」这条箭头在框架内**不可能是蕴含**：前件与后件互相独立。
仓库 2026-10-08 对抗性审稿把 CA7 改名并登记「箭头本身没有被证明」——本定理把它升级成**已证不可能**。要让箭头成立，必须引入把**场强**与**条数计数**联系起来的**新动力学**（框架里没有）。

### ⚠️ Y4D8 的编码更正（2026-11-01，同日）：非交换与间隙无关，但**场不是无关的**

leo 指出：「我们构建的是新的非阿贝尔规范场，构建过程算出质量间隙，间隙也有了」。
这个批评成立，Y4D8 有一处**编码错误**：

- Y4D8 把间隙写成 `strandMassSq N M₀ = 0 ∨ …`，其中 **N 是自由自然数、场完全不出现**。
  于是「间隙与场无关」是**把场从定理里删掉**造成的，不是物理结论。
- **更正模块** `Explorations/GapFromTopology.lean`（GT1–GT5，零 sorry）：
  **条数由场构型给**——三个方向的相位构型各自闭合 ⟹ 绕数 nᵢ ∈ ℤ（VBC1 已证）
  ⟹ N = Σ|nᵢ|² ∈ ℕ ⟹ **对每一个闭合场构型**间隙成立（`strandCount_from_field`）。
- 于是正确的说法分两句：
  1. **交换子 [A,A]（非交换性）确实不出现在间隙里** —— 这半仍然真；
  2. **但场的构型通过绕数出现了** —— `no_fractional_count`（不存在分数条数）就是它的形式。
- 一句话物理读法：**质量间隙 = 场的闭合性迫使绕数整数。整数不是公设，是拓扑的后果。**
- 仍未闭合：一般的 4 维矩阵值非阿贝尔规范场**如何取绕数**（plaquette 有了，从 plaquette 到绕数还没有）。

### 坑已补：从链路到绕数到条数到间隙（`Explorations/LinkTopology.lean`，LT1–LT6）

上一节留下的缺口是「绕数从哪来」——`GapFromTopology` 是**假设**了一个闭合相位 Δ。
新模块把它从**链路**算出来：

| 编号 | 定理 | 内容 |
|---|---|---|
| LT1 | `prod_link_eq_exp_sum` | 链路乘积 = 总相位的指数：∏e^{iθᵢ} = e^{iΣθᵢ} |
| **LT2** ★★★ | `winding_of_closed_links` | **闭合链路（乘积 = 1）⟹ Σθ = 2πk，k ∈ ℤ** —— 绕数是从链路算出来的，不是输入的 |
| **LT3** ★★★ | `small_loops_have_no_winding` | 若每段 \|θᵢ\| < 2π/n，则 k = 0 ⟹ **绕数有门槛**：小回路必然平凡拓扑 |
| **LT4** ★★★ | `strandCount_from_links` | 三方向各自的闭合链路 ⟹ 条数 N = Σ\|kᵢ\|² ⟹ **对每一个链路构型**间隙成立 |
| LT5 | `glueball_count_from_links` | k=(1,1,1) ⟹ N=3（胶球 0++ 的链路来源）；(1,1,2)→6；(1,2,2)→9 |
| LT6 | `gap_mass_from_links` | 三方向绕数全非零 ⟹ N ≥ 3 ⟹ m² > 0 |

**完整链条（U(1) 层，已闭合）**：

```
链路 U_i = e^{iθ_i}  ⟹  Wilson 环闭合（∏U = 1）
   ⟹  Σθ = 2πk, k ∈ ℤ（绕数，LT2）
   ⟹  条数 N = Σ|k|²（LT4）
   ⟹  质量 = √N·M₀ ⟹ 间隙（LT4/LT6）
```

**新读法**：LT3 说绕数有门槛——**低能（小相位）里根本看不出拓扑**。这解释了
「格点上的拓扑荷是跳到整数、而不是连续长出来」这件事。

**这一层仍是 U(1)**：矩阵值（非阿贝尔）链路的拓扑荷要 Pontryagin 指数，仓库里没有。
`YangMillsFourD.Y4D2` 有 plaquette，但 plaquette → 绕数这一步还没写。这是下一个坑。

### 升级完成：绕数从相位升到矩阵（`Explorations/NonAbelianLinkTopology.lean`，NA1–NA7）

上一节登记的下一个坑是「矩阵（非阿贝尔）链路如何取绕数」。本模块补上，入口是**行列式**：

> det : GL(3,ℂ) → ℂ* 是**群同态**（det(AB) = detA·detB），
> 所以矩阵链路的闭合回路，其**行列式相位**仍走满整圈 ⟹ 绕数仍是整数。
> 而 det 在共轭下不变 ⟹ 这个整数**规范不变**。

| 编号 | 定理 | 内容 |
|---|---|---|
| NA1 | `detLink_mul` | det(uv) = det(u)·det(v)（行列式乘性的群版） |
| NA2 | `detLink_mul_inv` / `detLink_inv_mul` / `detLink_one` | det 与逆元、单位元相容 |
| **NA3** ★★★ | `winding_of_closed_matrix_loop` | **四段矩阵回路闭合 ⟹ Σ arg det(Uᵢ) = 2πk，k ∈ ℤ** |
| **NA4** ★★★ | `detLink_conj` | **det(g·P·g⁻¹) = det P** ⟹ 整数是**规范不变量**（可观测） |
| **NA5** ★★★ | `gap_from_matrix_loops` | 三方向矩阵回路 ⟹ 条数 N=Σ\|k\|² 由链路给出 ⟹ 间隙 |
| NA6 | `loop4` / `detLink_loop4` | 四段回路乘积 = plaquette 的抽象；行列式按段分解 |
| NA7 | `witness_diag_det` | `diag(i,1,1)` 的行列式 = i ⟹ 只让一个色带相位也能带绕数（色分解真实） |

**升级后链条（矩阵端接上了）**：

```
矩阵链路 U_i（GL(3,ℂ)）⟹ 回路乘积 P（plaquette 抽象）
   ⟹ P = 1（闭合）⟹ det P = 1 ⟹ Σ arg det U_i = 2πk（NA3，整数）
   ⟹ 每个方向一个整数 ⟹ 条数 N=Σ|k|² ⟹ 质量 √N·M₀ ⟹ 间隙（NA5）
   ⟹ 且 k 规范不变（NA4），所以这是**可观测量**，不是规范选取的产物
```

**仍是诚实边界**：
- 本模块用 **det（色求和）** 作非阿贝尔整数；**逐色分解**（Σ_c\|k_c\|²）只在极大环面情形下显然成立，本模块只给 NA7 的单个见证，不给一般定理。
- **不等于 Pontryagin 指数**：4 维瞬子荷要 ε_{μνρσ}tr(F∧F)，本模块做的是「闭合回路 ⟹ 行列式绕数」，那是 Pontryagin 的**阿贝尔影子**（第一 Chern 类）。
- 反射正性 / 测度 / 连续极限仍为零。

### 拆 det：行列式的整数 = 三个色的整数之和（`Explorations/ColorSplit.lean`，CS1–CS6）

NA 模块用行列式给出**一个**整数（三色之和），而条数规则要 **Σ_c\|k_c\|²**。本模块把它拆开：

| 编号 | 定理 | 内容 |
|---|---|---|
| CS1a | `diag_mul_diag` | 对角乘对角 = 对角（对角元相乘） |
| CS1b | `loop4_diag_apply` | 四段对角回路的对角元 = 四个相位指数之积 |
| **CS3** ★★★ | `color_product_one` | **色之间不混合**：对角回路闭合 ⟹ 每个色的乘积各自 = 1 |
| **CS2** ★★★ | `color_windings_of_closed_diagonal_loop` | **逐色绕数整数**：三个色各自给出 k_c ∈ ℤ，Σᵢθ_{c,i} = 2πk_c |
| **CS4** ★★★ | `det_winding_is_color_sum` | **det 的绕数 = Σ_c k_c**（拆 det 的结论） |
| **CS5** ★★★ | `gap_from_color_windings` | 条数 N = Σ_c\|k_c\|²（`countOfWindings`）⟹ 间隙 |
| CS6 | `witness_one_color` | 见证：每段 π/2、四段合计 2π ⟹ k=1（其余两色 0） |

**关键读法**：行列式给的是**总和**（第一 Chern 类），逐色才给**条数需要的分量**。
所以「条数 = 三色绕数平方和」现在是从矩阵链路**算出来的**，不再是外加规则。

**诚实边界**：
- 只做**对角**（极大环面）情形。**一般非对角矩阵**的逐色分解需要本征值/三角化（`Module.End` 谱分解），仓库里**没有**——这是下一个坑。
- 对角情形的"色"是色指标（3 个分量）；它与 SU(3) 权重在此重合，是因为对角子代数就是 3 个独立 U(1)。
- 仍不声称 Pontryagin 指数；反射正性 / 测度 / 连续极限仍为零。

### B 已做：拆色**不是**规范协变的（否定结果，`Explorations/ColorSplitGauge.lean`，CG1–CG5）

问：条数 N = Σ\|k_c\|² 在全 SU(3) 下是否不变？

**答：否，结构性否定。**

反例（Lean 内验证，`conj_has_offdiag`）：

```
D = diag(i, 1, 1)                       对角（只有第 1 色带相位）
g = [[1,1,0],[0,1,0],[0,0,1]]           单位上三角（**不是**置换）
h = g⁻¹ = [[1,-1,0],[0,1,0],[0,0,1]]
g·D·h = [[i, 1−i, 0], [0,1,0], [0,0,1]]  ← 非对角元 1−i ≠ 0
```

| 编号 | 定理 | 内容 |
|---|---|---|
| CG1/CG2 | `gEx_mul_hEx` / `hEx_mul_gEx` | g、h 确实互逆 |
| CG3 | `dEx_diagonal` | D 确实对角 |
| **CG4** ★★★ | `conj_has_offdiag` | **(g·D·h) 的 (0,1) 元 = 1−i ≠ 0** |
| **CG5** ★★★ | `color_split_not_gauge_covariant` | 打包成否定命题：**共轭把对角变成非对角** |

**推论（写死）**：
- 逐色绕数 k_c 是**对角元相位**，矩阵一旦非对角，**k_c 没有定义** ⟹ 条数只在**选定 Cartan 基**里有意义。
- 对比：**行列式绕数规范不变**（NA4 `detLink_conj`）⟹ **"总数"可观测，"分量"不可观测**。
- 要让条数成为物理量，只有两条路：
  1. **选规范**（极大阿贝尔投影 / maximal abelian gauge）——格点 QCD 的标准做法，但**规范选取本身是模型输入**，仓库里没有；
  2. **改用本征值相位**——相似矩阵有相同本征值，所以本征值相位**天然规范不变**。
     这是正确方向，但要 `Module.End` 谱分解（下一个坑，现在有了明确理由）。

### 换方向：让**流动自己给出框架**（`Explorations/FlowFrame.lean`，FF1–FF7）

leo（2026-11-01）：「不是谱分解，是让流动给出框架。流动已经有方向结构和电荷 = 流散度；
如果能用它定出极大环面（而不是我们选），框架就从输入变成推论。
死法也清楚：框架随点漂移、或与三方向不对角，这条就死。」

**构造**（无自由参数）：

```
frameMat C g = [ C ;  g ;  C × g ]     三行
                 ↑    ↑     ↑
              流动   电荷梯度  叉积
```

即：第一轴 = 流动方向，第二轴 = 电荷梯度（流散度的梯度），第三轴 = 两者叉积。
**框架只依赖 (C, g)**——Cartan 选取不是输入。

| 编号 | 定理 | 内容 | 判决 |

| **FF1** ★★★ | `frameMat_determined` | 框架由 (C, g) 唯一给出（`rfl`：无自由度） | **成立** |

| **FF3** ★★★ | `frame_dead_of_parallel` | C ∥ g ⟹ 第三行全零 ⟹ det = 0 ⟹ **框架塌** | **死法一** |
| FF4 | `frame_dead_witness` | C=(1,0,0), g=(2,0,0) ⟹ det = 0 | 见证 |

**结论（写死）**：

  ⟹ 要全局一致的色分解，必须再加**一个约束**（如"流动是整体常向量"或"电荷梯度处处⊥流动"），
    而那个约束**就是新的输入**。**不能两头都要。**
- 未做：把 frameMat 当基、在该基下写矩阵表示、再与 `ColorSplit` 的逐色绕数接起来。

### 在流动给出的框架下做色分解（`Explorations/FrameBasis.lean`，GF1–GF5）

## 4. 因此现在能说与不能说的

**能说**：
- 四维规范化结构在框架内**已建立**（链路 + plaquette + 规范协变 + 规范不变的 Wilson 量）；
