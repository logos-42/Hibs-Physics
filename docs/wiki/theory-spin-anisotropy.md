# 自旋的应用（SA1–SA9）

> leo：「能不能把这个自旋拿来做应用（专门做自旋的应用）。」
> 本页做两件事：**先钉边界**（把「现在没有旋钮」写成定理），**再开一个口**（一个新假设，
> 带它自己的死法）。**不做**的是：假装现在已经有旋钮。

## 1. 边界（钉死）：自旋方向**不进入**质量

仓库现有两处锚定定义：

| 处 | 定义 | 后果 |
|---|---|---|
| `SpaceLightSpeed.lean` | `anchorMassOf = Int.natAbs s.spin + \|rel.x\| + \|y\| + \|z\|` | **只有绝对值**（方向被 natAbs 吃掉） |
| `MinimalCoreMathlib` | `anchorMassSq ψ = ‖σ₁ψ‖² = \|ψ₁\|² + \|ψ₀\|²` | **旋量范数**，而 σ₁ 是酉的 |

本页把它做成定理：

- **SA1 `anchor_massSq_eq_sum`**：锚定 = 总范数平方 `|ψ₁|² + |ψ₀|²`（不变性全是它的推论）
- **SA2 `anchor_sigma1_blind`**：对 σ₁ 不变
- **SA3 `anchor_sigma3_blind`**：对 σ₃（法向量方向）不变
- **SA4 `anchor_sigma2_blind`**：对 σ₂ 不变
- **SA6 `anchor_phase_blind`**：对全局相位不变（|z| = 1）
- **★ SA5 `up_down_degenerate`**：**↑ 与 ↓ 两态质量简并**

数值：三个生成元 + 随机 SU(2) + 全局相位，2000 次抽样的最大相对变化 ≤ **1.2e−15**；
↑↓ 两态锚定都 = 1.0，差 = **0.0**。

**结论：自旋方向不进入质量。** 所以「自旋的应用」目前为零**不是没做，是结构上没有开口**。
把这条写成定理，是为了让后来人不能靠改措辞绕过它。
（诚实边界：一般 SU(2) 元的酉性未形式化（需任意 2×2 酉矩阵）；本页证的是三个生成元 + 全局相位。）

## 2. 开口：夹角敏感锚定（**新假设**，带死法）

接口是现成的：**空间流动的涡度轴就是 B 的方向**——
`SF5` B = curl C；`FM9` ω₀ = CurlZ/2；`FM10` ω₀ = B_z/2。
所以「自旋轴 vs B 的夹角 θ」是现成的可观测量。

**最小扩展**：`anchoredMass s ε θ := s·(1 + ε·cos θ)`，ε = 新耦合常数。

**合法性检查（不过就是破坏对称性）**：

- 依赖的是**相对夹角** ⟹ 自旋与流动**一起**转动时不变 ⟹ **不破坏转动不变性** ✓
- 它破坏的是**单独的自旋转动** ⟹ 与「磁场挑出一个轴」同类；磁化等离子体本就不各向同性 ✓

**这是新假设（模型选择），不是推导。** 按仓库规矩它必须带着自己的死法：

- **★ SA7 `spinMassRatio_zero`**：**ε = 0 ⟺ 两态质量相同 ⟺ 无任何可观测效应** ← 失败判据
- `spinMassRatio_gt_one`：任何 0 < ε < 1 都给出严格劈裂
- `two_eps_le_spinMassRatio_sub_one`：比值超出 1 的部分 ≥ **2ε**（「劈裂 = 2ε」的严格形式）
- `anchoredMass_up/down/isotropic`：θ = 0 / π / π/2 三个取值

## 3. 与既有判决量 D1 合流

既有 D1（生死门 G1/M6）：`R_ci = 1/(1−μ) − 1`。
加自旋轴后：`m_eff = s(1−μ)(1 + ε cos θ)`，`ω_ci ∝ 1/m_eff`（FC9）

- **★★ SA8 `Rci_spin_split`**：`R_ci(↑) − R_ci(↓) = −2ε/((1−μ)(1−ε²))` ← 本应用的核心数
- **★★ SA9 `spin_split_amplified`**：劈裂大小 **≥ 2ε**，被 **1/(1−μ)** 放大
  ⟹ **μ 越大（越接近判决门槛）自旋轴越容易看见** —— 与 D1 判决**同向**，不竞争
- `RciAt_isotropic`：θ = π/2 退回各向同性
- **`spin_effect_vanishes_iff`**：两种「看不见」的方式 —— 耦合为零**或**取向垂直

数值（解析 vs 数值最大相对偏差 **5.4e−12**）：

| μ | ε | R_ci(↑) | R_ci(↓) | 劈裂 | 下界 2ε |
|---|---|---|---|---|---|
| 1e−4 | 1e−3 | −0.000899 | +0.001101 | −0.002 | 0.002 |
| 1e−2 | 1e−3 | +0.009092 | +0.011112 | −0.002 | 0.002 |
| 0.1 | 1e−4 | +0.11110 | +0.11112 | −2.22e−5 | 2e−4 ⟵ 放大 1.11× |
| 0.5 | 1e−4 | +0.99998 | +1.00002 | −4.00e−5 | 2e−4 ⟵ 放大 2.0× |

**它是加在现成生死门 G1/M6 上的一根轴，不是新实验**：同一台装置、同一套诊断、多一个旋钮。

## 4. 诊断门槛（这是要花钱花时间的地方）

回旋频率（质子）：B = 5.3 T ⟹ ω_ci/2π = **80.80 MHz**；B = 9 T ⟹ **137.21 MHz**
（都在现成射频诊断范围）。

但 **Doppler 展宽 ≈ v_th/c** 决定 ε 的可见门槛：

| T_i | v_th/c | 可分辨 ε ≥ |
|---|---|---|
| 1 keV | 1.46e−3 | **1.5e−3** |
| 10 keV | 4.62e−3 | **5e−3** |
| 100 keV | 1.46e−2 | 1.5e−2 |

诊断阶梯：

| 诊断 | 可分辨 ε | 定位 |
|---|---|---|
| 热等离子体谱线（T_i = 10 keV） | 4.6e−3 | 现有聚变装置：太粗 |
| 热等离子体谱线（T_i = 1 keV） | 1.5e−3 | 低温测试台：勉强 |
| 冷离子束 / 低 T_i 诊断（T_i ≈ 100 eV） | 4.6e−4 | 小型判据台：推荐起点 |
| **单粒子回旋共振 / Penning trap 单离子** | **1e−6** | **首选**（线宽由仪器而非温度决定） |

**结论：要看见自旋劈裂，需要的不是更准的频率计，是更冷 / 更窄线的诊断。**
第一步应放在能控线宽的小装置上，不是聚变装置。

## 5. 诚实边界（4 层）

- **① 数学恒等**：SA2–SA6 是范数在酉/交换下的不变性；SA8/SA9 是 ℝ 上有理函数的一次代数
  （`field_simp` + `ring`）。真但平凡。
- **② 结构对应**：锚定 = 旋量范数 = MC1'/MC4' 的既有内容；夹角耦合 = 各向异性介质（磁化等离子体）的标准结构。
- **③ 数值匹配**：SA1–SA5 全机器精度（验恒等本身）；诊断门槛用真实常数（q, m_i, c）。
- **④ 概念重构**：**「现在的自旋应用为零」被写成定理**（这是本页唯一的新东西）；
  开口那一步是**新假设**，不是推导。

**缺口登记（不许混进 PASS）**：
1. **ε 是被测的量，不是被预言的量。** 本页给「劈裂的形式 + 死法」，**不给数值预言**。
   属判决类（档 3），不属推导类。**这就是为什么没有新可检验预言的数值。**
2. 从 MC1' 推出「锚定该对夹角敏感」这一步**没做**，而且不好做：
   σ₁ 是酉的，酉作用天生对方向不敏感 —— 要让夹角进来，可能需要把 σ₁ 换成
   「带权 / 投影型」的耦合，那会**动到 MC1' 本身**（改公设）。
3. 极化燃料端（已知的 ~1.5× 截面增益、³He 亚稳态交换光抽运、D 原子束源）**本页未登记文献与装置清单**。
