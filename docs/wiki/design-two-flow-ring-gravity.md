# 双流环产生的引力场

## 0. 目标校正（leo 2026-10-02）

> 「**要的是双环方案产生的引力场，不是 FRC。**」

在此之前我把这条线当成**磁约束/场反位形**在做（零场面、分界面、闭合磁面、芯部几何）——
那算的是磁位形，**不是目标**。本页把目标改回框架本来的那句话：

**双流环方案要产生的是引力场**（μ 场 ⟹ 质量/引力响应被取消），FRC 只是历史上顺手引来的参照。

## 1. 框架里的链（全部已证，本页只组装）

| 环节 | 内容 | 出处 |
|---|---|---|
| **SLS6** | **引力 = 空间流动的非均匀性** | 公设层 |
| **GCA2** | 命题「**A 内引力关闭**」⟺ **Q_A = 0**（A 内流动起伏被抹平） | GravityControl |
| **PA3** | 双流形叠加：两股流的空间场**线性相加** C = C₁ + C₂ | PlasmaAntiGravity |
| **DR2b** | 反向环流抵消：Γ(v) + Γ(−v) = 0 ⟹ **\|Γ_H\| = \|Γ_Cu\|、反号** | PlasmaDynamics |
| **MUFC** | μ ← μ + η(1−μ)，**η = 抹平进展 = 1 − Q_A(v)/Q_A(v₀)** | MuFieldCoupling |
| **AMC1** | **m_eff = s(1−μ)** ⟹ 引力响应按 (1−μ) 缩小；μ=1 ⟹ 关闭 | MassCancellation |

⟹ **「双环产生的引力场」= 两股反向环流叠加后把目标区 A 的空间流抹平了多少**：

```text
Q_A(C) = Σ_{i∈A} |C_i − C̄_A|²           （GCA2 的判定泛函，越小 = 引力越关闭）
η      = 1 − Q_A(C_Cu + C_H) / Q_A(C_Cu) （加 H 环买到多少抹平）
μ_n    = 1 − (1−η)^n                     （MUFC 闭式；η=1 ⟹ 一步到 1，TD12）
引力响应 (1 − μ_n) = (1−η)^n              （AMC1：m_eff/s）
```

**环流的空间流模型**：取涡丝 Biot–Savart 律（与磁场同形式，系数 Γ/4π 代替 μ₀I/4π）；
Γ 由 DR2b 锁成一对 ⟹ **环流速度不是自由参数**（v_H·R_H = v_Cu·R_Cu）。

## 2. 结果

### 2.1 地基自检（决定性）

**同半径 + 反环量**的两环，其空间流**精确抵消**：

```text
Q_A(抵消对) = 0.000e+00      vs      Q_A(单 Cu 环) = 3.688e+02      ⟹ η = 1.000000
```

⟹ 「反向环流抵消」（DR2b）在**流场**上成立；η=1 时按 TD12 **一步 μ=1**，A 内引力关闭。

### 2.2 ★ 按 FRC 挑的几何给不出引力关闭（本轮的直接后果）

已定设计（R_Cu = 0.60 外环 / R_H = 0.35 内环，即**为场反位形而挑的半径差**）：

```text
Q_A(单 Cu 环) = 3.6875e+02   →   Q_A(Cu + H) = 7.9407e+03        η = −20.53  <  0
```

**加 H 环反而让目标区的空间流更不均匀** ⟹ 该几何**一点引力关闭都没有**。
（不是符号错：单 H 环自己 Q_A = 1.105e+04 更大，两个环一起是 7.94e+03 —— 确实在抵消，只是**远远不够**。）

### 2.3 η(R_H) 是**单峰**，峰在 R_H = R_Cu

共面细扫（步长 0.02 m）：

| R_H [m] | 0.48 | 0.50 | 0.56 | 0.58 | **0.60** | 0.62 | 0.70 | 0.84 |
|---|---|---|---|---|---|---|---|---|
| η | −0.008 | +0.417 | +0.943 | +0.988 | **+1.000** | +0.991 | +0.856 | +0.582 |

左升右降、峰恰在 R_H = R_Cu ⟹ **径向匹配是流抵消的充要条件**（不是「越近越好」的单调关系）。

### 2.4 容差（实测，两个方向；这是「有缺口也能推进」的空间）

| 方向 | η ≥ 0.5 | η ≥ 0.9 |
|---|---|---|
| **径向** \|R_H − R_Cu\| | **≤ 0.240 m**（= 40% of R_Cu） | ≤ 0.060 m |
| **轴向**分离 d | **≤ 0.05 m** | — |

轴向细扫 η(d)：0.05 → **+0.787**、0.10 → +0.233、0.20 → −1.168、0.30 → −2.198、0.50 → −2.938
⟹ **轴向共面性比半径匹配苛刻得多**（η>0 大致要求 d ≲ 0.13 m）。

### 2.5 引力关闭曲线（容差表）

达到 μ = 0.99（工程表：τ_E ×10）所需次数 n：

| η | 1.0 | 0.99 | 0.9 | 0.5 | 0.2 |
|---|---|---|---|---|---|
| n | **一步到 μ=1** | 1.0 | 2.0 | 6.6 | 20.6 |

⟹ **η > 0 是硬门槛**（η ≤ 0 ⟹ 永不关闭）；η 掉到 0.5 仍只要 7 步 ⟹ 对 η 的精度要求不苛刻。

## 3. 两条目标互相拉扯（本页最重要的设计结论）

| 目标 | 对半径的要求 |
|---|---|
| **FRC**（场反位形） | 两环**半径必须不同**（否则不产生反向场） |
| **引力场**（本页） | 两环**半径必须相同**（否则流不抵消，η ≤ 0） |

⟹ leo 的「要引力场，不要 FRC」有一条直接的、可算的后果：
**半径不该按 FRC 挑**。按引力目标，两个反向环流的**半径、轴向位置都要对齐到容差内**
（径向 40%、轴向 ≲ 4% of 装置尺度）。

## 4. 死法（可判）

| 死法 | 判据 | 现状 |
|---|---|---|
| 半径不匹配 | \|R_H − R_Cu\| > 0.24 m ⟹ η < 0.5；> 0.42 m ⟹ η < 0 | 已扫（η=0 在 R_H ≈ 0.48） |
| 轴向分离过大 | d ≳ 0.13 m ⟹ η ≤ 0 | 已扫（0.20 → −1.168） |
| 环量不比 | \|Γ_H\| ≠ \|Γ_Cu\| ⟹ 抵消不完整 | DR2b 锁（未扫非对称情形） |
| 流模型失效 | 若真实空间流不是涡丝律，η 的数值要重算 | **未做**（见 §5） |

## 5. 诚实边界

- **环流 ⟹ 空间流**是**结构对应层**（标准涡丝速度律，与磁场同形式）；流场的**绝对幅度 v 不由框架定**
  （只有比值被 DR2b 锁）。η **不含** v 的绝对值 ⟹ 本页结论是**几何效率**，不是时间尺度。
- **「η = 抹平进展」按 MuFieldCoupling 原文是模型选择**（该模块自己写明），不是从物理推出的。
- **抹平功率从哪来** = **第二输入缺口（档 3，未变）**：本页算的是「几何能给多少」，不是「多久给到」。
- 目标区 A 是**口径**（r ≤ 0.30 m、\|z\| ≤ 0.26 m）；η 随 A 的形状/大小变（未扫 A）。
- 涡丝律在**导线附近**有近场奇异性（与上一轮同一问题）⟹ A 若贴近环，η 的数值要另处理。
- **无新物理预言**；**不含**等离子体动理学/MHD；**不含**μ 的主动产生机制。
