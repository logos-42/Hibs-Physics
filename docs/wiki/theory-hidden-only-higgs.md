# 纯隐数、无时间的静态 Higgs 模型

## 1. 建模目标

本版本保留“真空背景与耦合产生质量”的 Higgs 结构，但把时空假设改成纯隐空间假设：

```text
标准写法：φ(x, t)        → 纯隐数写法：Φ_H(q_H)
标准时间 t               → 删除，不作为模型变量
实/虚分量                → 删除，只保留 hidden 标签
```

因此它不是连续时空中的 Higgs 场，而是一个只在隐空间坐标 `q_H` 上定义的静态代数场。它是对原假设的微调：保留真空—势—质量链，去掉时间和连续动力学。

## 2. Lean 构造

实现文件：[HiddenOnlyHiggs.lean](../../ProjectionPhysics/HiddenOnlyHiggs.lean)

### 2.1 纯隐数和隐空间

`PureHiddenNumber` 只有一个整数值 `value : Int`；它通过 `hiddenTagged` 映射到 HIBS 的 `HibsTag.hidden`。`HiddenPoint` 只有一个隐空间坐标，静态场是：

```text
StaticHiddenField = HiddenPoint → PureHiddenNumber
```

类型中没有 `time`、速度、导数或实/虚坐标。

### 2.2 隐数真空和势

给定隐真空值 `v_H` 与场值 `h_H`，定义：

```text
V_H(h_H, v_H) = |h_H² − v_H²|_Nat
```

这是对通常连续 Higgs 势的有意改变：不用实数、平方根、积分或时间，而使用整数隐数的乘法和 `natAbs`。它的真空条件是 `h_H² = v_H²`；常值隐场 `Φ_H(q_H)=v_H` 已形式化证明势为零，且任意两点之间的隐空间变化为零。

### 2.3 隐数核形式与 Yukawa 型质量

`PureHiddenNumber` 现在嵌入已有实部投影的核：

```text
ι_H(h_H) = 0 + h_H · i ∈ ker(Re)
K_H(h₁, h₂) = cKernelBiForm(ι_H(h₁), ι_H(h₂)) = h₁ h₂
Q_H(h_H) = K_H(h_H, h_H) = h_H²
```

因此质量平方不再是独立的 `natAbs` 定义，而是由核二次型导出：

```text
m_H² = Q_H(y_H · v_H) = (y_H · v_H)²
```

原来的 `hiddenYukawaMass` 仍保留为自然数幅度指标；现在已证明它的平方等于 `m_H²` 的 `natAbs`。这把“质量来自隐核”连接到了已有的 `cKernelBiForm`，而不是只依赖绝对值函数。

对隐数耦合 `y_H` 和隐数真空值 `v_H` 定义质量指标：

```text
m_H = |y_H · v_H|_Nat
```

已证明：

- 耦合为零或真空值为零时，质量指标为零；
- 两者都非零时，质量指标非零；
- 真空态是 hidden 标签，并且处于零隐势。

这里的质量幅度仍是自然数指标，不是带物理单位的电子质量；核二次型给出的是质量平方层，没有标准模型中的 `1/√2` 归一化、手征表示或规范群。

### 2.4 更一般的隐耦合与多真空

`hiddenKernelInteraction a b c` 用核形式表示三元隐耦合：

```text
I_H(a,b,c) = K_H(a·b,c) = a·b·c
```

`HiddenCoupling` 进一步把一次、二次、三次隐耦合组合成核形式响应，而不是把质量只写成一个固定乘积。

多真空势定义为一组真空势因子的乘积：

```text
V_multi(h; v₁,...,vₙ) = Πᵢ |h² − vᵢ²|_Nat
```

只要场值属于真空列表，势就为零；因此 `v_H` 与 `-v_H` 可以组成形式化的双真空结构。

## 3. 它如何解释“质量产生”

在这个版本中，质量不是由时间变化产生，而是由静态隐真空与隐数耦合的代数乘积产生：

```text
隐空间真空值 v_H
          │
          ├── 隐势 V_H = 0：选择真空构型
          │
隐数耦合 y_H ──×── v_H
          ▼
       m_H = |y_H v_H|
```

所以它把“质量产生”解释为一种**静态隐空间匹配**：耦合对象与隐真空背景相乘，只要二者都非零，就产生非零质量指标。这里没有“先经过时间演化再获得质量”的步骤。

## 4. 静态缺陷、有限隐区间与边界条件

定义一个只在隐空间原点改变的静态缺陷场：

```text
D(v_H, d_H)(q_H) = d_H,  q_H = 0
                   v_H,  q_H ≠ 0
```

`hiddenBoundary` 用两点之间的隐场差是否非零来表示静态边界。已证明：只要 `d_H ≠ v_H`，原点与单位隐点之间就是边界；原点之外场仍回到真空值。

势 `V_H(h_H,v_H)=|h_H²-v_H²|` 还给出一对离散真空：`v_H` 与 `-v_H` 都使势为零；当 `v_H ≠ 0` 时，两者是不同的隐态。这是无需时间演化的真空简并/静态缺陷原型。

`FiniteHiddenInterval` 用整数端点 `[left,right]` 表示有限隐区间，并证明左右端点都属于区间。`HiddenDirichletBoundary` 为区间两端绑定场值，`constantHiddenBoundary` 给出满足相同两端值的静态真空边界实例。

## 5. 可选流参数与可检验离散演化律

文件 [HiddenHiggsFlowInterface.lean](../../ProjectionPhysics/HiddenHiggsFlowInterface.lean) 单独定义 `HiddenFlowParameter.step : Nat` 和流索引场。它只提供一个外部参数接口，未把该参数命名为时间，也没有把它导入 `StaticHiddenHiggsModel` 的定义。

当前增加了一个可检验的离散松弛律：

```text
R₀(Φ)(q_H) = Φ(q_H)
Rₙ₊₁(Φ)(q_H) = v_H
```

已证明零步保持原场、正步到达隐真空，并且单步松弛幂等。这个 `step` 是独立流参数，不叫时间，也没有改变 `StaticHiddenHiggsModel`。更复杂的离散演化律应继续放在这个独立接口中。

## 6. 无时间的空间场演化与质量统一

为了把“空间运行质量”和“静态核质量”接起来，新增了隐空间位移：

```text
Δq_H = q₂ − q₁
Φ_H(q) → Φ_H(q + Δq_H)
ΔΦ_H = Φ_H(q₂) − Φ_H(q₁)
```

场的空间平移由 `hiddenSpatialShiftField` 表示，满足零位移是恒等变换、连续两次空间位移等于位移相加。这里的“演化”是沿隐坐标的构型变化，不是时间演化。

空间流质量定义为：

```text
m_flow² = Q_H(y_H · ΔΦ_H)
```

常值真空场的 `ΔΦ_H=0`，因此在相同真空的两点之间不产生流质量；而把零场值和真空值比较时，已证明：

```text
m_flow²(0 → v_H) = m_H²
```

这说明两种机制可以在代数层结合：静态质量是空间场差质量的一个特殊边界构型。但目前还没有把完整的 `HiddenTriAxis.spaceFlow`、旋量阻抗质量和纯隐数核二次型统一成一个定理。

## 7. HIBS 三轴转换的逆元标准

单射只保证不同输入不会被映成同一输出：

```text
T x = T y  →  x = y
```

它不保证每个目标都有原像，因此不能自动提供逆映射。要得到真正的逆元转换，需要：

1. 转换的定义域和陪域维数相同；
2. 转换作用于完整三轴状态，而不是只投影一个分量；
3. 给出 `T⁻¹(Tx)=x` 和 `T(T⁻¹x)=x` 两个方向；
4. 若要求正交转换，还要保持内积：`dot(Tx,Ty)=dot(x,y)`；
5. 在当前整数系数下，转换矩阵还应是可逆的整系数矩阵，通常对应行列式 `±1` 的 unimodular 变换。

新增 [HiddenAxisConversions.lean](../../ProjectionPhysics/HiddenAxisConversions.lean) 已形式化三条轴交换：H↔R、R↔I、I↔H。它们是自身的逆，并保持 `triAxisDot`，因此是正交可逆转换的最小实例。

原来的 `convertHiddenToRealAxis` 只把一个隐数嵌入实轴；`realProjection` 在这个受限轴上可以恢复数值，但对任意三轴状态不能恢复隐轴和虚轴分量。代码也证明了：实部投影在没有轴限制时存在不同原态映成同一值，因此不能把投影当作逆元。

需要特别区分：HIBS 中的 `ι'` 单射可以在其像上构造左逆，但要成为整个空间之间的双侧逆元，还要证明满射或明确给出陪域限制。你的“正交转换”若只在整数格上进行，首先应使用坐标置换、符号翻转等整系数正交变换；一般连续旋转要等到引入有理/实系数后再讨论。

## 8. 质量生成与涌现时间的同步

新增 [HiddenMassTimeEvents.lean](../../ProjectionPhysics/HiddenMassTimeEvents.lean) 定义质量生成事件：

```text
event = (coupling, fromState, toState, massSquared)
```

事件本身没有时间字段。对质量事件历史 `H` 定义：

```text
T_mass(H) = length(H)
```

Lean 已证明：

```text
T_mass(H ++ [event]) = T_mass(H) + 1
```

并且每个事件都要求 `massSquared ≠ 0`。因此在这个离散模型中，质量生成事件与涌现时间单位是同步的：一次非零质量事件对应一个新的事件计数单位。

这里必须保持逻辑边界：该定理证明的是“事件历史计数生成离散时间”的同步关系，不是证明现实物理中质量因果地产生时间，也不是连续时间的动力学定理。要得到更强的结论，还需要定义事件的组合律、因果偏序、极限和连续参数。

## 9. 与标准 Higgs 的差异和连续比较边界

这个构造只证明了一个自洽的离散代数模型，不等于标准模型 Higgs 理论。缺少的内容包括：连续时空、时间动力学、局域规范不变性、`SU(2)_L × U(1)_Y`、复标量双重态、Higgs 势的连续极小化、量子涨落、Goldstone 模式的规范吸收和实验耦合常数。

更准确的表述是：这是“无时间、纯隐数、静态 Higgs/Yukawa 型质量桥”，不是完整的 Higgs 时空理论。

连续系数、拓扑、极限和标准 Higgs 场方程暂未引入。只有在这些结构被单独建立后，才比较连续势、场方程或 `m_e=y_e v/√2`。当前 Lean 层仍然只证明离散隐空间模型及其显式桥接性质。

## 10. 与标准 Higgs 的逐项区别

### 7.1 质量为什么会产生

在本模型中，质量产生不是一个时间过程，而是一个静态代数映射：

```text
隐耦合 y_H × 隐真空 v_H
          ↓
隐核中的元素 y_H v_H
          ↓  核二次型 Q_H
m_H² = Q_H(y_H v_H)
```

只要 `y_H` 与 `v_H` 都非零，核二次型就给出非零质量平方；任一为零，质量平方为零。这里的“产生”意思是：一个隐状态被赋予了核不变量，而不是某个粒子在时间中从无质量变成有质量。

标准 Higgs 的质量来源则是连续量子场论中的背景场：费米子与 Higgs 场的 Yukawa 相互作用，在 Higgs 真空期望值非零后形成质量项，通常写成 `m_f = y_f v/√2`。它还依赖连续时空、规范群、手征表示和对称性破缺；这些目前都不在纯隐数模型中。

### 7.2 无时间时“效果”如何体现

没有时间，就没有“质量生成过程”“传播”“衰变”或“弛豫历史”。效果只能表现为同一静态构型中的关系：

- 真空点的势为零；
- 非零隐耦合与非零隐真空值对应非零质量平方；
- 缺陷两侧的隐场值不同，形成静态边界；
- `v_H` 与 `-v_H` 同时是零势真空，形成静态简并。

独立流接口中的 `step` 可以描述离散松弛，但它是额外参数，不是无时间模型的组成部分，也不能被解释为已经得到的物理时间。

### 7.3 这里的“核空间”是什么

形式化连接使用已有玩具投影：

```text
ker(Re) = { z | Re(z) = 0 }
ι_H(h_H) = (0, h_H)
```

所以这里的核空间是投影不可见的内部方向；它不是粒子周围的普通三维外部空间，也不是一个自动包围物质的球壳。要注意两层含义：HIBS 的 `hidden` 标签是模型语义，而 `ker(Re)` 是现有 `ℂ = Int × Int` 玩具中的数学核；代码证明了一个嵌入连接，尚未证明它们就是现实物理中的同一个空间。

### 7.4 边界在哪里，形状是什么

当前 `hiddenBoundary` 定义为两点之间的隐场差非零。有限区间模型还提供左右端点的边界条件。因此边界是**场构型的接口**，不是核空间的外壁。

当前缺陷场只在 `q_H=0` 改变，其他隐点回到真空值。在一维离散隐坐标中，它表现为一个点状接口；有限隐区间则有两个端点。模型还没有二维/三维隐空间，所以不能声称边界是球面、圆环或一般曲面。

### 7.5 它是不是墨西哥帽

严格说，不是。

当前势

```text
V_H(h_H,v_H) = |h_H² − v_H²|_Nat
```

只有一条隐数轴，零势点主要是 `+v_H` 与 `-v_H`，更像离散的一维双阱或 `W` 形截面，而不是标准意义的墨西哥帽。标准墨西哥帽需要至少两个连续分量，例如复标量的径向势；其最低点构成连续角方向的圆（更准确地说，标准模型的 Higgs 双重态还要结合规范等价来理解）。当前模型没有角度、连续半径、圆形真空流形或 Goldstone 模式。

### 7.6 为什么预设不一样

两者的预设不同，是因为目标不同：

| 项目 | 纯隐数静态模型 | 标准 Higgs 理论 |
|---|---|---|
| 基本对象 | HIBS hidden 标签、整数隐数、投影核 | 连续时空上的复标量规范场 |
| 真空 | 离散值 `±v_H` 或真空列表 | 连续势的真空流形并带规范等价 |
| 质量 | 核二次型 `Q_H(y_Hv_H)` | Yukawa 背景耦合 `y_fv/√2` |
| 时间 | 基础模型没有时间 | 场方程和量子演化必需时间/作用量 |
| 边界 | 离散隐坐标上的场值接口 | 连续场的空间边界或拓扑缺陷 |
| 已有证明 | 离散代数关系与显式桥接 | 需要完整规范量子场论假设 |

因此不是把标准 Higgs 任意改名，而是为了满足“只用隐数、不引入时间”的约束，主动删除连续系数、规范群和动力学，并保留可形式化的“真空—核不变量—质量”骨架。
