## 2. 流动空间四维化的三条设定

1. **流势** `C_μ(x)`：空间流动在每格点、每方向的势（标量版 `ℂ`，色版 `Mat3C`）。
2. **可观测量 = 流势的差**：能测的只有「流变了多少」，不是「流势本身取多少」。
   ⟹ **规范自由 = 流势可整体重标一个梯度** `C_μ ↦ C_μ + ∂_μχ`。
3. **场强 = 流势的旋度** `F_μν = ∂_μC_ν − ∂_νC_μ`；色版加 `[C_μ, C_ν]`
   —— 交换子项不是假设，「汇不交换」（YM2/CA3）就是它。

## 4. 这一版四维化真正的新内容

**只有一条**：F4D2 把「规范不变性」从**公设**降格为**流动前提的推论**。
标准 QFT 里 `A_μ ↦ A_μ + ∂_μχ` 是假设；在流动空间里它是「势只有差可测」的直接后果
（和「电荷 = 流散度」「场强 = 流的旋度」是同一句话的三种写法）。

**这条也是唯一可能被反驳的地方**（死法写死）：
若有人指出流动空间的**可观测量不止于流的变化率**（存在直接测流势本身的量），
F4D2 的**物理读法**即失效（数学定理仍成立）。这不是模糊的风险——它是一条可判死的边界。

## 4.5 「格子有连续性」这条反驳：一半成立，一半不成立（`FlowTopology.lean`，FT1–FT5）

leo（2026-11-01）：「空间本身的格子是有连续性的，因为电子的散度是有拓扑结构的」。
这句话混着两件事，分开各给一个定理：

**① 拓扑/整数那一半 —— 成立，而且比"取极限"更强**（`FlowTopology.lean`）

| 编号 | 定理 | 内容 |
|---|---|---|
| FT1 ★★ | `gauss_law_1d` | **格点 Gauss 定律**：盒内总荷 = 边界流之差（纯 telescoping，**不取极限**） |
| FT2 ★★★ | `charge_conserved_closed_box` | 离散连续性方程 + 闭盒 ⟹ 总荷**精确守恒**（无误差项、无重整化） |
| FT3 ★★ | `total_charge_boundary_only` | 总荷**只由边界决定**，内部重排不可见（= 拓扑性） |
| FT5 | `integer_charge_is_resolution_free` | 整数荷与分辨率无关（细分不改整数） |

⟹ 在**荷**这个层次，「格子有连续性」是真的：整数/守恒律是**精确**的，不需要 a → 0。

**② 度量那一半 —— 补不上**（FT4 `topology_does_not_fix_energy`）

同一个总荷 2：粗格 `[2]` 的 ∑ρ² = **4**，细格 `[1,1]` 的 ∑ρ² = **2**。
荷一样，能量差一倍 ⟹ **拓扑决定"哪一类"，决定不了"多大"**。
要让能量变成分辨率无关量，必须乘上**格距**（一个长度）—— 那是**度量输入**，不是拓扑不变量。

**结论**：a → 0 缺的是**度量**（一个长度尺），不是拓扑。拓扑能保证"粗算细算同一个整数"，
保证不了"‖F‖、谱、质量在细分下收敛"。这两件事不能互相替代。

## 5. 诚实边界

- **只到整体共轭**：F4D4 的 `g` 与格点无关。依赖格点的**局部**变换会多出 `∂_μ g` 项，

  （框架里没有），与 `YangMillsContinuum:311` 一致。
- **不声称**：不解决 Clay；不声称禁闭；不声称 λ/M₀ 被推导；无新数值预言。
