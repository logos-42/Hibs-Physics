# 按整数条数记账（MB1–MB7）

> leo（2026-11-01）：「可以按整数的条数来计算，形式化测量一下」。
> 前一轮的结论是「质量比是错觉，要算条数和对空间的变化率」——本页接受这个口径，
> 把「整数条数」的记账法能说与不能说，全部变成定理 + 测量。

## 1. 记账法

一个扇区 = **整数条数 N** × **每条标定单价 λ**；每条携带固定能量 ⟹

```
m = √N · λ        （即 m² = N·λ²，与 MassGap.strandMassSq 同形）
```

注意：这条与「质量 = 条数」（线性）不同。线性读法已被数据否掉——
若 m = N·m₀（m₀ = m_e），1.6–2.6 GeV 区间应有 **1920 个态**，实测 ~4 个（差 480×）；
平方读法给出 N ∈ [2.7, 6.9] ⟹ 可达集只有 {3, 6} ⟹ 3 个态，与实测吻合。
**所以「质量 = 条数」的正确量纲位置是「能量² ∝ 条数」。**

## 3. 测量结果（`scripts/verify_mass_bookkeeping.py`）

**MB-M1 单一单价的有理逼近**（q = N₂ ≤ 60 逐个试，偏差折算成测量精度 σ = 10⁻⁹ 的倍数）：

| 比值 | 最佳 q | 相对偏差 | 偏差/精度 |
|---|---|---|---|
| m_p/m_e | 25 | 1.3×10⁻⁴ | **1.3×10⁵ ×** |
| m_μ/m_e | 57 | 4.3×10⁻⁵ | **4.3×10⁴ ×** |
| 胶球 0++/m_e | 45 | 9.6×10⁻⁵ | **9.6×10⁴ ×** |
| m_τ/m_e | 45 | 2.5×10⁻⁴ | **2.5×10⁵ ×** |

**MB-M2 单一单价的「两只角」（都断）**：

- **角 A**（守仓库自己的可达集 N ≤ 109）：单一单价最多造出 √109 = **10.4 倍**；观测到的最小质量比是 **206.8**（μ/e）⟹ **差 20×，够不到**。
- **角 B**（硬凑）：要凑出 m_p/m_e 需 N_p ≈ 3.4×10⁶；那时 1.6 GeV 附近格距 = m/(2N) ≈ 10⁻³ MeV ⟹ 该区间应有 **10⁶ 量级**的态，实测 ~4 个。

**MB-M3 两价模型的退化**：任意质量 + 任意条数，反解 λ = m/√N，残差 **0.00**（不可证伪）。
**MB-M4 扇区内的纯度**：胶球阶梯比值对 λ = 0.1 / 987.3 / 10⁶ 三组取值**逐位相同**。

## 4. 判决

> **要么 λ 由结构推出（本仓库没有），要么跨扇区质量比就是输入。**

三条路，只有第一条活：
1. **单一单价**：被 MB-M1（10⁴–10⁵ σ）+ MB-M2（两只角）否掉。
2. **两价模型**：MB-M5 证明它拟合一切 ⟹ 自我取消（不可证伪）。
3. **λ 由结构推出**：仓库里**没有任何**推导（子智能体查实：λ 在 Lean 里始终是 `lam : ℝ`，
   脚本里明写「第二输入缺口，不是推导值」）。

**框架的诚实适用范围**：**一个扇区内的谱形状**（MB-M2 的纯数预言，胶球阶梯 5/7 即此），
**不是跨扇区质量比**。这句话不需要道歉——标准模型里 m_e 也是汤川耦合的输入，
m_p/m_e = 1836 到今天没有任何第一性推导。

## 5. 诚实边界 / 死法

- 「N 为整数」是框架公设（输入），不是本页证明的。
- σ = 10⁻⁹ 是保守取值；实际 m_p/m_e 精度更高，故否决只会更强。
- **死法**：若有人给出 λ 的结构推导且它让 MB-M4 的有理逼近在 q ≤ 60 内命中，本页判决被推翻。
- 本页不产生 λ，也不声称解释 m_p/m_e。
