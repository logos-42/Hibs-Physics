# FRC 迭代版紧凑装置——10cm 可行性转折报告

## 转折点：为什么 10cm 从"死刑"翻案

此前（PlasmaFusion 轮）判 10cm 死刑的三个理由，在 FRC 现实基础下全部动摇：

| 旧死刑理由 | 前提 | FRC 现实 | 新判 |
|---|---|---|---|
| 功率被 β×体积锁死 | β=5%（托卡马克） | **β≈1**（FRC 高 β 位形） | ✓ 功率 ×400 |
| 劳森需 μ≥0.9999998 | τ 需求 2s（低 n） | 高 n ⟹ τ 需求降 3 个量级 | ✓ μ≈0.999 够 |
| 磁体塞不下 | 铜磁体体积>球 | HTS/外置线圈 + 脉冲压缩 | ✓ 12cm 已实现 |

**现实锚点（Slough 2025, Nucl. Fusion 65 106019）**：MSNW/Helion 的 CFR2
方案——分段压缩 FRC，末级 **12cm 直径燃烧室**、真空场 7-9T 压缩到 **35T**、
2-5ms 脉冲、3.5 MJ FRC → D-T 产额 20-40 MJ/脉冲、**增益 G~10**。
论文核心标度律：**G ~ φ_p·B_e² 与径向尺度无关**——小型化没有固有劣势。
（诚实标注：12cm 只是末级燃烧室，完整装置是 ~0.8m 形成室 + 10 级压缩
线圈 + 3-6m 燃烧室的脉冲管线；这是概念设计 + 实验验证中，非已建成堆。）

## FC5 锁定定理：本轮最重要的修正

```
S*(μ)/S*(0) = τ_E(μ)/τ_E(0) = 1/√(1−μ)
```

**不可能只改善约束时间而不等比例抬高 s 参数。** 上一轮"μ≥0.9997 ⟹ τ_E×58 ⟹
劳森闭合"只算了输运一侧；FRC 的动力学稳定性（S*/E ≲ 3–4 经验边界）会在
**同一因子**上恶化。更糟的是 FC10 推论：为了把 S* 压回预算内必须同步降 B，
而降 B 的损失（∝B³）快过输运收益（∝1/√m）——**纯靠 μ 缩小装置是死路**。

这与 FRC 现实认知一致：TAE/Helion 实际走的是**高场 + 大轨道离子（NBI）**
来稳定（大 orbit 离子提升 S* 稳定性），不是质量取消。仓库理论的 FRC 迭代
版本应该同样以"高 B、快脉冲、大轨道离子"为稳定手段，μ(t) 只作辅助。

## 现实锚点验证（CFR2 参数代入）

### β=1 功率翻案（10cm 球，V=4.2L）

| B | 托卡马克(β=5%) | FRC(β=1) |
|---|---|---|
| 5.3T | 0.01 MW | 4.2 MW |
| 9T | 0.09 MW | 34.5 MW |
| 12.2T | 0.29 MW | 116.6 MW |
| 15T | 0.67 MW | 266.4 MW |

### 脉冲模式（MSNW 路线）——高 n 直接点火

- 压缩场 35T、β=1：n ≈ 1e23 m⁻³
- 2-5ms 脉冲劳森：nτT ≈ 4.6e24 ≫ 需求 3e21 ✓（差 1500 倍余量）
- 3.5 MJ FRC → 20-40 MJ/脉冲，G~10 ✓（论文值）

### 稳态模式（仓库 μ 迭代）

- β=1 高 n 压低 τ 需求：B=9T ⟹ 只需 τ_E ≥ 30ms
- 10cm FRC 实际 τ_E ~1ms（尺寸标度）⟹ 需 μ 补 ~30 倍 ⟹ **μ≈0.999**
- μ 容差从 1.6e-7（旧环路线）放宽到 1e-3——**三个数量级**

### 机械门（FC8，反解 PF7）

- B² ≤ 2μ₀σ_y·t/R_c：小环允许更高 B（Helion/TAE 走高场小环的工程杠杆）
- R=10cm、t=1cm、σ_y=1GPa（高强钢+外支撑）⟹ B_cap ≈ 15.8T
- 35T 压缩场是脉冲的（电容储能，瞬时应力由惯性/外结构承担）——与稳态 15T 上限不矛盾

## 仓库理论 × FRC 映射

| FRC 现实技术 | 仓库对应 |
|---|---|
| θ-pinch 时变磁场（形成） | PA4：时变磁场⟹时变空间场⟹时变 μ(t) |
| RMF 旋转磁场（维持） | SF6 螺旋边界（两方向参与） |
| 分段压缩（10 级递减线圈） | PF9 调制控制力 + 双流形慢/快流 |
| β≈1 高密度 | 质量取消辅助（非主稳定手段） |
| NBI 大轨道离子 | 双流形大轨道快离子（PA3 慢+快流） |
| 自然偏滤器（开磁力线） | AMC7 切向流捕获（无径向逃逸） |

**"变化的电磁场"是双向桥**：FRC 需要它形成/维持/压缩等离子体；仓库 PA4
需要它作为 μ(t) 的产生载体。机制同源，这是 FRC 迭代版成立的物理基础。

①**10cm 理论上可行吗？** FRC 现实基础下可行——β=1 功率 ✓、高 n 劳森 ✓、
μ≈0.999（容差 1e-3）✓、机械门 15.8T ✓、12cm 燃烧室已有论文方案（CFR2）。

但 **FC5 锁定定理证明 μ 不能是主杠杆**（S* 同因子恶化），稳定必须靠

③**之前验证为何修正？** 上一轮 μ≥0.9997 输运解锁漏了稳定性一侧；
FrcCompact 用 S*/τ_E 锁定补齐——同一 μ 不能既改善输运又不破坏稳定。

## 诚实边界（四层）

- **数学恒等**：FC1–FC10 是标度/锁定/不等式（n=βB²/4μ₀kT、S*²ρ²=βr_s²/2、
  τ∝1/√(1−μ)、B²≤2μ₀σ_yt/R_c）——真但平凡
- **FRC 工程映射**：s 参数稳定边界（S*/E≲3-4）、Bohm 系数 f_B、材料 σ_y
  是数值层经验输入；Grad-Shafranov 平衡 / Hall-MHD 稳定性未形式化
- **现实锚点诚实**：CFR2 是 2025 概念设计+实验验证中（形成/加速已验证，
  全流程燃烧未演示）；12cm 是末级燃烧室非整机
- **开放缺口**：μ 主动产生机制 = 第二输入缺口（未变）；**μ 对核反应率
  ⟨σv⟩ 的影响（v_th ∝ 1/√m_eff ⟹ 反应率可能变）未建模**——新增缺口；
  μ(t) 时变与分段压缩脉冲时序的耦合未分析
- **无新物理预言**——价值 = FRC 现实锚点 + 稳定性锁定定理（4 层判定：
  数学恒等 + 工程映射）
