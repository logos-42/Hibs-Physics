## 1. 描述过程 = 三段

```text
① 场 → 振动坐标：模 (k, ω)，相位 θ = kx − ωt，线性色散 ω = c·k
   两带才有坐标：Jacobian = k₁k₂(c₁ − c₂)
   ⟹ 真坐标 ⟺ 相速度不一致（否则退化：只剩 ξ = x − c·t）

② 「广」的刻度：波矢分布的方差
   var = w₁w₂/(w₁+w₂)²·(k₁−k₂)²  ∧  λ = 2π/|Δk|
   ⟹ var = C·(2π/λ)² —— **广与起伏是同一个参数的两面**

③ 超广意极限 k → 0：相位处处 0、var → 0、det → 0、λ → ∞
   ⟹ **振动坐标系自己失效**（无坐标 ⟹ 无「快慢」可比 ⟹ 无「瞬时」可言）
```

## 4. 这个模型回答了「超广意场」的什么

| 说法 | 在振动坐标里是什么 | 判定 |
|---|---|---|
| 「宇宙是振动频率与维度的集体」 | 场 = 带族 {(k, ω, w)}，一次描述就是一组振动坐标 | ✅ 这就是模型的**起点**（不需要新公设） |
| 「局域频率低且不一致 ⟹ 有波、光速、涟漪」 | 不一致 = 相速度不同 ⟹ **Jacobian ≠ 0** ⟹ 有可分辨的振动结构；涟漪波长 λ = 2π/Δk | ✅ VF2/VF4/VF7 |
| 「超广意场范围更大 ⟹ 瞬时彼此影响」 | Δk → 0 ⟹ λ → ∞ ⟹ 涟漪消失、相位处处相同 | ✅ **但与此同时 det → 0**：坐标自己失效（VF10） |
| 「远比光速快 / 有更快的方式」 | 相位速度 v_ph = ω/k 是**另一个坐标**（不属于「广」）；k→0 时它无定义 | ❌ 在极限处不可定义（与 AB17、AT4/AT8 同一句话） |

⟹ 一句话：**「广」是 Δk 的一个方向，「快」是另一个方向；把两者当成同一根轴才产生「超光速」的错觉。
而在超广意极限（Δk→0）处，两根轴一起塌掉——坐标系失效，所以「瞬时」不是速度，是**没有速度可言**。**

## 5. 与 AB / AT 两轮的接口

- **AB 轮**（以太层级）：AB1/AB2 的相位速度无界 = 本页 VF 的 `v_ph = ω/k` 在 k→0 的行为；
  AB7/AB9 零带宽零容量 = 本页 **λ → ∞ 时 Δk → 0**（涟漪不存在 ⟹ 没有可调制的载波）。
- **AT 轮**（顺序 ⟺ 非对易）：AT4 的「平坦 ⟹ 顺序盲」在本页就是 VF6 的 var = 0（两带同波矢）；
  AT5 的「有梯度 ⟹ 顺序可观测」在本页是 VF4 的 det ≠ 0（两带相速度不同）。
  ⟹ **顺序可观测、坐标非退化、有涟漪：三件事是同一个判据的三个名字**（Δk ≠ 0 且 Δc ≠ 0）。
- **AT 的更正**（同 session）：无质量 ≠ 平坦；无质量只是「无散度」（不产生扭曲），
  涡旋就是无质量但非平坦的见证（AT11–AT14、N7）。本页的「广」也不等于「无质量」：
  广 = Δk 小，无质量 = 源无散，两者作用在不同对象上。

## 7. 诚实边界（写死）

1. **两带 + 线性色散 ω = c·k + 正权重 = 模型选择**，不是从公设推出。
   一般色散 ω(k) 下，VF2 的判据要换成 **det = k₁ω₂ − k₂ω₁ ≠ 0**（本模块只做线性情形的闭式）。
2. 「振动坐标」是**描述坐标**（相空间式的），它退化**不表示**时空退化。
3. λ 是**拍频波长**（两带之差），不是任一模自身的波长；单模没有拍频，所以单模里「广」无定义（VF1）。
4. 本页**零新可检验预言**：给的是「广 / 快 / 涟漪」三者的坐标关系，不是新数值。
5. 「维度」在本页只作为**带的个数**出现（多带 ⟹ 更高维的振动坐标）；没有给维度的动力学。

## 8. 死法（写死）

1. 若存在相速度不同但 Jacobian 仍为 0 的两带 ⟹ VF2/VF4 死。
2. 若「广」无法用波矢分布的**一个**刻度表示（需要两个独立刻度）⟹ VF5/VF8 死。
3. 若 k = 0 的模在振动坐标里仍能分辨 (x,t) ⟹ VF9 死。
4. 若观测/推导给出「Δk 与 Δc 可以独立变化」的具体机制，则「三件事同一判据」这句话要收窄
   （本页只证：在**线性色散 + 两带**模型里它们由同一对参数控制）。
