# 空间场调制通信（四力合一单场的 FM 调制）+ 等效超光速随流传输

> 一种场**（主线 GQF：四力 = 流动动量 P̂ = m(Ĉ − v̂) 的 product-rule

## 0. 为什么可以调制（四力合一的单场）

- 主线 GQF2：四力 = dP̂/dt 的 product-rule 四通道
  **电场力 (dm·C) + 核力 (m·dC) − 磁场力 (dm·v) − 引力 (m·dv)**——
  四种基本力是同一个流动动量场 P̂ = m(Ĉ − v̂) 的不同调制方式。
- 因此**"场"只有一种，调制方式（哪个通道被点亮）决定表现为哪种力**。
- 本轮的通信方案 = **纯方向调制（核力通道 m·dC）**：载波 = 空间场
  方向向量 Ĉ 的旋转，幅值（|C|）保持恒定——与 AM 的本质区别（FM6）。

## 1. 核心命题（Lean 全证，零 sorry 零 warning）

### FM1. 相位步长可读（★ 编码）

- 消息 `m : ℕ → Fin 2`（无限比特流）；载波 `s_k = exp(I·(ω₀·k + φ_k))`，
  相位累积 `φ_k = Σ_{j<k} m_j`；瞬时频率 `ω_k = ω₀ + m_k`（两个频段
  对应 0/1 两个字母）。
- **★ `fm1_step_phase`**：连续两样本 `s_{k+1}·conj(s_k) = exp(I·(ω₀ + m_k))`——
  信息编码在相邻样本的相位差（瞬时频率），读相位差 = 直接读空间场。

### FM2. 读出注入性（★ 字母表可区分）

- **★ `fm2_same_phase_same_bit`**：`exp(I(ω₀+b₁)) = exp(I(ω₀+b₂)) ⟹ b₁ = b₂`。
  核心论证：exp 相等 ⟹ 相位差 = 2πn ⟹ |2πn| ≥ 2π > 1，与 |b₁−b₂| ≤ 1 矛盾。
- `fm2b_message_injective`：相同载波序列 ⟹ 相同消息（整条消息注入性）。

### FM3. 解码往返恒等（★ 数学证明可传递信息）

- `fmDecodeBit k ω₀ s`：从相邻样本相位差恢复比特。
- **★ `fm3_roundtrip`**：`decode(encode(m)) = m`——编码 → 传输 → 解码
  恒等。**这就是"空间场调制可以传递信息"的数学证明**。

### FM4. 调制 ⟹ 统一动量场响应（接轨 GQF1）

- `P̂ = m(Ĉ − v0)`；方向调制 `Ĉ₁ ≠ Ĉ₂` 且 `m ≠ 0` ⟹ **动量必变**。
- 载波变化 = 场动量变化——信息调制直接作用在统一场本体上。

### FM5. 核力通道

- 纯方向调制激活 `m·dC` 通道（核力），不激活幅值通道——
  调制方式决定表现为哪种力（四力统一的直接体现）。

### FM6. 载波单位模（★ 与 AM 的本质区别）

- **★ `fm6_carrier_unit_norm`**：`|s_k| ≡ 1`——纯相位调制，
  幅值通道不携带信息；噪声若只攻击幅值，解调免疫。

### FM7. 等效超光速（引用 GQC3，注释层）

- 信号随空间场流动：静止系等效速度 = 1 + v（流动系局部速度仍 ≤ 1）；
  局部因果由流动系光锥保持（GQC3a/GQC3b，`Explorations/QFTFlow.lean`）。

## 3. 直接回答

1. **能传递信息吗？** 能——FM3 解码往返恒等（Lean 全证）+ N30/N31 数值
   BER=0.0（机器精度）。
2. **媒介是什么？** 空间场本身的方向旋转（相位），不经过电磁通道；
   读相位差 = 直接读空间场（N31 两分量方案，读的是 (cosθ,sinθ) 方向向量）。
3. **频段按空间理解？** 是——空间波长被流动压缩 λ_st = λ₀(1+v)
   （N32 相位梯度实测匹配）；频段是空间属性，不是电磁属性。
4. **能超光速吗？** 等效超光速（静止系 1+v > c），随流传输中局部因果
   保持（GQC3 几何拖曳）——与曲率飞船愿景直接连接。
