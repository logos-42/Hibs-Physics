# 双流环设计：缺口容忍的可行域

## 0. 这一页要解决什么

`docs/wiki/hardware-axes.md` §2.4 的**缺口 #2** 是「双流环（Cu 慢流环 / H 快流环）的半径、厚度、
环间距、环流速度与配比数值」，并标注它**阻塞轴①关键件**。它原来的形态是**五个待填的数**。

本页**不改这条缺口的性质** —— 那五个数上游确实没写，本页也不发明它们、不给默认值。
本页改的是它的**形态**：把每个未知量从「一个待填的数」换成**一个由已证条件界定的可行域**，
再把整张表分成三档：

```text
档 1 硬界    ：越过就不成立（数学/机械），不需要实验也知道边界在哪
档 2 可调旋钮：界内**任取都可行**，取哪由实验定 —— 这就是容错空间
档 3 仍未定  ：上游确实没有的机制（μ 的主动产生 / η 的来源）⟹ 不填数，改为**前置判决**
```

⟹ **结论（本页的用处）**：档 2 的五个数**不必先定下来**，装置线照样能推进；它们只需要在放量
（G2 起）之前**落进界内**。而档 3 永远不闭合也不会让前面白干 —— 见 §5。

## 1. 双流环是什么（本页只引用，不重述）

出处：`docs/wiki/theory-antigravity-confinement.md` §2（三层同心架构）+ `PlasmaDynamics.lean` +
`PlasmaAntiGravity.lean`。

```text
① 内  D-T 燃料区      反引力约束的作用对象
② 中  双流环          Cu 慢流环（**外**，重离子惯性锚定，q=Z²/√m≈106）
                      + H 快流环（**内**，轻离子快速响应，q≈1）
                      两者**反向环流抵消**（DR2b）= 场反位形的几何表达
③ 外  RMF 时变场源     旋转磁场线圈，持续变化的电磁场（PA4 / FC9–FC11）
```

环量的**定义**在 `PlasmaDynamics.lean` 里是显式的：

```text
Γ = v · L     （L = 环周长 = 2πR，v = 环流速度）
DR2b★  Γ(v) + Γ(−v) = 0     （反向旋转双环抵消）
```

⟹ **一个立刻可用的推论**：两环的环量必须等大反向 ⟹

```text
v_Cu · R_Cu = v_H · R_H        ⟹   v_H / v_Cu = R_Cu / R_H
```

**「环流速度」因此不是两个独立的待填数** —— 给定半径布置，速度比就被锁死了。而且这个关系
**自己就把布置定死了**：Cu 在外、H 在内 ⟹ `R_Cu > R_H` ⟹ `v_H > v_Cu`（H 必快），
与「轻离子快响应」自洽；反布置（H 外 / Cu 内）会要求 `v_H < v_Cu`，与 PA1/PA2 的排序矛盾。
**布置唯一，不需要额外假设**（断言 A5/A5b）。

## 2. 三条已证约束给出的可行域（全部重算，并与仓库锚点逐位一致）

| 约束 | 出处 | 形式（**乘积/不等式，不是点值**） | 重算校验 |
|---|---|---|---|
| FC12 光速响应上界 | `FrcCompact.lean` FC12 | `k·f_ci(B) < c/L` ⟹ **`L·B < 2π m_i c/(k e)`** | k=5 ⟹ `L·B < 9.7613 m·T`；L=0.5 m 时 **B < 19.5227 T**（锚点 19.52 ✓） |
| PF7 环应力 | `PlasmaFusion.lean` PF7 | `σ = B²R/(2μ₀t) ≤ σ_y` ⟹ **`R·B² ≤ 2μ₀σ_y t`** | B=12.2 T、σ_y=250 MPa、t=0.5 m ⟹ **R ≤ 2.1107 m**（锚点 2.111 ✓） |
| FC8 机械上限 | `FrcCompact.lean` FC8 | `B_cap = √(2μ₀σ_y t_w/r_s)` | r_s=10 cm、2 GPa、t_w=1.35 cm ⟹ **26.0496 T**（锚点 26.05 ✓） |

**再补一条围包口径**（显式声明，不是新物理）：双流环必须连同**外圈 RMF 线圈**装进装置，
所以 `R ≤ L/κ`，本页取 **κ = 2**（口径参数；界随 κ 走，见断言 A4c）。

### 2.1 由此夹出的**环厚度上界**（本页的核心派生量）

同时满足 `R ≤ C_PF7/B²`、`L < C_FC12/B`、`R ≤ L/κ`，并要求存在这样的 B（且 B ≤ B_cap）：

```text
t ≤ t_max(κ) = B_cap · C_FC12 / (κ · 2μ₀ σ_y)
```

| κ | t_max | 含义 |
|---|---|---|
| 2（本页默认） | **0.2024 m** | 环厚度必须小于约 20 cm，否则装不进装置 |
| 1（若允许环贴满装置） | 0.4047 m | 界线性放宽 |

## 3. 本次的真发现：两条已证约束在装置尺度上**打架**

PF7 那个被 `hardware-axes.md` §2.1 引用的锚点用的是 **t = 0.5 m**；
而 FC12 的光速响应上界要求 **t < 0.2024 m**（κ=2）。**这两个数不能同时成立。**

- 这**不是**缺陷，也不是新的物理 —— 是两条**已证**约束在装置尺度上的冲突；
- 它的**用处**正是容错空间本身：两条硬界把环厚度夹成一个**区间**，
  **区间内的任何取值都同时满足两条已证约束**。t 落进 `(0, t_max)` 即相容。

⟹ 给轴①关键件的直接可执行建议：**环厚度按 `t < 0.2 m` 设计**（κ=2 口径），
PF7 的 2.111 m 半径锚点则**只在 t=0.5 m 这组口径下成立**，换厚度要按 `R ≤ 2μ₀σ_y t/B²` 重算。

## 4. 容错三档（本页的交付形态）

### 档 1 硬界（越过 = 数学/机械上不成立；不需要实验就知道）

| 界 | 来源 |
|---|---|
| 闭合环回绕和 = 0 | DR1（AMC6），双环叠加仍保守 DR5 |
| `Γ(v) + Γ(−v) = 0` | DR2b★ |
| 切向流无径向漂移（流被"粘"在环上） | DR4★（AMC7） |
| `μ < 1 − m_e/m_i = 0.999780568` | FC11（D-T） |
| `L·B < 9.7613 m·T`（k=5） | FC12 |
| `R·B² ≤ 2μ₀σ_y t` | PF7 |
| `B ≤ 26.05 T` | FC8（给定绕组口径） |
| `t < 0.2024 m`（κ=2） | 本页派生（§2.1） |

### 档 2 可调旋钮（界内**任取都可行** —— 这就是容错空间）

`环半径 R` · `环厚度 t` · `环间距` · `环流速度绝对值 v` · `Cu:H 配比` · `装置尺度 L` ·
`场强 B` · `FC12 谐波 k`

**已锚定的两条**（不是缺口）：

- **速度比**：`v_H/v_Cu = R_Cu/R_H`（DR2b，见 §1）；
- **配比**是连续旋钮（PA5 凸组合；PA6：μ=1 ⟹ 任意配比组合锚定归零）；
  权重 `q = Z²/√m` 复算得 Cu:H = **106.43**（锚点 106:1 ✓），各向异性 34×（N6）⟹ 氢配比是有效旋钮。

### 档 3 仍未定（**上游确实没有的机制，本页不填数**）

`μ 的主动产生机制` · `η（抹平）的物理来源与功率代价`

**处置 = 前置判决，而不是等它闭合**（见 §5）。这两项在 `world_feed.json` 里对应的槽位**仍是
`null`**，本页不改它们，也不给默认值。

## 5. 为什么这叫「有缺口也能推进」

```text
判决量      D1 回旋共振相对频移 R_ci = 1/(1−μ) − 1     （FC9 + AMC1；零假设 R_ci = 0）
可探测下限  μ_min(δ=1e-4, 3σ) = 2.9991e-4   （hardware-axes §3）
硬天花板    FC11 = 0.999781
⟹ 判决窗口 = [3.0e-4, 0.9998] 跨 3.52 个数量级（1σ 口径下 4.00 个数量级）
```

**关键**：档 3 不闭合**不妨碍判决** —— 桌面判据台只需把 μ 压到 **1e-4 量级**即可判别，
而它离聚变级还差 4 个数量级。于是推进不依赖任何档 2 的数被提前定死：

| 阶段 | 需要的档 2 数 | 是否阻塞 |
|---|---|---|
| **G0–G1（M0–M6，桌面判据台）** | **一个都不需要** | 不阻塞 —— 判的是"通道在不在"，不是"装置多大" |
| G2（M7–M12，中型测试台） | 环半径/厚度/环间距（落进档 1 界内） | 需要，但那时有 G1 的实测数据来选 |
| G3+（放量） | 速度绝对值、配比、L 与 B 的工作点 | 需要，且此时才有标定曲线 |

**花销锚点**：G1 = 9 人·月 = 全周期 1161 人·月的 **1.29%**（`fusion-program-roadmap.md` §7）。
**两个分支都不白干**：`R_ci > 3σ` ⟹ 继续放量；`R_ci = 0` ⟹ **停装置线**（预写的失败处置，
不延长）—— 后一个分支花 1.29% 买到的是一个**判决**，而不是一段没结论的工程。

## 7. 诚实边界

- 本页**没有**给出那五个数 —— 它给的是**域**。任何引用本页的场合都不得把域内的示例点
  （脚本里为展示关系用的 `R_Cu=0.6 / R_H=0.35`）当成设计取值。
- 三条约束的重算只证明**算术与仓库一致**（FC12/PF7/FC8 的闭式 + DR2b 的代换），
  **不证明双流环能产生 μ** —— μ 的主动产生仍是第二输入缺口（档 3）。
- §2.1 的 `t_max` 依赖两个**口径选择**：围包系数 `κ`、以及 FC8 的绕组口径（σ_w=2 GPa、
  t_w=1.35 cm、r_s=10 cm）。换口径，界按声明的方式变（断言 A4c 钉住了缩放关系）。
- 三温度窗口比 `τ_Cu/τ_H = 62.44`（= 质量比，TE2 定理）；数值 D3 的 62.64 含 `1.15e5` 的取整。
- 反引力约束环**整机**几何（径向/轴向包络、端部结构、真空腔）仍是缺口 #1，
  本页**只覆盖双流环那一层**。
- **无新物理预言**：本页是把已证条目组织成一个**可验收的可行域**。
