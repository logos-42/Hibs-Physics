# 理论概念：核、质量、投影与流通

## 1. 核（Kernel）是什么

**核是投影算子的核，不是独立的空间。**

```lean
KernelOf π := { s : S // π s = 0 }   -- Definitions.lean
```

- 核是隐数空间 S 的**子空间**（✅ L3：加法 + 数乘封闭）
- 核是被投影 π 抹平、观测不到的部分
- **具体实例（✅ L5 rank-nullity）**：π = Re : ℂ → Int，ker(Re) = **虚轴 iR**
  - "虚数空间的核"说法方向对但不精确——正确表述：**虚轴 iR 是实部投影 Re 的核**
  - 这正是公理 A3 里 √ 流向的那个 iR——现在有线性代数身份：iR = ker(Re)
- HIBS 公理语言：A1 说 f : S → R 非单射，ker(f) 就是 f 抹平的部分；ζ = ζ_π + ζ_κ，ζ_κ ∈ ker

## 2. 质量是什么意思，通过什么数学方法产生

**质量 = 核空间上的标量不变量（📋 草案定义，非动力学机制）**

```lean
m² := κ(ζ_κ)   -- Mass.lean: κ 是 Aut(ker π) 下不变的标量函数
```

数学方法**不是** Higgs / 自发对称破缺等动力学机制，而是**表示论**：
1. 核 ker π 是子空间（✅）
2. 核有自同构群 Aut(ker π)
3. 任何 Aut(ker) 不变的标量 κ 是质量候选
4. 📋 KernelRepresentation 草案：κ 唯一依赖 dim(ker π) —— **质量 = Φ(维度)**

已证边界：平凡核 ⟹ m = 0（✅ M1）——这就是光子。
未证核心：唯一性（质量 = Φ(dim)）需要核表示论。
实例：dim ker(Re) = 1 ⟹ 质量是标量 Φ(1)——"虚轴多少维 ⟹ 质量多少"。

## 3. 投影、流通、核运动指什么

| 词 | 定义 | 物理含义 |
|---|---|---|
| 投影 π | S → V 线性映射（Re 是实例） | 观测/粗粒化 |
| 流通 Flow | S 上的算子（乘法链 ⊗ⁿ，📋 草案） | 演化：隐数内部运算 |
| 动量 | `momentumOf := π(Flow(ζ))`（Bridges.lean） | 流通的投影 = 可见演化 |
| 核运动 | ✅ K4：非平凡核 ⟹ 核内存在两个不同元素 | 改变 ζ_κ 不改变观测值 |

关键定理（✅ K3）：π(s_im + s_ker) = π s_im —— **往态里加任意核元素，观测值不变**。
"核运动" = 在核内移动内部自由度（虚轴上移动 i 的倍数），观测纹丝不动。
