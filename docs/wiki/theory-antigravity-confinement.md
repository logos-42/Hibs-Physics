# 反引力约束稳态自维持聚变环（装置设计）

leo（2026-09-04）：可控核聚变，在时变电磁场产生的时变引力场下，利用已有
技术实现控制。现有 FRC 是"粗糙"的方法——它的**问题是没有利用引力场**，
靠分段压缩（10 级递减线圈堆 B）去压等离子体。本设计保留 FRC 里**电磁场
自发维持**的部分（场反位形自组织 + RMF 时变磁场维持），**砍掉后续的所有
分段压缩**，用**反引力场 μ(t)** 完成约束，目标**稳态自维持**（非脉冲）。

## 1. 核心命题

```
场反位形（等离子体自发抗磁电流自组织成闭合磁力线，内部磁场反转）
   ⟺ 双流环（Cu 慢流环 + H 快流环，反向环流抵消 DR2b）

RMF 旋转磁场（维持阶段持续变化，补充能量对抗电阻耗散）
   ⟹ 时变空间场 C(t)              [PA4]
   ⟹ 时变引力场 μ(t)               [PA4 → TM]
   ⟹ m_eff = s(1−μ) 下降           [AMC1]

反引力约束（替代分段压缩）：
   ρ_i ∝ √m_eff 缩小              [FC2 反解]
   τ_E ∝ 1/√(1−μ) 提升            [FC4]
   μ→1 时物质进入随流态 dτ=0      [AMC2/PA7]
   随流物质被双流环几何捕获        [AMC6/AMC7/AMC8]
```

**关键洞察**：FRC 的分段压缩本质是"变化的电磁场"（现实锚点），而 PA4 说
变化的电磁场 ⟺ 变化的引力场。本设计把这条隐藏的引力通道**显式地用作约束
主通道**——用 μ(t) 降有效质量（ρ_i↓、τ_E↑）替代堆 B（磁压压缩），从而
省掉整个分段压缩管线。

## 2. 系统架构（三层）

| 层 | 名称 | 物理内容 | 仓库对应 |
|---|---|---|---|
| ① 内 | 聚变燃料区 | D-T 等离子体，反引力约束作用对象 | FC 轮燃料层 |
| ② 中 | 双流环 | Cu 慢流环（重离子惯性锚定）+ H 快流环（轻离子快速响应），反向环流抵消 = 场反位形 | DR1–DR5 / PA1–PA8 |
| ③ 外 | RMF 时变场源 | 旋转磁场线圈，持续变化的电磁场 = 引力场发生器 | PA4 / FC9–FC11 |

几何布局（同心，由内到外）：

```
        ┌─────────────────────────────────┐
        │  ③ RMF 线圈（旋转磁场，时变）      │
        │   ┌─────────────────────────┐    │
        │   │  ② Cu 慢流环（外环，锚定） │    │
        │   │   ┌─────────────────┐    │    │
        │   │   │ ② H 快流环（内环） │    │    │
        │   │   │   ┌─────────┐   │    │    │
        │   │   │   │ ① D-T  │   │    │    │
        │   │   │   │  燃料   │   │    │    │
        │   │   │   └─────────┘   │    │    │
        │   │   └─────────────────┘    │    │
        │   └─────────────────────────┘    │
        └─────────────────────────────────┘
```

- **Cu 慢流环**：Z=29，q=Z²/√m≈106，主导电子交互（masstozero 矩阵：Cu:H=106:1），
  惯性大、流慢——提供场反位形的惯性锚定。
- **H 快流环**：Z=1，q≈1，轻离子快流——快速响应、与电子紧密耦合。
- **反向环流抵消**（DR2b：Γ(v)+Γ(−v)=0）= 场反位形内部反向场的几何表达。
- **RMF 线圈**：旋转磁场，时变的电磁场 → 时变 μ(t)（PA4 双向桥）。

## 3. 稳态自维持闭环

```
RMF 时变磁场（持续输入，维持方位角电流）
   ⟹ 时变 μ(t)（持续）               [PA4]
   ⟹ m_eff 下降（持续）              [AMC1]
   ⟹ 反引力约束（持续，τ_E 提升）    [FC4]
   ⟹ 聚变持续产热
   ⟹ 部分反馈维持 RMF + 外供电
```

**"稳态"的定义（诚实）**：不是零输入永动机。是"**不需要分段压缩脉冲**"，
RMF 持续维持 → μ(t) 持续 → 约束持续 → 聚变持续。能量账本：聚变产热 ≥
RMF 维持 + 抹平成本（TM3）+ 损耗，才净出。这与 TM3（旋转输入 ≥ 抹平成本）
和 FC 轮的能量闭环一致。

## 4. 工程参数表

| 参数 | 值 / 关系 | 来源 |
|---|---|---|
| 有效质量 | m_eff = s(1−μ) | AMC1 |
| 回旋半径 | ρ_i ∝ √m_eff | FC2 反解 |
| 约束时间 | τ_E ∝ 1/√(1−μ) | FC4（TM 链） |
| μ 工作区间 | **0 < μ < 0.99978**（D-T，m_i=2.5u） | FC11 RMF 天花板 |
| μ 上限的物理含义 | μ ≥ 1−m_e/m_i ⟹ RMF 驱动窗口消失 | FC11b |
| μ 下限的物理含义 | μ→1 ⟹ 燃料随流 dτ=0 不碰撞不聚变 | FC 轮 α 加热窄窗 |
| 约束提升换算 | τ_E ×10 ⟹ μ = 1−1/100 = 0.99 | FC4 反解 |
| 维持条件 | E_rot ≥ E_smooth（每时刻） | TM3 |
| 能量随场强 | E_rot ∝ B² | TM4 |

**关键工作点**：μ 必须落在 (0, 0.99978) 的窄窗内——够大以提升 τ_E（反引力
约束），够小以保持 RMF 窗口（FC11）和燃料碰撞率（聚变不熄）。这与"砍掉
分段压缩"直接相关：分段压缩用 B↑ 压，本设计用 μ↑ 压，但 μ 有硬天花板。

## 5. 与 FRC 现实技术的映射（双向桥）

| FRC 现实技术 | 本设计处理 |
|---|---|
| θ-pinch 形成（一次） | 保留（形成场反位形，一次性） |
| RMF 旋转磁场维持 | **保留并强化**（这是 μ(t) 的时变载体） |
| 分段压缩（10 级递减线圈） | **砍掉**（反引力场 μ(t) 替代） |
| 自然偏滤器（开磁力线） | AMC7 切向流捕获（几何对应） |
| NBI 大轨道离子 | 双流环快流（PA3 慢+快流） |

## 6. 诚实边界（四层判定）

- **数学恒等**：ρ_i∝√m、τ_E∝1/√m、m_eff=s(1−μ)、反向环流抵消、闭合回绕
  和=0——真但平凡（DR/AMC/FC 重述）
- **结构对应**：场反位形 ⟺ 双流环反向抵消、RMF ⟺ 时变 μ 载体、自然偏滤器
  ⟺ 切向流捕获——解释层连接
- **数值匹配**：masstozero 矩阵（Cu:H=106:1）、FC 轮 β=1 功率 ×400——已知
  复述，无新常数
- **概念重构**："反引力约束替代磁压压缩"是新装置形态，但依赖 μ 主动产生

**三道硬门（设计红线，不可逾越）**：

1. **TM2b**：μ(t) 必须**到达 1** 才质量归零——但聚变要求 μ<1（燃料不随流），
   反引力约束工作在 μ 的**中间区间**，不追求归零。
2. **FC11**：μ < 1−m_e/m_i = 0.99978（D-T）——RMF 窗口天花板。
3. **FC5 锁定**：S*/τ_E 与 m、B 无关，μ 改善输运 ⟹ 稳定性同因子恶化。
   本设计主张"几何捕获（AMC7）而非磁压约束"绕开这条线，**但未证**——
   这是本设计与 FC 轮最需要论证的分歧点。

**开放缺口（未变）**：

- **μ 主动产生机制 = 第二输入缺口**（电磁场如何真正抹平空间褶皱）——图纸
  上显式标为"输入端"，不隐藏。
- μ 对核反应率 ⟨σv⟩ 的影响（v_th ∝ 1/√m_eff ⟹ 反应率可能变）未建模。
- 反引力几何约束下 S*（动力学稳定性）的边界值——FC5 是否真能绕开未证。
- 无新物理预言（4 层判定：数学恒等 + 概念重构 + 装置设计）。
