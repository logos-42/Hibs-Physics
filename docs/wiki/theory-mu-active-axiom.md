# μ 主动产生假设的分步闭链验证

## 0. 收编指令 + 更正（leo 2026-10-19）

> 「就把这个事情当成是已经解决了的实验缺口。我的脑子里已经有基本的物理来源了，
> 而且代码和数学模型都已经建好了，现在是要去验证它。不要用反问或者抗拒的语气，
> 先用大胆假设的方式来验证。」
>
> **更正**：「**不能让 μ 一步到位**。我们可以开始计算，但不是一步到位。我要算的
> 事情是基于现有系统里的内容进行大胆假设，不是让你直接一步到位。我们的推导是
> 一步一步来的。」

**做法**：大胆假设只落在**链条第一环**——电磁时变场驱动空间流起伏变化（Q_A 改变），
产生**有限**增益 η>0；之后每一环用仓库已有闭式**逐项计算**，不跳步、不承诺
一步到位。初版把「η=1 ⟹ μ 一步到 1」当头条，违反更正，已改。

## 1. 假设 H1（只承诺第一环，写死）

> **电磁时变场驱动空间流起伏变化（Q_A 改变），产生有限增益 η > 0。**
> `η = flattenProgress A v v₀ = 1 − Q_A(v)/Q_A(v₀)`（MUFC TD11）。
> η 是几何/场配置的**有限输出**，符号可变：FRC 半径差几何给 η = **−20.5**（负增益，
> 关门不可能），同半径退化给 η = +1.0（**上界**）。η 的数值由 G1/D1 **首次标定**
> （无实验证据）；**不承诺一步到位、不承诺 η=1**。抹平功率来源随本假设收编
> （时变电磁场自身 = PA4 + CR 轮同族）。

## 2. 分步链（每一环都是仓库已有内容，一步步算）

## 5. 续轮（2026-10-19）：反馈控制律闭环（MAC7–MAC10 / C1–C7）

S5 的「末步调小增益 + 关断」一般化成**显式反馈律**：

    η_control(μ) = 0                          if μ ≥ μT   （关断 TD19）
                 = min(η_inj, (μT−μ)/(1−μ))   if μ < μT   （钳制到精确落窗）

### Lean（`MuAxiomChain.lean` 追加 MAC7–MAC10，零 sorry）

| 定理 | 内容 | 角色 |
|---|---|---|

| **MAC7b ★★** | 控制律单步 μ_{n+1} ≤ μT（min 两支都被钳住） | 一步不变量 |
| **MAC8 ★★★** | ∀n, 闭环轨道 μ_n ≤ μT（归纳不变量；μT < 天花板 ⟹ 永不越界） | **机器保证** |
| **MAC9** | 钳制未激活段 η_control = η_inj ⟹ 进窗步数与开环一致 | 控制不拖慢 |
| **MAC10** | μT ≤ μ ⟹ 闭环一步不变（关断即冻结） | TD19 停留 |

1. **H1 只承诺「η > 0 有限」，不承诺一步到位**：物理来源由 leo 提供，η 的数值
   由 G1/D1 首次标定（无实验证据）；本仓库验证的是假设之后的分步后果链

3. **η 衰减/关断形状是模型选择**（TD18「满增益⟺平坦」+ TD19「关断」语义已有），
   本页验证的是结构结论「关断才能停窗」，不是具体控制律。

   口径（m_e/m_i）钉死的，不是本页新加的约束。

## 8. 死法（写死）

- **H1 的死亡条件**：G1/D1 标定给出 R_ci ≈ 0（δ 精度内）⟹ 电磁时变场不驱动
  质量取消 ⟹ H1 证伪，按原预写处置停装置线。
- **闭链的死亡条件**：η < 0（双流环几何给出负增益，如 FRC 半径差
  η=−20.5 的实例）⟹ 关门不可能，本页 S4/S5 不再适用。
- **停窗的死亡条件**：反馈关断不可实现（η 无法在窗口内关断）⟹ 即使到达
  窗口也会越天花板，劳森持续不成立。
