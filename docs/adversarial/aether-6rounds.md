## R1「瞬时 ⟹ 不可传信」——撤回

**我的主张**：`AetherBand.lean:147 bandZero_iff_const / :158 message_needs_bandwidth / :169 capacity_zero_band`
⟹ 「瞬时模零带宽 ⟹ 零容量 ⟹ 不能传信 ⟹ 不比光速快」。

**隐含前提（6 条）**
1. 「彼此」写成了 `s : ℤ → α` —— **只有时刻、没有位置**（:143）；该模型语法上无法陈述跨位置条件。
2. 需要全局全序时刻索引 ℤ —— 这正是 leo 前提 7 说「在无质量空间不存在」的那个层。
3. 「传信」被默认要先有发送者—接收者—符号集—噪声—分槽五件套；前提 1–9 里一件都没有。
4. 「可分辨」被默认等于「两个**时刻**的值不同」，于是空间编码（同刻多点图案）被排除在外。
5. 「瞬时」被等同于 k=0 全局模，再用 ω=c·k 得 ω=0；而 AB3 已证 k>0 时任意距离相位差可 <ε。
6. AB17/AB18 用 ω=c·k 给以太层封顶 —— 拿被攻层的光锥当地基（循环）。

**偷换**：坐标轴整体交换。（他的问题：同 t、异 x；我的定理：同 x、异 t。）
「彼此」从空间对退化成时间对，方向从对称双向变成隐式信道；「更快」被要求用「符号/秒」度量。

**正确读法**：存在全局标定 L，使**同一时刻不同位置**落在同一纤维：
`MediumFiber L := fun x y => L x = L y`（等价关系，不是序、不是信道）。
落地：`AetherBand.lean` 新增 ⑥ 段 `MediumFiber / mediumFiber_equivalence / CoPhaseAll / coPhaseAll_iff_const / spatial_const_not_time_const`。
其中 `spatial_const_not_time_const` 是决定性的一条：**空间处处同相 ⇏ 时间恒定** ⟹ AB7/AB8 对「瞬时影响彼此」无判定力。

**落地修改**：`BandZero → TimeConst`、`bandZero_iff_const → timeConst_iff_const`、`message_needs_bandwidth → not_timeConst_of_two_instants`；容量四件加「外部信道模型，不在本框架前提内」的层级声明；AB17/AB18 的线性色散前提写明；wiki §1 结论句改写。

**死法**：① 若证明任何跨位置相位对齐都必须由沿空间逐点传播**建立**且该建立时间受 c 约束 ⟹ 读法降为「稳态同步」。② 若证明同刻跨位置同相必然使场在位置上为常数（对齐不能承载结构）⟹ 「影响」失去传递内容。

## R2「时间 = 非交换性的记录」——降级

**我的主张**：`AetherTime.lean:145 AT5 / :179 AT8 / :196 AT9`，wiki §1「线性时间不是先验坐标，而是非对易性的记录」。

**隐含前提**
1. 时间被预设成**先验存在、处处有定义的全函数** τ : ι → ι → ℝ —— 于是「没有时间」只能写成「τ ≡ 0」（零点 ≠ 无对象，这一步从未被检查）。
2. `τ ≡ 0` 在数学上等价于「比较域塌成一个点」；AT8 可以逐字用在任何恒零二元函数上，**「时间」二字在定理里不起作用**。
3. T∘S 与 S∘T 的**词序是输入**（我写下的嵌套），交换差只能报告「语法在语义下可见」，不是「时间被生出来」。
4. 结论里的 ℝ 是**场值**单位，全文件没有「场值 → 秒」的映射 ⟹ 「时间刻度 ∝ 起伏」在量纲上不成立。
5. 可区分 ≠ 有朝向：hgrad 对 (p,q) 与 (q,p) 同时成立、λ² 对称 ⟹ 只给「不同」，不给「谁先」。
6. 「接上 YM 接口」未达成：文件里没有 A、没有 F=dA+A∧A，只有仿射收缩算子 `sinkToPoint` 的不交换性。

**偷换**：他的「不存在**当前的线性时间**观」（否掉一个把多维频率压成一维刻度的**仪器/读法**）
被我写成「不存在序关系」（否掉**对象**）。并且单调性反转：他的无质量层是**瞬时互联的富结构**，我的无质量层是**零**。

**正确读法**：时间的主对象是（带指标 k，相位 φ），刻度是闭合计数 n = kL/2π（`TimeCount` TC1–TC6；`VibrationClosure` VBC4/VBC5）。
无质量/全局层不是「读数 = 0」，而是**时间坐标这个对象没有被生成**（k=0 ⟹ 闭合不发生 ⟹ 无刻度）。
线性时间 = 沿**某一条**带把相位除成一维刻度（一个 section），是人类层选定的读法；TC4 已证不存在带无关的绝对计数。

**落地修改**：文件头删「接上 YM 方程接口 / 时间 = 非对易性」；`order_visible_of_gradient → commutator_of_gradient`（docstring：可分辨≠朝向、无量纲）；`no_strict_order_of_zero_intervals → degenerate_no_strict_order`（序论平凡事实）；`flat_massless_no_time → flat_and_degenerate`（两支**无桥引理**，不得合成引用）。

**死法**：① 在 k=0 全局模上找到不依赖闭合的可分辨相继状态 ⟹ 「k=0 无时间单位」死。② 存在带无关读数 F 使 ∀k, timeCount k L = F L ⟹ 「线性时间只是观」死（TC4 已排除）。

## R3「多带不是高维」——降级

**我的主张**：`BandDimension.lean:50 ND1 / :66 ND2 / ND4`，wiki 结论句「维度 = min(带数, 空间维数+1)」。

**隐含前提**
1. 所有带共享同一对 (x,t)：`phaseOfG (m) (x t)` 里 (x,t) 是**共用实参**；ND2 的「∀ x t」就是这条前提本身。
2. 带 = 一对实数（ModeG 只有两个 ℝ 字段）⟹ 「N 条带」恒等于「ℝ² 里 N 个点」，加带不可能增维。
3. 「维数」被算成相位映射**像的秩**；rank-nullity 说同一句话也给出 dim ker ≥ 1 —— ND 取走秩、扔掉了核。
4. rank ≤ min(带数, d+1) 对带数**完全不敏感**（N=3..1000 同一 2 槽编码秩恒 2），用它回答「多带是否高维」无判别力。
5. 数值门验的是夹具形状：`verify_band_structure.py:226` 的 3×2 矩阵是脚本自己写死的，`rank==2` 由数组形状保证。

**偷换**：他的「维度 = 独立振动轴的个数 n（输入，由集体给出）」，被我换成「共享帧下像的秩（输出）」；
再用这个输出上界去否定输入的可变性。第二处：「像只有 2 维」被读成「空间不是 3 维」。

**正确读法**：维度 = n = 配置空间 𝕋ⁿ 的维数；`rank ≤ min(带数, n+1)` 是**投影降秩**（因子化引理）。
ND 的真内容是被扔掉的那一维核：**相位锁定**（N > 2 条共享帧的相位存在非平凡线性关系）。
落地：`BandDimension` 头注释改写；ND3 从「秩封顶见证」升格为「相位锁定」；ND5 三条改成互不相同的结论。
数值门改为对**带数**扫描（N=3,10,50,200 秩恒 2），让门对该变量真有响应。

**死法**：① 若在 ModeN n 上证明秩恒 ≤ 2 与 n 无关 ⟹ 「n 是输入」死。② 若给出情形使「各自带轴」与「共享 1+1 帧」在一切可测上不可区分 ⟹ 额外轴成为不可观测的形上添加。③ 不可证伪本身即不忠于前提（原 ND 的死法至今无人能触发）。

## R5「无质量 = 无散度」——降级（结论对、判据错）

**我的主张**：`AetherTime.lean:240 AT11 / :247 AT12 / AT14`：divV = 0 表示无质量，涡旋 v=(0,1,1,0) 作「无质量非平坦」见证。

**隐含前提**
1. 质量在 Gauss 定律的位置上（源/荷）—— 而仓库 P3 把那个位置给了**电荷**。
2. 扭曲是可加的带符号标量且只看净和 ⟹ 一正一负两个源被判成「不产生扭曲」（抵消当不存在）。
3. 扭曲只沿两条边取样、只测源性，不测剪切/旋转 —— 而 AT12 自己报告 curlV = 2（场在转）。
4. 「无质量」与「中性」被当成同一谓词的两个名字（仓库 paper3:227 正是这样焊的）。

**偷换**：他说的是「物体不去**拧**周围空间」（逐点、非负、含压缩+剪切+旋转）；
我形式化成 4 点回路上的**净流出和**（带符号、可抵消、不含旋转）。
层级更致命：div 是 P3 的电荷判据，质量是 P2/MC1 的条数/锚定 —— 用 P3 的判据判 P2 的属性。

**自证死**：AT12 的涡旋 v₁ = 1 ≠ v₀ = 0 **有梯度**，按 MC1（梯度 ⟹ 锚定 ⟹ 质量）它**有质量**
⟹ 它根本不能充当「无质量但非平坦」的见证（该见证仍缺，已登记缺口，不许用 div 代打）。

**正确读法**：无质量 ⟺ 锚定/条数为零（N=0 / Γ=0），是**耦合**属性，与场形状（平坦/有源/有旋）无关。
落地：AT11/AT12/AT14 改名为 `flat_implies_sourceless / vortex_sourceless_not_flat / flat_strict_subset_sourceless`；
新增 `massSq N M0 = N·M₀²` 与 `massless_iff_zero_strands`（M₀≠0 ⟹ m²=0 ⟺ N=0）。

**死法**：① 给出 divV=0 而按 MC1 有锚定的场 ⟹ 「div=0 = 无质量」死（AT12 自己就是）。② 承认 curlV≠0 是扭曲 ⟹ 「无扭曲 ⟺ div=0」死。③ 若能造 N=0 探针在平坦场上给出可观测顺序 ⟹ 新读法死。

## R6「以太 = P1 换名」——撤回

见 `docs/adversarial/raw/`（R6 独立件）。要点：

- `A := C` 是**定义恒等**（rfl 级）。一旦同一，「A 超越 C」在类型上不可表达；任何谓词都不可区分（Leibniz）
  ⟹ leo 的命题被我的定义**变成不可判定**，不是被解释。
- 「换名」偷掉了「**基础**」二字：他要的是更底层、可超出、可同步的**载体**；我给的是同一对象的两个名字。

  正是「场层定理不足以判定介质层」的证据 —— 即 `AetherMedium.lean` 的 AL1 `fieldOf_not_injective`。

**死法**：若存在只依赖场的量能唯一反推介质标签 ⟹ AL1 死，「介质先于场」降级。
